## 摘要
基于LLM的自主智能体需要外部记忆来克服其无状态性和有限的上下文窗口，以实现长期交互和动态知识推理。然而，现有的记忆检索方法往往缺乏适应性和样本效率，并且难以从异构存储中检索到正确的记忆混合。我们提出了探索性-同化性反思（EAR）框架，该框架具有高初始检索性能和样本高效的适应性。EAR结合了两种机制：探索性反思，它执行迭代搜索以引导检索并为每个查询收集有用的经验；以及同化性反思，它从经验缓冲区中重放这些经验，以比仅依赖即时奖励的方法更高效地优化全局重排序器。实验表明，在两个长期对话基准上，EAR相对于基线检索器的检索性能提升了高达17.9%。我们还表明，EAR具有高度样本效率和对噪声反馈的鲁棒性。

## Abstract
LLM-based autonomous agents require external memory to overcome their statelessness and limited context window for long-term interaction and dynamic knowledge reasoning. However, existing memory retrieval methods often lack adaptability and sample efficiency, and struggle to retrieve the right mixture of memories from heterogeneous stores. We propose Exploratory-Assimilating Reflection (EAR), a framework for high initial retrieval performance and sample-efficient adaptation. EAR combines two mechanisms: Exploratory Reflection, which performs iterative search to bootstrap retrieval and collect useful experiences for each query, and Assimilating Reflection, which replays these experiences from an Experience Buffer to refine a global reranker more efficiently than methods relying only on immediate rewards. Experiments show that EAR improves retrieval by up to 17.9% over the baseline retriever on two long-term dialogue benchmarks. We also show that EAR is highly sample-efficient and robust to noisy feedback.

## 方法论

### 核心思想
EAR（Exploratory-Assimilating Reflection，探索性-同化性反思）由两个协同模块构成：

- **探索性反思（Exploratory Reflection）**：相当于"短时工作记忆"，在单个查询内进行 T 轮迭代搜索，主动挖掘最相关的记忆条目，既为当前查询构建丰富的证据集，也收集可用于长期自适应的经验。
- **同化性反思（Assimilating Reflection）**：相当于"长期记忆"，利用经验缓冲区（Experience Buffer）存储历史探索经验，通过经验重放持续优化全局重排序器（adapter），而非像现有 RL 方法那样只依赖即时奖励。
- 两者共同构成"反思循环"，在即时自适应性和累积学习之间取得平衡，提升样本效率。

### 关键技术细节
- **残差检索适配器（Residual Retrieval Adapter）**：学习残差变换矩阵  ϕ = {Wq, Wm}（均为 d×d），生成适配后的查询与记忆嵌入：
  - eq = (I + Wq)q / ‖(I + Wq)q‖₂， emᵢ = (I + Wm)mᵢ / ‖(I + Wm)mᵢ‖₂
  - 适配器在候选集 C 上定义 softmax 分布  pϕ(i | x, C)。
- **探索选择机制**：将每个候选记忆视为"查询局部的手臂（bandit arm）"，维护选择次数 N 与经验平均反馈 μ̂，计算 UCB 置信上界；结合三项得分进行无放回选择：
  - 相关性得分：λ_rel · eqᵀemᵢ
  - 多样性惩罚：λ_div · max(emᵢᵀemℓ)，避免重复冗余
  - 探索奖励：λ_exp · UCB 上界
- **当前查询损失**：使用反馈加权排序目标  L_cur，对正/负反馈记忆分别增加/降低其被选概率（含基线 b 以加强负惩罚）。
- **经验重放**：将每条查询的经验（原始查询、候选集、聚合反馈）存入缓冲区；按"预适配查询嵌入"的余弦相似度为当前查询挑选最相关的历史经验（Top-B），用 Gumbel-trick 进行随机采样，复用同一排序损失计算重放损失 L_rep，最终联合优化：L = L_cur + λ_rep · L_rep。

### 算法流程（文字描述）
1. 冻结编码器对查询和记忆库检索出 Top-K 候选集；
2. 适配器残差变换得到修正嵌入；
3. 进行 T 轮探索：每轮用 Bandit 选择（相关性+多样性+UCB）构造 s 个记忆的子集，外部批评者（LLM 引用评分）给出 ±1 反馈，更新 UCB 统计；
4. 聚合 T 轮反馈，将经验存入缓冲区；
5. 从缓冲区采样重放批次，用当前查询损失+重放损失更新适配器参数；
6. 返回最终记忆子集。推理时可选"仅适配器"（零额外 LLM 调用）或"探索器辅助"（额外 T−1 次批评者调用）。

## 实验设计

## 主要结论与发现

- **检索性能显著提升**：LongMemEval 上 Recall@5 相对静态基线最高提升 17.9%，相对 RL 更新方法提升 20.6%；LoCoMo 上分别提升 12.5% 与 29.1%；下游问答 J 指标提升 9.0%–24.4%。
- **样本效率高**：仅需约 80 个训练查询即可超越静态检索器；相比 RL 基线，达到静态基线性能所需的反馈步数减少 77%。在相同 LLM 调用预算（1600 次）下，EAR 仍保持稳定领先（320 次调用即超越基线）。
- **对小检索器增益最大**：在低样本条件下，Contriever 上的提升幅度大于 Stella、GTE 等大检索器（与适配器参数量随嵌入维度增大有关）。
- **对噪声反馈鲁棒**：即使在高噪声条件（Precision=70, Recall=70）下仍优于静态基线；多轮探索反馈聚合是抗噪关键。
- **自适应平衡异构记忆**：EAR 能按查询类型动态调整情景记忆与语义记忆的混合比例，时序类查询的 J 指标从 37.50 提升至 51.56；适配器在嵌入空间中使查询向其所需记忆类型靠拢。
- **与现成重排序器兼容**：叠加 MonoT5 后仍有一致增益，证明 EAR 是检索层的通用反馈驱动组件。

## 优点

- **认知启发的设计**：将工作记忆（探索性反思）与长期记忆（经验缓冲重放）的交互机制引入检索系统，思想新颖且逻辑自洽。
- **样本效率突出**：相较已有 RL 方法，冷启动退化小、收敛快，解决了自适应记忆检索中"初期性能脆弱"的关键痛点。
- **模块化与模型无关**：可无缝叠加于 Contriever、Stella、GTE 甚至 MonoT5 等不同检索/重排序器之上，兼容性强。
- **鲁棒性好**：对反馈噪声不敏感，更贴近真实 LLM 引用不稳定的应用场景。
- **实验严谨性较好**：引入概率化奖励模拟器并通过真实 LLM 验证；设定了严格的 s=5 容量约束；提供了延迟-性能权衡分析，明确两种推理模式的适用场景。

## 不足与局限

- **经验缓冲策略仍有优化空间**：论文自述目前的重放采样策略（相似度 Top-B）较朴素，更精细的采样/重放机制是未来方向。
- **大检索器增益递减**：随着基础检索器规模增大（嵌入维度更高），适配器参数量（2d²）变大，在低样本下提升有限甚至未超过基线（如 LongMemEval 上 GTE），需要更高效的训练策略（如 LoRA）或更多训练数据。
- **算力信息缺失**：未报告 GPU 型号、数量与训练时长，影响复现与成本评估。
- **实验维度存在局限**：多存储混合实验仅使用 Contriever 和 LoCoMo 一个数据集；真实 LLM 引用验证仅 1 次运行；未涉及更长训练轨迹或更大规模查询的充分验证。

- **奖励依赖外部批评者**：框架依赖 LLM 引用评分的质量，虽然对噪声鲁棒，但在批评信号系统性偏差（如任务特定偏好）时，其上限仍受批评者能力约束。
