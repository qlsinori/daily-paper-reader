## 摘要
生物医学实验室机器人必须导航到仪器前才能执行实验程序。现有的具身导航平台专为家庭环境设计，并将目标视为对象中心或任意附近位置。这种表示法不适用于实验室仪器，必须从其操作侧接近，同时与周围设备保持安全距离。我们介绍了BioVLN，一个用于在生物医学实验室中开发和评估视觉语言导航代理的仿真平台。BioVLN将每个仪器表示为三个区域：其物理主体、周围的安全间隙区域以及可用侧前方的操作区域。该模型一致地应用于场景生成、目标放置、导航评估和安全性分析，因此成功取决于到达一个可以访问仪器的位置。BioVLN支持程序化场景生成和手动设计的环境，产生47个场景和1667个情节。标准化的导航和强化学习接口使得轨迹收集和策略训练成为可能。实验表明，几何探索达到74.4%–87.5%的成功率，而在操作区域中采样多个有效位置可将成功率提高到83.3%–92.5%，并减少不安全的接近。

## Abstract
Biomedical laboratory robots must navigate to instruments before performing experimental procedures. Existing embodied navigation platforms are designed for household environments and treat a target as an object center or an arbitrary nearby position. This representation is inadequate for laboratory instruments, which must be approached from their operating side while maintaining safe clearance from surrounding equipment. We introduce BioVLN, a simulation platform for developing and evaluating visual-language navigation agents in biomedical laboratories. BioVLN represents each instrument with three regions: its physical body, a surrounding clearance region, and an operation area in front of the usable side. This model is applied consistently to scene generation, target placement, navigation evaluation, and safety analysis, so success depends on reaching a position from which the instrument can be accessed. BioVLN supports procedural scene generation and manually designed environments, producing 47 scenes and 1667 episodes. Standardized navigation and reinforcement-learning interfaces enable trajectory collection and policy training. Experiments show that geometric exploration reaches 74.4--87.5% success, while sampling multiple valid positions in the operation area improves success to 83.3--92.5% and reduces unsafe proximity.

- **核心问题**：当前导航任务表述缺乏三类关键信息——①仪器的操作方向；②可用的接近区域；③与周围设备的安全间距约束。此外，主流场景生成管线缺乏统一表示来编码上述约束，导致"语义目标搜索"与"支持下游操作交互的导航"之间存在鸿沟。

### 2. 方法论：核心思想与关键技术

**核心抽象：三区域操作包络（Three-Zone Operational Envelope）**

- **Zone 1—物理本体**：仪器轴对齐包围盒，表示仪器实际占用的物理空间。
- **Zone 2—安全净空区**：本体四周向外扩展 0.25 m 的缓冲区域，场景生成时任意两台仪器的 Zone 2 不可重叠（保证至少 0.5 m 的可通行间隙），评估时轨迹侵入记为安全违规。
- **Zone 3—操作包络**：从操作面向外延伸的矩形区域（深度 0.5–0.9 m，依仪器而定），目标位置置于其外边界处，是导航任务真正需要到达的"工作站位置"。

**操作面目标导航（Operational-Face Goal Navigation）**

- 目标位置由公式 `g_i = c_i + f_i · (d_i + δ_i)` 生成，其中 `c_i` 为仪器质心、`f_i` 为操作面方向单位向量、`d_i` 为质心到操作面距离、`δ_i` 为仪器特定的接近距离。
- 行动空间 A = {前进 0.25 m，左转 30°，右转 30°，停止}；在距目标指定成功半径内调用 stop 即判成功。

**双通道场景生成管线**

- **P1（设计师导入）**：通过 LSAT（LabScene Annotation Toolkit，Blender 插件）导入手工构建的 GLB 场景，支持基于目标标记（模糊字符串匹配）和基于网格几何（质心+操作面）的两种目标提取策略。
- **P2（程序化生成）**：从仪器目录和布局模板出发，经规范生成器产生 JSON 描述，再由 Blender 构建器组装场景。
- 两条路径汇入同一基准流程：语义标注（COLOR_0 编码）→ Recast 导航网格 → 情节构建（起点采样 + 操作面目标 + 难度分层）。

**其他技术细节**

- 零原点架构：所有 GLB 资源以局部坐标原点为中心，支持统一的世界空间摆放和旋转，区别于传统预烘焙工作流。
- 四类布局模板（单房间、双房间已实现；套间和开放平面预留），种子值确定性控制随机选择，保证场景可复现。

**对比方法（6 种基线）**

1. **Random**：均匀随机动作 + 5% 停止概率，纯概率下限。

4. **LLM-Frontier**：Frontier 基础上，等距多前沿时调用 DeepSeek 选择。
5. **3-Zone Oracle**：在 Zone 3 内采样多候选点逐一导航，隔离多点采样收益。
6. **VLFM**：基于 VLM 的零样本语义导航（Grounding DINO + GPT-4o + SAM）。

**评估指标**

- 导航指标：SR（成功率）、SPL（路径加权成功率）、DTG（到目标距离）、平均步数。
- 安全指标（创新）：MCR（最小净空半径）、VRT（违规模拟率，即轨迹中进入 0.5 m 危险范围的步数占比）。

### 6. 主要结论与发现

1. **几何覆盖在单房间中已足够**：Frontier Exploration 的 SR 为 74.4–87.5%，在 MS-DEV 和 Two-Room 上甚至超过 Oracle（+2.5 pp 和 +4.0 pp），说明系统化几何探索可补偿离散动作下的目标可达性误差；但差异未达统计显著。
2. **3-Zone Oracle 最优**：在操作包络内采样多个有效位置可将 SR 提升至 83.3–92.5%，同时降低不安全接近（VRT 降至 4.9–6.3%）。
3. **布局密度决定安全性**：紧凑的 LSAT 场景中 VRT 高达 55.3–70.3%，而双房间场景因走廊分隔路径降至 6.3–11.3%。
4. **VLM 失败源于渲染纹理而非知识缺陷**：GPT-4o 对仪器的文本识别 100% 正确，但图像识别仅 13.3%；识别率与表面颜色多样性严格正相关（r=0.84，阈值约 5,000 种颜色），近均匀表面仪器完全无法识别。
5. **操作面目标具有布局不变性**：与质心目标相比，聚合 SR 持平（78.2%），但避免了逐场景方向相反的波动。
6. **行为克隆基线可行**：基于 Frontier 轨迹训练的 BC 策略达到 41.9% SR（vs. Frontier 的 80.0%），提供未来学习方法的参照基准。

### 7. 优点

- **问题表述创新**：首次将"操作面目标"和"三区域模型"系统引入导航平台，成功标准从"到达物体"升级为"可操作接近"，更贴近真实机器人任务。
- **三区域模型的贯穿式应用**：从场景生成（碰撞约束）→ 目标定义 → 评估指标（MCR/VRT）→ 奖励设计（安全惩罚项），同一空间语义全程一致，设计连贯。
- **双通道场景管线**：程序化生成与人工标注导入并重，适配不同需求；LSAT 工具链设计成熟（13 模块、~2,500 行 Python）。
- **接口标准化**：Gym-compatible 环境、轨迹记录器、PyTorch Dataset 构建，便于 RL 训练与零样本评估。
- **实验设计细致**：含专项 VLM 识别实验定位失败原因、质心 vs. 操作面消融、难度分层、逐类别安全分析等，多层次验证。
- **安全性度量创新**：MCR/VRT 是现有平台均未覆盖的指标，填补了导航安全评估空白。

### 8. 不足与局限

- **资产视觉质量**：no_lights 渲染模式和平坦着色大幅降低表面纹理丰富度，导致 VLM 类方法严重失效，构成评估偏差（对语义方法不公）。
- **场景多样性有限**：仅两类基准模板（单房间、双房间），47 个场景中大部分由固定仪器集合程序化生成；缺少纹理随机化、杂乱物品、照明变化等复杂因素。
- **模拟与真实差距**：无 sim-to-real 部署验证；操作面目标的实际物理可行性未经真实机器人检验。
- **数据规模适中**：420 个基准情节不足以支撑大规模学习；行为克隆训练数据仅约 7,142 步。
- **VLFM 评估不完整**：TEST 划分因 API 限制未测，SPL 缺失，与其他方法不可完全比较。
- **统计检验部分缺失**：Random vs. 其他方法的显著性均未报告；LLM-Frontier 在部分划分上与 Frontier 无法区分（样本量不足）。
- **人体工学假设简化**：操作区深度和成功半径的设置依据模型检查而非真实人体/机器人操作验证。
- **评估偏向几何方法**：Frontier 类方法天然契合单房间布局；VLFM 在实验室渲染环境中的劣势可能被夸大（源于资产质量问题）。

**总体评价**：BioVLN 在问题定义、空间抽象和评估体系上具有明确贡献，为实验室场景的具身导航研究提供了有价值的基础设施。受限于资产视觉质量和场景多样性，平台的通用性和对语义导航方法的公平性仍有提升空间，但其建立的操作面目标范式对未来功能性导航研究具有启发性意义。
