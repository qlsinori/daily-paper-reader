## 摘要
目标导向的空中视觉语言导航（VLN）要求在长时程闭环控制下搜索指定目标并精确定位。在导航过程中，由目标描述指令引导，感知优先级动态演变：早期探索优先关注低频空间布局，随后转向高频目标细节。现有VLN方法在导航各阶段使用相同的视觉令牌来建模不同的感知需求，导致无关物体和背景杂波干扰。为此，我们将长时程空中导航建模为从空间结构向局部细节的频偏转移，并提出FreqNav，一种轻量级频率路由自适应感知框架。在固定计算预算下，FreqNav根据当前导航阶段动态地在频率分量间重新分配视觉令牌。频率令牌路由器从双视角观测中选择与阶段相关的视觉表示，而相位依赖定位模块通过显式监督锚定视觉证据。随后，扩散Transformer预测平滑轨迹以进行连续控制。实验表明，FreqNav在优于强基线方法的同时，实现了约3倍的推理加速。实际部署进一步证明了其在长时程空中自主领域的有效性、效率及实际潜力。

## Abstract
Object-oriented aerial vision-and-language navigation (VLN) requires searching for a described target and landing on it precisely, under long-horizon and closed-loop control. Guided by a target-descriptive instruction during navigation, perceptual priorities dynamically evolve: early-stage exploration prioritizes low-frequency spatial layout, and then shifts to high-frequency target details. Existing VLN methods model the varying perceptual requirements across navigation stages with identical visual tokens, leading to interference from irrelevant objects and background clutter. To this end, we therefore formulate long-horizon aerial navigation as a frequencypreference shift from spatial structure to local detail and propose FreqNav, a lightweight frequency-routing adaptive perception framework. Under a fixed computational budget, FreqNav dynamically reallocates visual tokens across frequency components according to the current navigation stage. A Frequency Token Router selects stage-relevant visual representations from dual-view observations, while a Phase-dependent Grounding Module anchors visual evidence through explicit supervision. A Diffusion Transformer then predicts smooth trajectories for continuous control. Experiments show that FreqNav outperforms strong baselines while achieving approximately 3x faster inference. Real-world deployment further demonstrates its effectiveness, efficiency, and practical potential for long-horizon aerial autonomy.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

**整体框架**：FreqNav 将导航建模为部分可观测马尔可夫决策过程（POMDP），由三个模块组成：① 频率令牌路由器（Frequency Token Router）、② 相位依赖定位模块（Phase-dependent Grounding）、③ 基于扩散Transformer的动作生成模块（DiT-based Action Generation）。模型以Qwen2.5-VL为骨干，采用"视觉编码 → 频率路由 → 接地 → 动作生成"的闭环流水线。

**① 频率令牌路由器（Frequency Token Router）**

- **特征空间频谱分解**：对前置/下视双视角视觉特征网格（形状为 B×8×8×H）沿两空间轴施加二维DCT变换，得到频域表示，保持通道维度不变以便后续空间令牌回映射。
- **固定低频核心（Fixed Core）**：通过低通裁切（low-pass crop）保留两个视角的低频全局语义，重构为固定数量的空间令牌（`T_core`），作为全局布局线索。
- **自适应证据库（Adaptive Evidence Bank）**：将频域划分为三个重叠频带（low: r≤2, mid: 2≤r≤4, high: r≥4），对每个视角×频带组合重构出六个有序频率库（B_{v,b}），分别补充粗布局、目标尺度结构、局部边界/纹理信息。
- **目标条件离散路由**：将目标文本嵌入投影为6维未归一化logits，通过**Straight-through Gumbel-Softmax**实现端到端可微的离散选择，每次仅选取一个最相关的频带库，与固定低频核心拼接为最终路由视觉令牌（T_t^R），总令牌数固定（50个）。

**② 相位依赖定位模块（Phase-dependent Grounding）**

- 将路由后的视觉令牌插入Qwen VLM的提示序列，并追加128个**可学习定位查询**（按16×8网格排列并注入二维位置编码）。
- 通过VLM的深层自注意力，这些查询与阶段感知的视觉特征及目标描述充分交互，输出包含空间语义的查询状态 Q_t。
- 在训练时，引入辅助预测头输出**二维热图**，对3步后的专家航点（hg=3）投影到堆叠视图上进行显式空间监督，强制查询定位未来航点，从而将视觉证据蒸馏为具体的空间导航线索。

**③ 基于扩散Transformer（DiT）的动作生成**

- 采用**Flow Matching**框架，将航点生成视为从高斯噪声到专家航点块的线性插值过程：定义概率路径 X_τ = (1-τ)ε + τA*，目标速度场 V* = A* - ε。
- DiT 网络以 [Q_t, p_t, 历史状态] 为条件，通过交叉注意力预测速度场 V_θ，并并行输出停步概率。
- **两阶段训练**：第一阶段用LoRA微调Qwen骨干以对齐多模态感知；第二阶段冻结VLM特征，单独训练DiT控制器。推理时采用16步均匀Euler采样，并采用高频率重规划（每步重新生成动作）以抑制累积误差。
