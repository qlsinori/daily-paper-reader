## 摘要
长期机器人操作在动态演化的环境中，需要跨重复访问持续存在的物体级理解。现有系统要么覆盖历史以维护最新地图，要么存储语义快照但缺乏一致的跨会话物体身份，导致时间遗忘：物体历史的系统性丢失，使得无法回答诸如“绿色椅子在所有会话中曾出现在哪里？”之类的查询。我们提出LT-Mem，一种波动感知的记忆演化框架，将空间对齐的实例级3D感知与波动条件的时间推理统一起来。首先，多会话SLAM主干提供跨会话的空间对齐的每个物体观测。其次，推理层控制物体记忆的演化：确定性证据评分保留跨会话身份，波动感知策略根据每个物体的动态在覆盖、保持和多假设动作之间选择。第三，由此产生的三记忆结构（Live、Delta、Meta）同时保留当前状态和事件历史，支持纵向的以物体为中心的推理。我们进一步引入LT-VQA，一个包含多会话记录、持久身份标注和时间问答对的数据集与评估套件。实验表明，LT-Mem在所有指标上持续优于基线，同时消耗的令牌少一个数量级，消融实验确认收益来自结构化记忆架构而非LLM能力。

## Abstract
Long-term robot operation in evolving environments requires object-level understanding that persists across repeated revisits. Existing systems either overwrite history to maintain an up-to-date map or store semantic snapshots without consistent cross-session object identity, resulting in temporal amnesia: the systematic loss of object history that prevents answering queries such as "Where has the green chair been across all sessions?" We propose LT-Mem, a volatility-aware memory evolution framework that unifies spatially aligned instance-level 3D perception with volatility-conditioned temporal reasoning. First, a multi-session SLAM backbone provides spatially aligned per-object observations across sessions. Second, a reasoning layer governs how object memory evolves: deterministic evidence scoring preserves cross-session identity, and a volatility-aware policy selects among overwrite, hold, and multi-hypothesis actions based on each object's dynamics. Third, the resulting Tri-Memory structure (Live, Delta, Meta) preserves both current states and event histories, enabling longitudinal object-centric reasoning. We further introduce LT-VQA, a dataset and evaluation suite comprising multi-session recordings, persistent identity annotations, and temporal QA pairs. Experiments show that LT-Mem consistently outperforms baselines across all metrics while consuming an order of magnitude fewer tokens, and ablations confirm that gains are driven by the structured memory architecture rather than LLM capacity.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题：时间遗忘（Temporal Amnesia）**。在长期机器人操作中，机器人会反复访问不断演化的环境，物体可能移动、消失、被遮挡或在各会话间被不一致地观测。现有系统存在两类范式缺陷：
  - **几何中心式系统**（如 Khronos、LT-mapper）虽然能维持全局空间一致性，但将物体变化简化为“删除+重建”，系统性地丢失物体历史状态；
  - **语义记忆系统**（如 ConceptGraphs、ReMEmbR、3D-Mem）依赖最新观测或将各会话独立处理，未建立一致的跨会话物体身份。
- 由于上述缺陷，系统无法回答纵向查询，例如：“绿色椅子在所有会话中都出现在哪些位置？”“机器人狗在第 9 次会话时在哪里？”——即**无法进行跨会话、以物体为中心的时间推理**。
- **核心主张**：空间一致性不足以支撑长期操作；系统需要明确建模“何时以及如何更新物体状态”，保留变化轨迹而非将其压缩为单一覆盖状态。论文提出 **LT-Mem**，一种波动感知（volatility-aware）的记忆演化框架，用结构化记忆同时保存当前状态与事件历史，实现高效、可扩展的终身场景理解。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 整体框架：感知层 + 推理层 + 三记忆结构
- **感知层（Perception Layer）**：
  - 基于 **MASt3R-SLAM** 构建多会话 SLAM 主干，结合 **MR.ScaleMaster**（Sim(3) 锚节点）将各会话局部坐标系对齐到统一全局坐标系，并通过 g2o 联合优化轨迹；
  - 使用 **SAM3** 做实例级 3D 分割与提升，对每个物体提取三元组观测：质心 \( c_q^t \)、体积 \( v_q^t \)、视觉嵌入 \( f_q^t \)。
- **推理层（Reasoning Layer）**：
  - **跨会话重识别**：采用五种确定性证据评分（见下表），加权组合，权重 \( w_1=0.05, w_2=0.20, w_3=0.45, w_4=0.15, w_5=0.15 \)，对候选轨迹做 Top-5 检索；简单情况用确定性规则，模糊情况才调用受限 LLM 判定（MATCH / NEW-TRACK / HOLD）；
  
  | 证据 | 作用 |
  |---|---|
  | E1 空间邻近 | 弱先验，避免惩罚位移 |
  | E2 时间连续性 | 跨连续会话的稳定线索 |
  | E3 特征相似性 | 主信号，对视角变化鲁棒 |
  | E4 运动一致性 | 以波动性估计为条件 |
  | E5 遮挡处理 | 抑制误报消失 |

  - **结构完整性检查**：比较当前会话观测锚点与 Live Memory 中注册位置的均值位移 \( \bar{d}_{\text{anchor}} \)；若 \( \bar{d}_{\text{anchor}} > \tau_{\text{align}} = 0.3\text{m} \)，则触发 **SESSION HOLD**，跳过该会话所有更新，防止错误对齐污染记忆；
  - **变化检测**：基于优先级排序的确定性规则集，结合对齐质量、缺失证据信号和波动性条件下的运动容差判断事件类型。
  - **波动性感知更新策略**：波动性分数 \( V_t \in [0,1] \) 采用贝叶斯式证据累积更新：
  \[
  V_t = \frac{P(E_t|V_{t-1})V_{t-1}}{P(E_t|V_{t-1})V_{t-1} + P(E_t|1-V_{t-1})(1-V_{t-1})}
  \]
  其中事件 \( E_t \in \{ \text{NONE}, \text{MOVE}, \text{APPEAR}, \text{DISAPPEAR}, \text{RE-APPEAR} \} \) 为波动性的固定单调函数（非学习参数）；初始先验 \( V_0 \) 由一次性 LLM 查询（基于语义标签）获得。更新策略在以下三种动作间做出选择：
  - **HOLD**：低置信度或遮挡时保留旧状态；
  - **OVERWRITE**：提交新状态；
  - **MULTI-HYPOTHESIS**：保留多个竞争位置假设，待证据积累后优胜劣汰。

- **Tri-Memory 结构**：
  - **Live Memory**：存储当前确认状态，回答“现在在哪”；
  - **Delta Memory**：按时间戳记录逐物体事件日志（MOVE/APPEAR/DISAPPEAR/RE-APPEAR/NONE），含位移度量等上下文，回答“何时发生什么”；
  - **Meta Memory**：累积长期统计（波动性分数、变化频率等），反馈至更新策略，回答“哪个物体最常移动”等聚合查询。
- **查询机制**：物体中心检索模块按查询类型路由到对应记忆组件；度量类查询（位移、频率）通过确定性计算回答，不依赖 LLM 生成，避免幻觉。

## 3. 实验设计

### 3.1 数据集与基准：LT-VQA
- 论文构建了 **LT-VQA** 数据集，包含：
  - **Lab-S**：紧凑室内房间，10 个跟踪物体，10 个会话，每会话 116–159 帧、1.6–2.1 分钟；
  - **Lab-L**：更大室内空间，10 个物体，10 个会话，每会话 115–183 帧、2.6–3.3 分钟；
  - **Parking Lot**：室外场景，用于空间统计任务，10 个会话（不同日期/时段），每会话 124–195 帧、2.2–3.2 分钟。
- 数据集提供：全局对齐的多会话几何、持久物体实例身份、事件级状态转移标注、会话索引的时间问答对。
- 任务类型：**Instance History Tracking**（实例历史追踪）与 **Spatial Statistics**（空间统计）。
- 标注统计：共 61 个状态变化事件（两个室内环境合计）、80 个 QA 对。

### 3.2 对比方法（基线）
- **Geometric Only**：纯距离阈值变化检测，无事件日志 → 时间查询结构性不可回答（N/A）；
- **Text-Batch**：逐帧生成描述并汇总为会话摘要，从连续摘要推断事件；
- **VLM-Batch**：对每个物体批量输入所有会话关键帧，由 VLM 直接判断状态转换；
- **STAR**：近期 agentic 记忆-动作检索系统，禁用导航动作后直接用于回答查询。

### 3.3 评估指标
- **Event F1**：事件级检测精确率与召回率；
- **QA-Event**：自然语言事件历史查询的精确匹配准确率；
- **QA-Freq**：频率查询（如“机器人狗移动了几次？”）的准确率；
- **Tokens**：累计 LLM/VLM API token 消耗。

## 6. 主要结论与发现

- **LT-Mem 在所有指标上优于全部基线**：
  - Event F1：0.910（Gemini）/ 0.885（Qwen），高于最强的 VLM-Batch（0.790）；
  - QA-Event：0.820（Gemini）/ 0.800（Qwen），VLM-Batch 为 0.680；
  - QA-Freq：0.600（Gemini）/ 0.567（Qwen），VLM-Batch 仅 0.333；
  - Tokens：438K（Gemini）/ 352K（Qwen），比 VLM-Batch（7,114K）低约 **一个数量级**，比 STAR（45,859K）低约两个数量级。
- **结构化记忆是收益的根本来源而非 LLM 能力**：使用轻量级 Qwen2.5-3B 仍大幅超越所有基线，证明架构贡献大于模型容量贡献。
- **跨会话身份是时间推理的基石**：去除重识别模块后所有指标近乎崩溃（Event F1 降至 0.140），说明没有持久身份，Delta 和 Meta 记忆均无法形成有意义的记录。
- **波动性感知更新优于固定阈值**：固定阈值产生虚假事件并污染 Meta Memory 统计，导致全面退化。
- **纯几何或纯文本/视觉记忆均不足以回答纵向查询**：Geometric Only 因无事件日志而结构性失败；Text-Batch 因缺乏空间锚定与身份约束而表现最差；VLM-Batch 虽有完整视觉上下文但 Token 成本高昂且频率推理仍弱。
- **LT-Mem 的每会话 Token 成本与会话帧数无关**，在会话增长时优势进一步扩大，适合长期部署。

## 7. 优点

- **问题定义清晰且具有实际意义**：提出“时间遗忘”概念并系统化分类了跨会话物体事件类型（APPEAR/DISAPPEAR/MOVE/RE-APPEAR/NONE）及对应的纵向查询类型，为后续研究提供了清晰的问题框架。
- **方法设计体现结构性创新**：
  - 波动性分数通过贝叶斯式证据累积动态调整，能够自适应不同物体的真实动态，且无需逐物体调参；
  - 三种更新动作（HOLD/OVERWRITE/MULTI-HYPOTHESIS）对应实际推理中的不同不确定性层级，设计简洁而有力；
  - Tri-Memory 结构是推理层输出的自然组织，不是硬凑的架构堆叠。
- **高 token 效率**：推理层只处理紧凑结构化表示而非原始视觉流，每会话 token 成本与帧数解耦，工程实用性突出。
- **确定性可审计**：度量类查询通过确定性计算回答，不依赖 LLM，避免数值幻觉；结构完整性检查提供对齐失败的审计记录。
- **创建了新的基准数据集 LT-VQA**：填补了多会话场景中“事件级标注 + 时间问答对”这一数据空白。

## 8. 不足与局限

- **实验规模有限**：仅 3 个环境（2 室内 + 1 室外）、各 10 个会话、80 个 QA 对，样本量较小；作者也承认需要更大规模、更多样化环境的验证。
- **跨会话重识别在模糊场景下依然困难**：当多个物体外观相似且空间上下文接近时，身份保持仍存在根本性挑战，论文未给出此类对抗场景的定量分析。
- **结构化校验机制未实际触发**：结构完整性检查在所有实验中均未拒绝任何会话，其有效性和阈值选择的敏感性缺乏实证支持。
- **Spatial Statistics 任务缺乏定量评估**：仅展示定性结果，无法客观衡量该任务上的表现。
- **基线的公平性存疑**：Text-Batch 和 VLM-Batch 是论文自行构造的简化基线，而非现有系统的原生能力；STAR 被禁用了其导航动作且以关键词匹配评分，与其原始设计有出入。
- **对感知层依赖较高**：多会话 SLAM 对齐质量、实例分割准确性直接影响下游记忆，但论文未报告感知层单独的错误率或对齐误差分布。
- **长期可扩展性的实际验证不足**：论文声称 token 效率随会话数增长优势扩大，但实验仅覆盖 10 个会话，未做更长部署周期的演示。
