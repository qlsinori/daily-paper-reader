## 摘要
尽管大型视觉语言模型（VLMs）显著推进了具身导航，但其直接部署仍面临挑战，因为现有方法往往迫使VLM进入与它们2D预训练先验不一致的非自然动作空间，加之僵化的推理调度和低效的记忆管理。为克服这些局限，我们提出TAMP-Nav，一个用于高效具身导航的统一框架。首先，我们引入像素到3D动作公式化（指向），将导航重新表述为2D视觉提示。具体而言，VLM仅选择2D像素，随后将其投影到3D坐标以用于低级SLAM控制器。这一设计自然地将具身执行与VLM固有的2D视觉能力对齐。其次，我们提出集成选择性推理与锚点轨迹记忆机制（思考与记忆），该机制动态触发思维链，并仅在关键节点保留高保真记忆，将冗余轨迹压缩为轻量级时空指示符，从而保留关键历史信息并增强时空感知。最后，我们通过群体相对策略优化（GRPO）设计了一种高效的两级对齐范式（对齐）。通过叠加全局结果奖励与细粒度过程奖励，这种密集监督将智能体的认知规划与物理环境反馈紧密对齐，赋予模型自适应推理能力。实验表明，TAMP-Nav在R2R-CE上实现了最先进的性能（如66.2%的SR），同时具有高运行时和样本效率（仅需9万条训练轨迹）。

## Abstract
Although Large Vision-Language Models (VLMs) have significantly advanced embodied navigation, their direct deployment remains challenging, as existing methods often force VLMs into unnatural action spaces that misalign with their 2D pre-training priors, compounded by rigid reasoning schedules and inefficient memory management. To overcome these limitations, we propose TAMP-Nav, a unified framework for efficient embodied navigation. First, we introduce a Pixel-to-3D Action Formulation (Point) that reformulates navigation into 2D visual prompting. Specifically, the VLM merely selects 2D pixels, which are then projected into 3D coordinates for a low-level SLAM controller. This design naturally aligns embodied execution with the VLM's inherent 2D visual capabilities. Second, we propose an integrated Selective Reasoning and Anchor-Trajectory Memory mechanism (Think and Memorize), which dynamically triggers Chain-of-Thought and retains high-fidelity memory only at critical nodes, compressing redundant trajectories into lightweight Space-Time Indicators, thereby preserving critical historical information and enhancing spatio-temporal perception. Finally, we design an efficient Two-Level Alignment Paradigm (Align) via Group Relative Policy Optimization (GRPO). By superimposing global outcome rewards with fine-grained process rewards, this dense supervision tightly aligns the agent's cognitive planning with physical environmental feedback, endowing the model with adaptive reasoning capabilities. Experiments demonstrate that TAMP-Nav achieves state-of-the-art performance (e.g., 66.2% SR on R2R-CE) with high runtime and sample efficiency (requiring only 90k training trajectories).

## 1. 核心问题与整体含义（研究动机与背景）

- **研究对象**：视觉语言模型（VLM）在具身导航（Embodied Navigation）任务中的直接部署问题。
- **核心动机**：尽管VLM多模态理解能力强大，但在现实导航中存在三大关键瓶颈：
  1. **动作公式化的几何鸿沟（Geometric Gap）**：VLM主要基于2D图像-文本对预训练，现有方法却强迫其输出低级原子动作（如"左转30°"）或回归3D空间坐标，导致空间幻觉与低样本效率。
  2. **推理效率与导航性能的矛盾**：现有方法通常每步或按固定间隔触发思维链（CoT），虽然提升决策质量，但带来严重推理延迟，无法平衡效率与性能。
  3. **长时记忆的信息丢失与时空感知缺失**：保留全部视觉特征会导致注意力稀释和内存溢出；不加区分地丢弃历史又可能丢失关键信息；且现有架构缺乏显式时空坐标来组织历史信息。
- **整体意义**：论文提出统一框架**TAMP-Nav**，试图同时解决动作公式化、推理调度和记忆管理三方面问题，为高效VLM具身导航提供新范式。

## 2. 方法论

### 核心思想

TAMP-Nav 框架围绕四个关键组件构建：**Point（指向）、Think（思考）、Memorize（记忆）、Align（对齐）**，通过连续交互循环完成导航任务。

### 关键技术细节

**① Pixel-to-3D 动作公式化（Point）**

- 智能体扮演"视觉指针"角色，在每步接收4幅覆盖360°视野的自我中心图像（前/左/后/右）。
- VLM首先选择最优视图，然后输出指向目标路点的2D像素坐标 `(u, v)`。
- 通过深度图 `D_t,i` 和相机内参矩阵 `K`，将像素投影为局部3D点：`P_t = D_t,i(u,v) · K⁻¹[u,v,1]ᵀ`。
- 再经坐标变换送入低级SLAM控制器执行局部移动。
- **优点**：免除VLM学习复杂3D几何变换，使其专注于视觉语义定位；利用深度相机可迁移至真实世界。

**② 选择性推理与锚点轨迹记忆（Think + Memorize）**

- **动态推理触发**：模型在关键拓扑节点（如十字路口、门口、目标附近）自主触发深度CoT，日常路径段跳过推理。
- **显式锚点（Explicit Anchors）**：在触发CoT的关键节点 `t_k`，以三元组存储状态：时空指示符 + 高保真原始视觉特征 + 规划信标（CoT任务阶段摘要）。
- **时空指示符（Space-Time Indicators, STI）**：将坐标 `(x,y)`、时间 `t`、朝向 `yaw`（用三角函数表示避免0°/360°不连续）分别通过2D/1D RoPE编码后，经MLP融合成单一token，注入上下文序列，提供密集几何与时间感知。
- **轨迹压缩**：对两个锚点间的冗余路径段，仅保留轻量级STI流，丢弃冗余视觉特征。
- **工作记忆与长期拓扑记忆**：当前步与最近锚点之间均匀采样两帧作为工作记忆，与重建的长期拓扑记忆序列拼接作为输入上下文。

**③ 两级GRPO对齐范式（Align）**

- **阶段一（SFT冷启动）**：在自构的 MultiNav-CoT 数据集上对 Qwen2.5-VL-7B 进行简短监督微调。
- **阶段二（两级GRPO强化学习）**：
  - **局部逐步奖励** `R_local⁽ᵗ⁾`：包含目标接近奖励、碰撞避免奖励、停止动作奖励、推理价值奖励（仅当CoT带来优于平均策略的行动时才奖励）、格式遵守奖励。
  - **全局轨迹奖励** `R_global`：包含任务成功奖励（成功=1.0，oracle成功=0.5）、SPL轨迹效率奖励、推理密度奖励（约束过度思考，CoT比例超过0.4开始衰减，超过0.6归零）。
  - **多分支滚动**：每个决策步采样M=4个候选动作，通过退火引导采样策略选择执行动作；早期以局部奖励加权候选选择，后期趋于均匀分布。
  - **双层次优势叠加**：全局轨迹优势（对G=8条轨迹的全局奖励做Z-score标准化）与局部逐步优势（对M个候选的局部奖励做Z-score标准化）相加，形成总优势。
  - **token级GRPO损失**：在策略比值上应用clip和KL散度惩罚。

## 6. 主要结论与发现

- **SOTA性能**：TAMP-Nav 在 R2R-CE Val-Unseen 上达到 66.2% SR，在 RxR-CE Val-Unseen 上达到 65.7% SR，均超过此前所有方法。
- **高样本效率**：仅用90k训练轨迹（700k交互）达到竞争性结果，RL从SFT基线（55.7% SR）提升至66.2% SR，证明密集奖励RL比纯监督学习更高效。
- **推理按需涌现（Emergent Reasoning-on-Demand）**：RL训练后，模型将直线走廊中的CoT触发比例从SFT模型的38%降至11%，自动将推理集中在拓扑关键节点；自动触发策略（26.3% CoT比例）几乎匹配Dense CoT（100%比例）的性能（66.2% vs 66.8% SR）。
- **记忆机制优势**：AT-Mem在长时任务上显著优于均匀采样和全历史策略；STI token对维持长时空间记忆至关重要（去除STI后SR从49.8%降至45.6%）。
- **两级GRPO有效**：局部逐步优势解决信用分配困难，退火引导采样加速收敛并提升最终性能（学习曲线奖励从0.59提升至0.68）。
- **真实世界可行性**：零样本迁移下达到60.0%成功率，优于StreamVLN（49.0%）和DualVLN（53.0%）。

## 7. 优点

- **方法创新性强**：
  - Pixel-to-3D动作空间巧妙化解VLM的2D-3D几何鸿沟，充分利用2D预训练先验。
  - 选择性推理与锚点记忆耦合设计，同时解决效率与信息保持两方面问题。
  - 引入推理价值奖励和推理密度奖励，直接优化"何时推理"这一元认知能力。
- **实验全面**：覆盖模拟、真实世界、长时任务、深度噪声扰动等，尤其在长时任务和真实世界部署上具有较强说服力。
- **效率突出**：不仅性能SOTA，推理速度（16.58s/任务）显著优于基线，训练数据量需求大幅降低。
- **工程完成度高**：详细给出了奖励公式、损失函数、超参数、关键节点选择算法伪代码及多阶段CoT生成提示，可复现性强。
- **分析深入**：STI token的可视化分析（坐标-颜色映射）、推理触发空间热力图分析等，提供了模型可解释性视角。

## 8. 不足与局限

- **感知依赖**：严重依赖深度信息（Pixel-to-3D投影、STI编码）和可靠SLAM栈。实验虽验证了对中等深度噪声的鲁棒性（σ=0.2时SR仅下降2.8%），但严重深度误差、SLAM漂移、定位失败、高度动态环境仍会造成显著性能下降。
- **训练局限**：GRPO训练依赖模拟器特权信号（进度、成功、SPL、碰撞），不支持实体机器人上的在线强化学习；真实世界部署仅限仿真训练的零样本迁移。
- **关键节点挖掘启发式**：基于CLIP语义相似度和视觉变化的启发式方法，可能漏选视觉显著性低或指令风格差异大的关键状态，需要额外训练样本或学习式触发标准。
- **STI编码不完整**：仅编码平面位置 `(x,y)` 和朝向，不含高度信息，无法显式区分楼层，在多楼层或复杂地形中可能受限。
- **推理密度阈值需要调整**：固定的0.4/0.6 CoT比例阈值可能不适配推理密度分布显著不同的新任务/新数据集。
