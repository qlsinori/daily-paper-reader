## 摘要
视觉语言导航智能体通常根据其遵循路线式指令朝向固定目标的能力进行评估。然而，真实的导航指令往往依赖于环境的状态：如果某个条件成立，则走一条路，否则走另一条路。这类指令要求智能体评估场景证据，选择正确的逻辑分支，并执行相应的导航行为。现有的评估对条件分支执行的控制有限，难以确定智能体失败是由于感知、接地、导航还是逻辑决策。我们引入了CondVLN，一个基于场景图的基准，用于诊断视觉语言导航中的条件分支。CondVLN程序化生成指令，其分支条件基于可验证的3D场景图谓词，并在分支深度、依赖链长度、空间组合、证据可观察性和指令范围方面进行控制变化。CondVLN包含跨AI2-THOR、Matterport3D、Gibson和ReplicaCAD的超过11500条生成的条件指令，并使用标准VLN指标和分支特定诊断来评估智能体：分支选择准确率和条件成功率。评估四个最先进的VLN智能体（VLN-Zero、NaVid、NaVILA和Open-Nav）表明，条件分支暴露了仅通过标准成功率或路径长度无法捕捉的失败：智能体可能在做出与观察场景条件不一致的分支决策的同时，以合理方式导航。我们还提出了一种轻量级的神经符号分支选择模型，该模型将条件接地与导航执行分离，性能提升了2倍。CondVLN提供了一个可复用的测试平台，用于衡量具身智能体是否不仅能够遵循指令，还能够在正确条件下遵循正确的指令。

## Abstract
Vision-language navigation agents are often evaluated on their ability to follow route-like instructions toward a fixed goal. Yet, real navigation instructions often depend on observed states of the environment: if a condition holds, then follow one path, otherwise take another. Such instructions require an agent to evaluate scene evidence, select the correct logical branch, and execute the corresponding navigation behavior. Existing evaluations provide limited control over conditional branch execution, making it difficult to determine whether agents fail because of perception, grounding, navigation, or logical decision-making. We introduce CondVLN, a scene-graph-grounded benchmark for diagnosing conditional branching in vision-language navigation. CondVLN programmatically generates instructions whose branch conditions are grounded in verifiable 3D scene-graph predicates, with controlled variation in branch depth, dependency chain length, spatial composition, evidence observability, and instruction horizon. CondVLN contains over 11,500 generated conditional instructions across AI2-THOR, Matterport3D, Gibson, and ReplicaCAD, and evaluates agents using standard VLN metrics and branch-specific diagnostics: Branch Selection Accuracy and Conditional Success Rate. Evaluating four state-of-the-art VLN agents (VLN-Zero, NaVid, NaVILA, and Open-Nav) shows that conditional branching exposes failures that are not captured by standard success rate or path length alone: agents can navigate plausibly while committing to a branch inconsistent with the observed scene condition. We also present a lightweight neurosymbolic branch-selection model that separates condition grounding from navigation execution, improving performance by 2x. CondVLN provides a reusable testbed for measuring whether embodied agents can not only follow instructions, but follow the right instruction under the right condition.

# If, Then, Otherwise：视觉语言导航中的条件分支诊断（CondVLN）

## 1. 核心问题与研究动机

- **背景**：现有视觉语言导航（VLN）基准（如 R2R、RxR、AI2-THOR、Gibson、ReplicaCAD 等）普遍以“固定目标、路线跟随”为主要评估范式，关注智能体能否沿指令轨迹到达目标位置。
- **核心缺陷**：真实导航指令往往依赖**环境状态**进行条件分支，例如“如果厨房有咖啡桌，去它北边的凳子；否则去洗手间水槽下方的灯”。这类指令要求智能体同时完成**感知、语义空间接地、逻辑决策与导航执行**，而现有评测既缺乏对分支条件的系统控制，也无法将失败归因到具体环节（感知、接地、导航还是逻辑判断）。
- **论文目标**：引入 CondVLN，将“条件推理”确立为 VLN 的显式评估维度，使条件分支的复杂度可控制、条件真值可验证、任务成功率可归因——最终回答“智能体能否不仅在正确情况下遵循指令，而且在正确条件下遵循正确指令”。

## 2. 方法论

### 2.1 核心思想

以 **3D 场景图（scene graph）** 为中介，程序化生成条件导航任务。所有分支条件均锚定于场景图中可验证的谓词（如“对象 X 是否在房间 A”），从而保证条件真值在生成时已知、可复现。

### 2.2 技术细节

- **统一场景层次表示**：将 AI2-THOR、ReplicaCAD、MP3D、Gibson 四种异构数据集的标注抽象为统一的“房间→对象”层次结构；每个对象含语义标签、3D 中心坐标，以及可选的大小、半径、AABB 等几何元数据。
- **空间关系生成**：
  - 距离指标按优先级回退选择：AABB 表面距离 → 球体表面距离 → 中心距离；
  - 生成 8 方位 × 3 高度（水平/上/下）的**规范方向谓词**（如 east-of、east-and-up-of）；
  - 生成语义谓词（near/far、higher/lower、above/below），采用固定保守阈值保证可复现；
  - 所有谓词均记录来源指标（中心距离、方位角分区、仰角分区等），保证可追溯性。
- **条件指令合成**：
  - 基础逻辑结构为 `IF condition THEN action ELSE action`，条件为“对象存在性查询”；
  - 沿**两个可控复杂度轴**扩展：逻辑深度（嵌套层级 d）与链长度（顺序分支数 ℓ），形成 6 类任务（简单、嵌套、深度嵌套、链、长链、嵌套链）：
    - 嵌套：IF A THEN (IF B THEN x ELSE y) ELSE z
    - 链式：IF A THEN x ELSE IF B THEN y ELSE z
  - 对象采样策略：有效引用对象存在与房间中，无效引用对象在场景其他房间存在但不在当前房间，以构造受控的错误分支；重复对象用空间限定词消歧。
- **VLN-CE 兼容封装**：将生成指令转换为 Habitat/VLN-CE 标准 episode（含场景 ID、起止点、旋转、参考路径、测地距离），可直接替换数据集路径评估现有模型。
- **诊断指标**：
  - **分支选择准确率（BSA）**：智能体按序到达正确分支的有序子目标的最长前缀比例（支持部分分数）；
  - **条件成功率（CSR）**：要求 BSA 为 1 且最终导航成功（Habitat Success）；
  - 二者互补，可区分“到达了看似合理目标但分支错误”与“分支正确但执行失败”的情形。
- **神经符号 Oracle 基线**：利用构造时记录的符号元数据确定正确分支，将条件指令改写为线性化指令（保留目标与有序子目标），下游导航模型不变。用于诊断“若分支选择正确，模型表现如何”。

## 6. 主要结论与发现

- 条件分支显著恶化现有 VLN 智能体表现，且**标准 SR/SPL 无法反映分支错误**——智能体可能在路径上看似合理却选择了与场景条件不一致的分支。
- **NaVid、NaVILA 在所有数据集上表现较弱且不稳定，尤其在 CSR 上接近或等于 0**，说明当前训练范式难以泛化至结构化条件决策。
- **Open-Nav 与 VLN-Zero 相对较强**，分别受益于 LLM 时空推理与显式场景图结构。
- **复杂度扩展实验**：逻辑深度与链长度增加均导致 BSA/CSR 一致下降；深度从 d=2 到 d=3 的退化尤其显著，说明嵌套层数比链长度对模型更具挑战性。
- **Oracle 的优势在简单场景不明显，但在复杂场景（d=3、ℓ=2）中凸显，超越 Open-Nav 2 倍**，证明显式符号分解在复杂条件推理中不可或缺。

## 7. 优点

- **提出新评测维度**：首次将“条件分支”作为 VLN 的可控诊断变量，弥补现有基准的盲区。
- **场景图锚定与可验证性**：所有条件均基于场景图谓词生成，真值可精确复现，支撑细粒度失败归因（感知/接地/逻辑/执行）。
- **跨环境兼容性**：单一代框架适配 4 种异构数据源，输出 VLN-CE 标准格式，无需改动模拟器即可评估现有模型，实用性强。
- **诊断指标设计合理**：BSA/CSR 与标准 SR 互补，能够揭示“到达目标但分支错误”等隐性失败模式。
- **神经符号 Oracle 基线**：将符号分支分解与下游导航解耦，作为诊断探针和强基线，为后续神经符号方法提供了参照。

## 8. 不足与局限

- **环境覆盖**：仅限室内 VLN-CE 兼容环境，不涵盖室外、开放世界或动态场景。
- **数据质量风险**：基准继承底层扫描噪声与语义标注错误（尤其 MP3D/Gibson），可能干扰感知与条件验证的真实性。
- **关系生成启发式**：固定几何阈值和方位分区可能不适用于所有场景分布或风格。
- **Oracle 不真实**：利用构造期符号真值，回避了真实智能体的感知不确定性，其增益反映的是“理想分支选择”的上界而非可实现水平。
- **指标局限**：BSA 依赖子目标标注质量；对无子目标 episode 的 BSA 采用二值化处理，可能损失部分区分度。
- **实验补充不足**：未报告算力消耗、方差/置信区间、分任务类别（6 类）的结果，限制了结果的统计可靠性。
