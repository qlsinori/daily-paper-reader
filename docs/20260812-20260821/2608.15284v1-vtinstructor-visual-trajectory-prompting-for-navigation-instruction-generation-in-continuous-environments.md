## 摘要
在连续环境中，从自我中心RGB视频生成导航指令是人机交互和可扩展数据集构建中一项重要但具有挑战性的任务。先前的指令生成器假设具有全景观测的离散视点图，其中轨迹结构是显式的；然而，在连续环境中，智能体仅接收到密集的RGB流，使得轨迹线索难以恢复。我们提出了VTInstructor，这是首个面向连续环境的VLN指令生成框架。我们的关键思想是将隐式轨迹几何转换为显式视觉轨迹提示：EDTC将长RGB轨迹压缩为导航关键帧，VTP将路径、转向和目标线索叠加到这些锚点上，VTMod将生成的轨迹信号注入视觉编码器，VT-GRPO在训练期间进一步校准这种空间注入，所有这些都不需要导航图、预建地图或场景重建。在具有挑战性的R2R-CE和RxR-CE验证未见基准上，VTInstructor在所有标准NLG指标上树立了新的最优水平，分别超越了最强基线+0.357 CIDEr和+0.109 CIDEr。在自动指标之外，VTInstructor生成的指令将冻结跟随者的成功率提升到63.3%，比最佳竞争指令来源高出+14.7个百分点，并在下游导航任务上提供一致的+3 SR点的数据增强增益。

## Abstract
Navigation instruction generation from ego-centric RGB video in continuous environments is an important yet challenging task for human-robot interaction and scalable dataset construction. Prior instruction generators assume discrete viewpoint graphs with panoramic observations, where trajectory structure is explicit; in continuous environments, however, the agent receives only a dense RGB stream, making trajectory cues difficult to recover. We propose VTInstructor, the first VLN instruction generation framework for continuous environments. Our key idea is to convert implicit trajectory geometry into explicit visual trajectory prompts: EDTC condenses long RGB trajectories into navigation-critical keyframes, VTP overlays path, turn, and goal cues onto these anchors, VTMod injects the resulting trajectory signals into the visual encoder, and VT-GRPO further calibrates this spatial injection during training, all without requiring a navigation graph, pre-built map, or scene reconstruction. On the challenging R2R-CE and RxR-CE Val Unseen benchmarks, VTInstructor sets a new state of the art across all standard NLG metrics, surpassing the strongest baseline by +0.357 CIDEr and +0.109 CIDEr, respectively. Beyond automatic metrics, VTInstructor-generated instructions raise a frozen follower's success rate to 63.3%, a +14.7 percentage-point gain over the best competing instruction source, and provide consistent data augmentation gains of +3 SR points on downstream navigation tasks.

## 1. 核心问题与整体含义

- **研究背景**：导航指令生成（NIG）旨在用自然语言描述智能体已走过的轨迹，是人机交互与大规模数据集构建的关键技术。已有方法（如 Speaker-Follower、C-Instructor、MapInstructor 等）均在**离散导航图**上工作，依靠全景图像和显式的视点关系，轨迹结构易于推断。
- **核心问题**：在**连续环境**（如 Habitat 模拟器）中，智能体只获得稠密的**第一视角 RGB 视频流**，没有导航图、预建地图或 3D 重建；相邻帧高度相似，路径方向、转向行为、目标进度等轨迹线索变得**隐式且难以恢复**。现有 VLN 智能体与多模态大模型（MLLM）恰恰缺乏这种细粒度空间推理能力，导致生成的指令容易退化为方向模糊、空间不精确的通用描述。
- **论文目标**：提出 **VTInstructor**，这是**首个面向连续环境的 VLN 指令生成框架**。其核心思想是**将隐式轨迹几何转换为显式视觉轨迹提示**，使模型可以直接“看见”路径结构，而不是从密集 RGB 流中艰难推断，从而在不依赖任何图结构或场景重建的前提下生成高质量导航指令。

## 2. 方法论

### 2.1 总体框架

- VTInstructor 基于 **Qwen3-VL-8B** 主干，输入为交替排列的“关键帧图像 + 动作文本片段”序列（如 `P, I1, [Action 1: d1], I2, [Action 2: d2], ...`），自回归生成导航指令。
- 包含四个核心组件：**EDTC**（事件驱动轨迹压缩）、**VTP**（视觉轨迹提示渲染与数据策展）、**VTMod**（视觉轨迹调制器）、**VT-GRPO**（强化学习校准）。

### 2.2 事件驱动轨迹压缩（EDTC）

- **Level 1：动作行程长度编码（RLE）**：将连续相同动作合并为段 `s_k = (type_k, n_k)`，保留全部位移/旋转；前向段若超过 4.0 m 则拆分为两段，避免事件过长。
- **Level 2：小步组合分组**：将短前向（0.25 m/0.5 m）或单步旋转（30°）合并为组合事件（最多 6 段），保留细粒度的“转向+前进”语义单元。
- **Level 3：动态优先级压缩（DPC）**：当帧数超过 `F_max = 32` 时，用视觉-几何联合得分 `J(i,j)=λ_vis Δvis + λ_geo Δgeo` 移除最不重要的边界帧，始终保留首帧和当前帧，最终得到紧凑关键帧集。

### 2.3 视觉轨迹提示渲染与数据策展（VTP + QF）

- 在关键帧上叠加三类显式提示：
  - **路径带（Path ribbon）**：在当前视角中绘制平滑后的未来路线（非纯旋转事件时使用）；
  - **旋转箭头（Rotation arrow）**：用弯曲箭头和角度标注转向事件；
  - **端点标记（Endpoint marker）**：在未遮挡时标注目标位置。
- 每个提示存储为 **3 通道二进制掩码** `M ∈ {0,1}^{3×H×W}`（分别对应路径带、旋转箭头、端点标记），避免颜色歧义。
- 为 R2R-CE 和 RxR-CE 设计不同风格的系统提示，并明确要求模型**利用提示但不得在指令中提及这些渲染标记**。
- **GPT 质量过滤（QF）**：从方向准确性、地标特异性、距离合理性、语言流畅性四个维度评分，只保留高分（≥6/10）的指令-关键帧对。

### 2.4 视觉轨迹调制器（VTMod）

- **VTP 编码器**：将二值掩码经 3 个 stride-2 卷积块（通道 64→128→256，含组归一化与 GELU）处理，再用 1×1 卷积投影到维度 `d_v=384`，最后用自适应平均池化对齐到 ViT patch 网格，得到与每个 patch 一一对应的特征 `v_i`。
- **空间调制注入**：在 ViT 第 7 层对每个 patch token 执行：
  `h'_i = h_i + g ⊙ LN(W v_i)`，其中 `g` 为可学习的通道级门控，**初始化为接近 0**（懒惰激活），保护预训练视觉表征，同时允许新任务渐进入侵。
- 设计消融表明：在**单一早期层**注入优于跨多层；**门控投影**优于交叉注意力。

### 2.5 两阶段训练

- **阶段一：SFT**：在 GPT 过滤后的数据上做标准 next-token 交叉熵训练；使用双学习率（新模块高、预训练骨干低）。
- **阶段二：VT-GRPO**：
  - 采样 G=8 个候选回复，奖励为自动 NLG 指标的加权组合：`r(y)=w_B1·B1 + w_B4·B4 + w_M·METEOR + w_R·ROUGE-L + w_C·CIDEr`（权重 0.25/0.25/0.25/0.20/0.05），并设置 KL 惩罚和裁剪。
  - 额外引入**门对比损失**：在每组最好/最差回复上计算对比项，直接驱动门控向量放大与高奖励相关、抑制与低奖励相关的 VTP 通道。
  - 训练时冻结 ViT、VTP 编码器和调制投影层，仅训练 LLM 骨干和门控向量。

## 7. 局限性与潜在争议

- **关键帧依赖与信息瓶颈**：VTInstructor 的性能上限依赖于 EDT C 选取的关键帧是否忠实保留轨迹几何。若轨迹中发生快速连续转向、长距离匀速直行或大角度抬头/低头（如上下楼），DPC 的动态优先级打分可能移除携带重要转向信息的帧，从而丢失事件语义。
- **提示渲染的理想化假设**：路径带与旋转箭头要求系统已知当前帧的相机内参、外参和后续路径的精确几何。在真实传感器存在噪声、漂移或遮挡（如被桌子挡住的目标点）时，绘制的提示可能偏移或失效；论文的 QF 步骤只能过滤指令质量，无法修复几何估计本身的误差。
- **依赖强大外部模型**：QF 使用专有 GPT 模型进行打分，VT-GRPO 的奖励也依赖自动指标，而数据策展质量直接影响训练上限；论文未讨论在无 API 或低资源环境下的替代方案。
- **VTMod 的通用性存疑**：门控初始化为近零的设计虽然保护了预训练表征，但也可能造成训练早期梯度极小、收敛缓慢；在更长训练轮次下是否会超过普通微调尚不清楚；仅单一注入层也意味着不同视觉任务之间难以共享该模块。
- **评估指标偏差**：CIDEr 等 NLG 指标与人类判断的相关性有限，尤其在指令这种“空间正确性 > 词汇丰富度”的生成任务中；SR 提升虽然显著，但只针对单一跟随者骨干，对更强或更弱的跟随者是否依然成立未验证。

## 8. 对未来工作的启示

- **无监督关键帧选择**：当前的 DPC 属于启发式几何打分，可进一步训练一个可微的“帧重要性预测器”，与 LLM 联合优化，实现端到端的轨迹压缩。
- **多模态融合的视频级建模**：既然连续环境带来了时间冗余，将 VTInstructor 扩展到短视频片段（而非离散关键帧）的时空编码器，可能让模型更自然地理解动作连贯性，而无需显式的轨迹渲染。
- **跨领域泛化**：把 VTP 思路应用到真实机器人平台（如带里程计和深度相机的移动机器人），利用其自身轨迹采样生成指令，构成“探索-描述”闭环数据引擎。
- **更强的 RL 奖励设计**：将“跟随者是否成功到达”作为真实反馈信号引入 RL，替代或补充 NLG 指标，让指令生成与导航效用直接对齐。

## 9. 总体评价

VTInstructor 的贡献是清晰且重要的：它首次将 VLN 指令生成从离散图设置推进到连续第一视角视频设置，并且通过“显式轨迹渲染”这一朴素却有效的思想绕开了大模型缺乏细粒度空间推理的瓶颈。技术上四个组件（EDTC、VTP、VTMod、VT-GRPO）各司其职、易于复现；实验层面横跨 NLG 质量、导航效用、数据增强和真实世界迁移，证据链完整。虽然在关键帧选择策略、真实传感器鲁棒性和下游评估多样性上仍有改进空间，但作为该方向的开创性工作，其方法论框架对后续研究具有很强的启发和示范价值。
