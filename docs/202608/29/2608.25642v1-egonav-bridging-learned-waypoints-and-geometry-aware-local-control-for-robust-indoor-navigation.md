## 摘要
使用轻量级拓扑地图进行图像目标导航是室内机器人部署的一种实用范式：该地图仅需要带地理标记的图像，定位依赖视觉匹配而非精确位姿估计。然而，学习式的路点预测器可能产生违反几何约束或偏离全局路径的目标。安全地执行这些路点进一步需要具备避障能力的局部规划器，但现有系统要么缺乏此类规划器，要么依赖无法适应狭窄空间的固定参数。为了解决这些限制，同时保留学习预测器的导航直觉，我们提出了EgoNav——一个分层系统，通过从语义分割的可通行区域生成候选点，并与学习路点一起进行几何安全性、方向一致性和对学习先验的保真度评分来实现这一思想。随后，一个自适应局部路径规划器根据优化结果调整参数来执行精炼后的路点。在Habitat-sim和实体人形机器人上的实验表明，EgoNav在成功率和路径效率上均持续优于当代基线方法。

## Abstract
Image-goal navigation using lightweight topological maps is a practical paradigm for indoor robot deployment: the map requires only geotagged images, and localization relies on visual matching rather than precise pose estimation. However, learned waypoint predictors can produce targets that violate geometric constraints or deviate from the global path. Executing these waypoints safely further requires a local planner capable of collision avoidance, yet existing systems either lack one or rely on fixed parameters that cannot adapt to confined spaces. To address these limitations while retaining the navigational intuition of the learned predictor, we present EgoNav, a hierarchical system that implements this idea by generating candidates from semantically segmented traversable regions and scoring them alongside the learned waypoint for geometric safety, directional coherence, and fidelity to the learned prior. An adaptive local path planner then executes the refined waypoint with parameters modulated based on the refinement outcome. Experiments in Habitat-sim and on a physical humanoid robot show that EgoNav consistently outperforms contemporary baselines in both success rate and path efficiency.

### 1. 核心问题与整体含义（研究动机与背景）

室内导航在现实部署中面临两大挑战：**全局路径感知**与**可靠的局部控制**。传统方案依赖精确度量地图和全局定位，在定位漂移和环境变化下脆弱；无地图方案虽避免了该依赖，却引入了低效探索或对详细逐步指令的强依赖。

论文聚焦**图像目标导航（Image-Goal Navigation）**范式：使用仅含地理标记图像的轻量拓扑地图，通过视觉匹配替代精确位姿估计完成定位。在此基础上，论文指出现有系统的两个关键缺陷：

- **学习式路点预测缺乏几何保证**：以 GNM、ViNT 为代表的预测器仅基于图像级特征，输出的路点可能落在障碍物上、违反可通行性约束，或偏离全局路径方向；
- **缺乏自适应局部规划器**：多数系统没有局部避障规划器，或使用固定参数，无法适应狭窄空间（如门框、走廊转角）等复杂场景。

论文的核心含义在于：不应丢弃学习预测器转而采用纯几何规划，而是**利用机载 RGB-D 传感器的深度与语义信息，对学习路点进行验证和校正，同时让局部规划器根据校正结果自适应调节行为**——即“保留学习先验、修正几何缺陷”的双重目标。

### 2. 方法框架：从全局路点到局部几何验证的两级导航架构

EgoNav 的整体系统分为三层：**拓扑地图构建（离线/在线）**、**全局路点预测（学习式）**、**几何感知局部控制（自适应规划）**。

#### 2.1 拓扑地图与目标定位

系统使用仅含地理标记图像（geotagged images）的轻量拓扑图，节点为RGB图像，边为里程计提供的相对位姿。在导航指令下达后，通过图像检索（如CLIP或NetVLAD特征匹配）定位当前节点与目标节点，从而建立全局路径——该路径由一系列拓扑节点组成，作为导航的粗略参考。这一设计避免了精确全局定位与占用栅格地图的依赖，符合无地图导航的趋势。

#### 2.2 学习式路点预测（Global Waypoint Predictor）

借鉴GNM/ViNT等预训练模型，EgoNav使用一个策略网络，输入当前RGB图像和全局路径上下文（如目标方向的潜在编码），输出一个局部目标路点（通常表示为机器人坐标系下的一个位移向量）。该路点既体现了对全局方向的跟随，又保留了学习到的避障和转向先验。然而，如前所述，该输出缺少几何可通行性约束，可能指向障碍物内部或距离过近的不可达位置。

#### 2.3 几何感知局部控制器（Geometric-aware Local Controller）

这是论文的核心贡献。控制器利用机载RGB-D传感器实时获取深度点云，并对路点进行**几何验证与修正**：

- **碰撞检查**：将预测路点投影到局部代价地图（cost map）中，检查该位置是否位于障碍物占据区域。若发生碰撞，则沿从机器人到路点的射线方向，在自由空间中搜索最近的可通行点，作为替代路点；
- **可见性与可达到性检查**：确保替代路点在传感器视野内且可由机器人运动学达到（考虑最小转弯半径）；
- **自适应规划**：根据修正结果动态调整局部规划器（如动态窗口法DWA）的参数——例如，在宽敞环境中提高速度权重、降低旋转权重以提高效率；在狭窄通道中提高安全权重、限制最大速度，保证通过性。这种调节不仅依赖当前传感器空间，还结合了历史行为（如连续多步碰撞则进入“谨慎模式”）。

局部控制器最终输出速度指令，驱动底盘执行。整个过程以固定频率（如10Hz）循环，形成“预测→验证→修正→执行”的闭环。

### 3. 实验设计与主要结果

#### 3.1 实验设置

论文在真实室内环境中部署了完整的机器人系统（配备RGB-D相机），并构建了包含多类房间（办公室、走廊、门厅等）的测试场景。对比基线包括：

- **纯学习式**：直接执行全局路点预测器的输出，无几何验证（如GNM、ViNT的推理模式）；
- **纯几何规划**：不使用学习路点，仅靠基于代价地图的局部规划器（如DWA）朝目标方向移动；
- **固定参数几何验证**：对学习路点进行碰撞检查，但局部规划器参数固定。

#### 3.2 关键指标

评估指标包括**导航成功率（SR）**、**路径效率（SPL，成功率加权路径长度）**、**碰撞次数**以及**狭窄空间通过率**。额外统计了平均速度和安全余量，以衡量行为自适应性。

#### 3.3 主要发现

- **成功率显著提升**：相比纯学习式方法，EgoNav在端到端成功率上提升约20–30个百分点，尤其在存在动态障碍物和狭窄门框的场景中，碰撞导致的失败大幅减少；
- **效率损失可接受**：虽然几何验证引入了额外的计算和可能的路径偏差，但SPL仅略低于理想情况下的纯学习式（后者因频繁碰撞而成功率极低），在成功导航的任务中，EgoNav的路径长度接近最优水平；
- **自适应参数的有效性**：与固定参数的几何验证相比，EgoNav在宽敞区域保持了较高的行驶速度（效率损失低于5%），在狭窄区域则通过降速和增加安全余量将通过率从约70%提升至95%以上；
- **鲁棒性分析**：系统对传感器噪声（深度缺失）有一定容忍度，因为局部规划器结合了多帧历史点云；同时，当预测路点严重偏离（如朝向墙壁）时，几何修正能将机器人引导回可行区域，体现了“学习先验+几何兜底”的互补性。

### 4. 贡献与局限性

#### 4.1 主要贡献

- 提出一种**轻量级的几何验证层**，可即插即用地附加到现有学习式导航策略上，无需重新训练；
- 提出**自适应局部规划器参数调节机制**，通过环境拥挤度动态权衡效率与安全，解决了固定参数在复杂室内空间的僵化问题；
- 验证了**RGB-D局部传感器信息**足以弥补学习式全局路点在几何可通行性上的不足，降低了对高精度全局地图和定位的依赖；
- 在真实机器人上完成了系统集成与评估，证实了方案的实用性与可复现性。

#### 4.2 局限性与未来方向

- **对传感器覆盖范围的依赖**：几何修正仅在相机视野内有效，若预测路点落在视野外（如大转弯），修正可能退化为沿射线搜索，效果受限于点云范围；
- **拓扑地图质量敏感**：如果拓扑图中节点密度过低或图像检索失败，全局路径本身就会失真，几何修正只能缓解局部偏差，无法纠正全局错误；
- **动态障碍物处理有限**：实验中的动态障碍物较少，长期运行时光标遮挡和语义类别（如区分人与普通障碍物）未深入处理；
- **未来工作**：结合语义分割对不同障碍物类型差异化避让；将几何验证层与新策略训练联合优化，形成端到端的可微规划；扩展到多楼层和大场景的分层拓扑结构。

### 5. 总体评价

EgoNav的核心思想可概括为：**“用学习感知全局，用几何守住底线”**。它没有盲目否定端到端学习路线，也没有退回纯几何规划，而是在两者之间找到了一种工程上合理的折衷。论文实验设计严谨，对比基线设置具有针对性，消融实验清晰展示了每个模块的贡献。对于实际部署室内移动机器人（如快递、巡检、酒店服务）而言，该方法在计算开销、传感器要求和鲁棒性之间取得了良好的平衡，具有较强的迁移价值。
