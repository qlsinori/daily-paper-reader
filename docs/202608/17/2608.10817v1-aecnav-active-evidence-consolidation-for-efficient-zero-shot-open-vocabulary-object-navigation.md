## 摘要
开放词汇场景下的零样本目标导航（ZSON）具有挑战性，因为它要求机器人在未经任务特定训练的情况下，在未知环境中定位任意指定的物体。目前，由于冗余的感知流程和缺乏用于可靠目标确认的充分证据，该任务仍面临高延迟和精度受限的问题。在本信中，我们将ZSON重新构建为证据驱动的感知到决策问题，并提出了AECNav，一种基于三个组件的免训练流程：i) 证据门控感知，它利用所有推理阶段共享的编码来建立统一的语义基础并消除冗余计算；ii) 证据整合，它将检测结果聚合为聚类级别的对数几率置信度。这明确区分了真实目标支持与视觉相似干扰物的虚假置信度，同时将预期检测的缺失视为负面证据；iii) 主动证据获取，它通过选择以最小遍历成本最大化信息增益的前沿，在弱语义线索下维持有效的探索。因此，AECNav显著优于先前方法，在HM3D-v2、HM3D-OVON和MP3D上分别达到了84.7%、57.3%和51.3%的最新成功率，且推理开销大幅降低，并在物理四足机器人上以约5Hz的频率在40次试验中实现了95%的成功率。代码将在接收后公开发布。

## Abstract
Zero-shot object-goal navigation (ZSON) in open-vocabulary scenarios is challenging, as it requires a robot to locate an arbitrarily specified object in an unseen environment without task-specific training. Currently, the task still suffers from high latency and limited accuracy due to redundant perception pipelines and insufficient evidence for reliable target confirmation. In this letter, we reframe ZSON as an evidence-driven perception-to-decision problem and present AECNav, a training-free pipeline built on three components: i) Evidence-gated perception, which utilizes a shared encoding across all reasoning stages to establish a unified semantic basis and eliminate redundant computations; ii) Evidence consolidation, which aggregates detections into cluster-level log-odds beliefs. This explicitly separates genuine target support from the false confidence of visually similar distractors, while treating the absence of expected detections as negative evidence; and iii) Active evidence acquisition, which sustains productive exploration under weak semantic cues by selecting frontiers that maximize information gain at minimal traversal cost. As a result, AECNav significantly outperforms previous methods and achieves state-of-the-art success rates of 84.7%, 57.3%, and 51.3% on HM3D-v2, HM3D-OVON, and MP3D, respectively, with substantially lower inference overhead, and attains 95% success across 40 trials on a physical quadruped robot at roughly 5Hz. Code will be made publicly available upon acceptance.

## 1. 论文的核心问题与整体含义

零样本目标导航（Zero-Shot Object-Goal Navigation, ZSON）要求机器人在未知环境中定位任意指定的物体，且不依赖目标任务或场景布局的训练。在开放词汇（open-vocabulary）场景下，该任务面临三个关键瓶颈：

- **感知冗余度高**：现有方法往往为前沿选择和目标确认分别使用不同的视觉编码管道（如 CLIP + GroundingDINO + MobileSAM），导致每次观测被多个模型重复处理，推理延迟显著。
- **目标确认证据不足**：高置信度得分可能来自真实目标、视觉相似的干扰物或瞬时误检，现有方法难以可靠区分。多数方案采用单帧阈值式判断，缺乏时间维度的证据积累。
- **探索效率不高**：前沿选择大多依赖语义相关性或几何启发式，未显式建模"到达某前沿所获得信息量 vs. 通行成本"的权衡，在弱语义线索下容易低效徘徊。

论文将 ZSON 重构为**证据驱动的感知到决策（evidence-driven perception-to-decision）问题**，提出 AECNav（Active Evidence Consolidation Navigation），将感知、目标确认与探索统一在证据获取与积累的框架内，在无需训练的前提下同时提升导航精度与实时性。

## 2. 方法论：核心思想、关键技术细节与算法流程

AECNav 是一个免训练流水线，由三个紧密耦合的组件构成。整体流程为：感知模块输出语义线索 → 证据整合模块维护目标置信度 → 当证据不足时，主动获取模块选择最优前沿继续探索 → 循环直至目标簇被确认并接近停止。

### 2.1 证据门控感知（Evidence-Gated Perception）

- 使用**单一 C-RADIOv4 编码器** E 对图像进行一次前向传播，同时获得 summary token 与 patch tokens：
  \[
  (z^{\text{sum}}_t, z^{\text{patch}}_t) = E(I_t)
  \]
- 目标类别文本经 SigLIP2 文本编码器编码后**缓存**，整集只计算一次。
- **场景级相关性**：summary token 经适配器与目标文本嵌入的余弦相似度生成 \(\sigma^{\text{scene}}_t\)，结合深度与位姿投影为俯视价值图 \(V_t\)，作为探索的持久空间先验。
- **局部目标感知**：patch tokens 的最大相似度 \(\sigma^{\text{patch}}_t\) 作为局部目标指示信号。
- **证据门控**：仅当 \(\sigma^{\text{patch}}_t > \tau_{\text{gate}}\) 时，才将已提取的共享特征路由至 SAM3 分割解码器，无需重新编码图像。该方法可跳过约 60% 以上的 SAM3 调用，将单步延迟降低约 30%。

### 2.2 证据整合（Evidence Consolidation）

- 将检测到的实例通过深度反投影到 3D 点云，按几何距离（关联半径 0.75 m）融合到最近簇或创建新簇。
- 每个簇 \(C_k\) 维护一个对数几率置信度（log-odds belief）：
  \[
  l(C_k) = \log \frac{P(C_k = g)}{1 - P(C_k = g)}
  \]
  正值支持目标假设，负值拒绝目标。
- 更新公式：
  \[
  l(C_k) \leftarrow l(C_k) + \Delta l_{\text{sem}}(C_k) + \Delta l_{\text{miss}}(C_k)
  \]
  值被钳制在 \([l_{\min}, l_{\max}] = [-4, 4]\) 内防止饱和。
- **语义证据（\(\Delta l_{\text{sem}}\)）**：由 LLM（DeepSeek-V4-Flash）**离线生成最多三个干扰物类别**，SAM3 同时提示目标与干扰物类别，得到目标得分 \(s_g\) 与最高干扰物得分 \(s_{\text{conf}}\)。按占优关系进行正更新、负更新或保持不变（模糊情形不更新）：
  - 目标分明显高于干扰物分 → 增强目标假设（+）；
  - 干扰物分明显高于目标分 → 主动抑制该簇（−）；
  - 两者接近（margin \(\delta = 0.10\)）→ 不更新。
- **缺失证据（\(\Delta l_{\text{miss}}\)）**：若某正置信簇在相机视野内但未被检测到，该缺失构成负证据。按可见度比例 \(v_k\) 进行衰减：
  \[
  \Delta l_{\text{miss}}(C_k) = -\alpha_{\text{miss}} v_k \logit(1 - s_{\text{miss}})
  \]
  这使得误检造成的虚假置信可随时间被纠正、释放探索。
- **停止条件**：簇置信度超过 \(\tau_{\text{stop}} = 1.0\) 且在 5 帧中至少 2 帧保持，且机器人距簇小于 0.5 m 时停止。需要时间稳定性和空间接近同时满足，避免对瞬时高置信的过早承诺。

### 2.3 主动证据获取（Active Evidence Acquisition）

当证据不足时，AECNav 将探索视为主动证据收集过程，选择最大化复合效用值的前沿：
\[
U_t(f; g) = \tilde{S}_t(f; g) + \lambda_{\text{info}} \tilde{G}_t(f) - \lambda_{\text{dist}} \tilde{C}_t(f)
\]
其中 \(\tilde{(\cdot)}\) 表示 min-max 归一化。

- **语义相关性 \(S_t\)**：聚合各前沿附近价值图中的目标相关值（同 VLFM），指导机器人趋向可能含目标的区域。
- **信息增益 \(G_t\)**：对 BFS 求得的可通行路径采样视点，沿路径进行射线投射（5° 步长、5.0 m 范围），统计未知单元的可视数量。路径中途的可见信息也被计入。
- **通行成本 \(C_t\)**：路径长度。
- 默认权重 \(\lambda_{\text{info}} = 1.0\)、\(\lambda_{\text{dist}} = 1.0\)，跨数据集保持统一，避免过拟合单一基准。

## 6. 主要结论与发现

1. **精度 SOTA**：HM3D-v2 上 SR 84.7%、SPL 45.3%，比此前最佳 TrajRAG 高出 6.6% SR；MP3D 上 SR 51.3%（超 WMNav 5.9%），且 SPL 大幅领先 8.7%；HM3D-OVON 上 SR 57.3%，超 MSGNav 9.0%。
2. **效率显著提升**：单 episode 端到端时间 24.39 s，为 VLFM 的 1/2.2；所需步数 108.63，比第二优 ASCENT 少 33%。
3. **共享语义基础是关键**：用统一 C-RADIOv4 编码取代多模型管道，SR 提升 8.8%，延迟降低 1.6 倍，说明各推理阶段共享同一视觉表示既可提精度又省算力。
4. **证据累积的价值大于任何单一证据类型**：仅使用目标证据累积已可从 71.9% 提升至 81.9%；干扰物负证据贡献 +1.8%，缺失检测负证据贡献 +1.3%，两者近似可加，说明它们修复的是互补类型的错误。
5. **信息增益必须与通行成本搭配使用**：单独使用信息增益几乎无收益（81.9% vs. 81.8%），因为无成本约束时，机器人会被大开阔空间吸引而远离语义相关区域。
6. **真实世界可行性**：40 次实物试验 95% 成功，以约 5 Hz 频率运行，验证了方法的实际部署价值。

## 7. 优点

- **问题重构具有清晰洞察**：将 ZSON 统一为证据获取 → 积累

将 ZSON 统一为证据获取 → 积累 → 整合 → 主动获取的闭环，使感知、记忆与规划在同一证据框架下协同，而非将各模块简单拼接，这一视角比单纯堆叠新组件更具方法论价值。

- **单一编码器的设计极具工程与学术双重优势**：C-RADIOv4 的 summary token 与 patch token 同时服务场景级先验与局部目标感知，门控机制按需调用 SAM3，在精度提升的同时显著降低延迟，验证了"共享语义表示"在机器人导航任务中的普适价值。
- **证据机制设计精巧、互补且可解释**：目标正证据、干扰物负证据与缺失负证据分别针对"漏检确认""视觉混淆"与"瞬时误检"三类典型错误，Log-odds 框架天然支持正负证据的叠加与衰减，且各证据分量可独立剥离验证，科学性与工程性兼顾。
- **免训练特性使方法具有突出的可复现性与低成本可部署性**：无需训练数据、无需微调，单张 RTX 4090 即可运行，且跨数据集沿用统一超参数，避免了为刷榜而逐数据集调整权重之嫌。
- **实验规范、深入且诚实**：从多 benchmark 横向对比、效率剖析、门控阈值扫描、多层级消融到真实机器人部署，层层递进；对负结果（如无效信息增益、模糊证据不更新）也如实报告并给出解释，可信度高。

- **消融实验范围偏窄**：所有组件消融仅在 HM3D-v2（6 类目标）上进行，未在目标类别更多、干扰更稠密的 HM3D-OVON（49 类）或 MP3D 上验证各证据类型的有效性，结论的泛化性略有折扣。
- **对 LLM 的依赖未充分讨论**：干扰物类别由 DeepSeek-V4-Flash 离线生成，若目标类别来自长尾或专业领域，LLM 生成的干扰物质量可能不稳定；论文未评估 LLM 生成的失败案例或替代方案（如基于词嵌入相似度的启发式）。
- **真实实验的对照不足**：真实世界仅评估了 AECNav 自身的成功率（95%），未在相同硬件与场景下部署任一基线方法进行实物对比，难以从实物数据中直接得出"优于其他方法"的结论。
- **缺少数值细节与失败模态分析**：未报告成功率之外的真实实验细节（如失败 2 次的具体原因、是否因证据误导或机械问题）；对 5 帧中 2 帧稳定、0.75 m 聚合半径、\(\tau_{\text{stop}}=1.0\) 等关键超参数缺乏敏感性分析，其鲁棒性有待检验。
- **探索权重统一性的解释充分但缺乏自适应机制**：作者用"大开阔空间信息增益高但对导航无益"解释了单一权重有效的现象，但未尝试基于场景拓扑自动调节 \(\lambda_{\text{info}}\)，在更空旷或更封闭的未知环境中固定权重是否仍然成立，仍属开放问题。
- **与 VLFM 的承继关系需更明确**：AECNav 的价值图构建、前沿聚合等模块明显承继自 VLFM，论文在叙述上侧重于自身创新，但对增量贡献的边界（哪些来自 VLFM 基础、哪些为本方法新增）交代得不够显式，可能影响对创新量的评估。

## 9. 总体评价

AECNav 是一篇方法清晰、实验扎实、写作规范的免训练零样本目标导航工作。其核心贡献不在于提出新的神经网络结构，而在于**以证据累积为统一主线重构了"感知—记忆—探索"三阶段的交互逻辑**：用单一编码器解决感知冗余，用 log-odds 证据机制解决目标确认的可信度问题，用"信息增益 − 通行成本"的复合效用解决探索决策的短视问题。三者在消融中均被验证有正贡献，且整体在 HM3D-v2 / MP3D / HM3D-OVON 三个基准上达到 SOTA，同时将推理延迟大幅压缩，并完成了 40 次真实场景试验，体现出较强的工程完成度。

在学术贡献上，本文最重要的启示是：**在开放词汇导航中，"什么时候停止并确认目标"与"往哪里走"同等重要，而两者可以统一到一个证据获取的框架下**。这种将视觉识别中的证据积累思想迁移到具身导航决策中的做法，为后续工作提供了可扩展的范式。同时，免训练的设定使得该方法可以便捷地与任何更强大的视觉基础模型或大模型组合，具有清晰的演进路径。

当然，该方法在资源报告、基线数值澄清、消融覆盖范围、真实对照等方面仍有提升空间。瑕不掩瑜，作为一篇面向零样本目标导航的系统性解决方案，AECNav 在精度、效率和可解释性之间取得了良好的平衡，具备较强的启发意义与应用潜力。

---

**一句话总结**：AECNav 用"证据获取与累积"统一了零样本目标导航的感知、确认与探索，以单一编码器 + Log-odds 证据整合 + 主动信息采集在三大基准和真实机器人上同时实现了 SOTA 精度与显著效率提升，是免训练范式下目标导航的有力代表。
