## 摘要
多模态终身导航要求智能体在自主探索未知环境的同时，顺序完成由目标类别、语言描述或参考图像指定的导航任务。现有方法主要通过构建以状态为中心的语义场景图来完成这些任务。通过将场景图视为语义观测的持久化存储库，这些方法难以区分相似实例、联合表示语义目标与探索前沿，并且无法有效利用导航记忆和轨迹经验。为解决这些局限性，我们提出时空事件图导航（STEGNav），一种无需训练的框架，沿互补的空间与时间轴将传统场景图扩展为时空事件图。空间轴执行查询条件驱动的实例定位，并联合表示语义目标与具有可达性、路径代价和探索效用的占用感知探索前沿。时间轴采用轨迹感知的双窗口记忆，以保留近期决策-轨迹事件以及经过验证的跨子任务导航结果。基于VLM的导航智能体对生成的时空事件图进行推理，并选择目标实例或探索前沿作为下一导航目标。STEGNav在GOAT-Bench上取得66.3%的SR和39.7的SPL，在HM3Dv1和HM3Dv2上分别取得64.0%和69.4%的SR分数。消融实验与错误分析验证了两个轴的互补效应，表明事件驱动的时空表示能提高导航可靠性并促进跨子任务经验复用。

## Abstract
Multimodal lifelong navigation requires an agent to autonomously explore unseen environments while sequentially completing navigation tasks specified by object categories, language descriptions, or reference images. Existing methods primarily accomplish these tasks by constructing state-centric semantic scene graphs. By treating scene graphs as persistent repositories of semantic observations, these methods struggle to distinguish similar instances, jointly represent semantic targets and exploration frontiers, and effectively exploit navigation memory and trajectory experience. To address these limitations, we propose Spatio-Temporal Event Graph Navigation (STEGNav), a training-free framework that extends conventional scene graphs into spatio-temporal event graphs along complementary spatial and temporal axes. The spatial axis performs query-conditioned instance grounding and jointly represents semantic targets and occupancy-aware exploration frontiers characterized by reachability, path cost, and exploration utility. The temporal axis employs trajectory-aware dual-window memory to retain recent decision--trajectory events and verified cross-subtask navigation outcomes. A VLM-based navigation agent reasons over the resulting spatio-temporal event graph and selects either a target instance or an exploration frontier as its next navigation goal. STEGNav achieves 66.3% SR and 39.7 SPL on GOAT-Bench, as well as SR scores of 64.0% and 69.4% on HM3Dv1 and HM3Dv2, respectively. Ablation studies and error analyses validate the complementary effects of the two axes, demonstrating that event-driven spatio-temporal representations improve navigation reliability and cross-subtask experience reuse.

**论文背景与动机：**

- 具身导航正从单目标的零样本搜索，逐步演化为多模态终身导航（Multimodal Lifelong Navigation）——智能体需要在一个未知环境中连续完成多个子任务，每个任务的目标分别由物体类别（object）、自然语言描述（language）或参考图片（image）指定。
- 现有方法（如 MTU3D、MSGNav 等）主要以"以状态为中心"的语义场景图（state-centric scene graph）来组织环境信息。这些方法将场景图视为持久化的静态语义观测仓库，在终身导航中存在三大关键缺陷：
  1. **实例歧义（Instance Ambiguity）**：仅按类别过滤节点，无法区分同类别下的不同物理实例，容易导致语言/图片查询定位到错误的物体。
  2. **语义-空间分离（Semantic-Spatial Separation）**：场景图（语义层）与占用图衍生的探索前沿（空间层）被分别提供给 VLM，导致策略无法联合推理目标身份、可达性和探索效用。
  3. **缺乏历史轨迹利用（Memory Loss & Repeated Exploration）**：场景图只记录当前环境状态，不记录"智能体如何到达当前状态"以及"过去哪些决策成功或失败"，造成重复探索和跨子任务经验无法复用。

**整体含义：**

- 论文提出 **STEGNav（Spatio-Temporal Event Graph Navigation）**，主张多模态终身导航在本质上是"事件驱动"的——每次导航决策既改变了智能体的空间知识，也改变了可供未来导航使用的历史经验。因此，论文将静态场景图扩展为**时空事件图**（spatio-temporal event graph），沿空间和时间两个互补的轴对场景进行事件级建模，从而提升导航的可靠性与跨子任务经验复用能力。

## 2. 论文提出的方法论

**核心思想：**

STEGNav 是一个**无需训练（training-free）**的框架，通过以下两个轴将普通场景图转化为事件图：

- **空间轴（Spatial Axis）**：构建查询条件下的语义-导航双层图（semantic–navigational graph），同时表示语义目标实例、探索前沿、可达性、路径代价与探索效用。
- **时间轴（Temporal Axis）**：维护轨迹感知双窗口记忆（trajectory-aware dual-window memory），短期窗口记录近期决策与轨迹事件，长期窗口保存经 VLM 验证过的最佳跨子任务导航结果。

**关键技术与流程（文字说明）：**

1. **查询条件实例接地（Query-Conditioned Instance Grounding）**：
   - 先用类别预过滤器（VLM prefilter）保留与目标类别相关的场景节点；
   - 再用 VLM 接地模块 Φ_inst 对每个保留节点，基于查询、视觉特征与空间语境输出"查询-实例相关性得分 r(i) 和查询条件化描述 d(i)"；
   - 对图像查询评估参考图与存储实例外观的对应关系，对语言查询将属性描述匹配到实例外观/房间/空间语境，对类别级目标不做实例级裁剪；
   - 只保留 top-N 相关实例，并构造查询-实例边，避免暴露全部节点。

2. **占用感知前沿接地（Occupancy-Aware Frontier Grounding）**：
   - 将占用图上边界单元聚类为前沿区域，每个前沿存储空间中心、可达路径距离、探索增益与最近访问状态；
   - 将可达前沿连接到同一可通行区域内的附近语义节点，形成"前沿-语义边"；
   - 占用图同时建立从当前智能体节点到物体节点和前沿节点的导航边，记录可达性与测地路径代价——最终使物体节点和探索前沿在**同一图结构中**呈现，VLM 不再把两者作为单独输入。

3. **时间轴双窗口记忆**：
   - **短期决策-轨迹窗口（W_st = 20）**：在高水平决策执行后记录所选节点、轨迹段（起点/终点、经过的节点、覆盖区域）、路径长度和执行结果；轨迹被投影回当前空间图，以更新前沿访问状态并暴露重复路径；子任务结束即清空。
   - **长期任务事件窗口（W_lt = 8）**：仅保存通过 VLM 正验证的结果。验证条件 w_k = ⟦ i_term = i* ∧ o_k = + ∧ d_k ≤ δ ⟧（δ = 0.8m，不使用仿真器真值）；保存事件锚点（实例 ID、类别、查询模态、历史查询、终端外观特征、房间标签），不含固定坐标。
   - 锚点通过持久标识符或 CLIP 外观相似度（γ_hi = 0.92，γ_lo = 0.70）重新关联当前场景图，歧义情况由轻量级 VLM 验证器解决。

4. **事件图导航决策**：
   - 将空间图、短期事件、长期锚点序列化为统一的事件图 H_{k,t} = (V_H, E_H)；
   - 导航 VLM 直接输出**一个物体节点**或**一个探索前沿节点**作为下一目标；
   - 若选物体则导航至其中心，若选前沿则沿占用图路径执行；执行结果回写短期窗口；
   - 整个流程循环执行直到成功或步数耗尽，并在子任务结束时清空短期窗口、更新长期窗口。

- 场景节点表示：每个节点包含持久 ID、语义类别、3D 包围盒、房间标签、聚合外观特征和代表性 RGB 裁剪。

## 6. 论文的主要结论与发现

- **GOAT-Bench 上最优**：SR = 66.3%、SPL = 39.7。相比最强 SR 基线 MSGNav 提升 3.9%；相比同时报告两指标的最强基线 EvoMemNav，SR/SPL 分别提升 6.7/0.8。
- **HM3D 上显著提升 SR**：HM3Dv1 SR = 64.0%（+3.8%），HM3Dv2 SR = 69.4%（+5.6%），验证了事件图表示从多模态终身导航到类别级 ObjectNav 的泛化能力。
- **空间轴的核心价值（OFG 增益最大）**：加入占用感知前沿接地后，总 SR/SPL 提升 7.5/4.9，图像查询 SR/SPL 提升 10.2/5.8——说明将语义目标与可达性、探索效用统一到同一图是对成功率提升最关键的组件。
- **时间轴的核心价值（DWM）**：双窗口记忆将 image 查询 SR 从 68.2% 提升到 73.9%，证明近期轨迹与已验证的跨子任务事件能有效支持实例级导航。
- **两轴互补**：完整模型相比纯 3D 场景图变体 SR/SPL 提升 15.1/9.3，消融确认 QIG、OFG、DWM 三者各自独立贡献且相互补充。
- **错误分析**：STEGNav 将总失败数从 123 降至 81（−34.1%），其中实例混淆减少 53.8%（13→6），低效探索减少 40.0%（45→27），记忆回忆失败、目标接地失败也均有下降；但低层执行/停止类错误改善有限（18→14），表明低层控制仍有提升空间。

## 7. 优点

- **事件驱动的视角创新**：明确指出现有"状态中心"场景图的缺陷，提出"事件中心"的时空事件图范式，思路清晰且问题定义准确。
- **无需训练**：完全基于预训练检测器（YOLOv8-World + SAM + CLIP）和 VLM（gpt-5.4-mini），不需要任何微调或强化学习，部署成本低。

- **验证机制重视真实性**：长期记忆的写入不依赖模拟器真值，而是基于 VLM 对终端观测的验证和距离阈值，更接近实际部署场景。

## 9. 总体评价与适用场景

**总体定位：**

STEGNav 是一篇定义清晰、工程完成度高且实验扎实的免训练导航框架论文。它的核心贡献不在于提出一个新的学习算法，而在于给出了一种**重新组织环境与历史信息的方式**——将“状态中心”的场景图改造为“事件中心”的时空事件图，使 VLM 能够在同一图结构上联合推理“目标是什么、在哪里、是否可达、值不值得去、以前去过没有”。这种思路在模块化导航范式中具有较强的通用性和迁移价值。

**与同类工作的相对位置：**

- 相比 MSGNav，STEGNav 在 SR 上实现了 3.9 个百分点的提升，且不依赖模拟器真值写入长期记忆，方法论上更接近真实部署约束；
- 相比 EvoMemNav，两者都强调跨 episode 记忆，但 STEGNav 将记忆从纯文本摘要升级为可重关联的事件锚点，并显式接入空间图，从而在 image 类查询上优势明显；
- 相比 MTU3D 等以场景图为核心的方法，STEGNav 的创新点在于补上了“探索前沿”与“历史轨迹”两块被长期忽略的拼图，使场景图从“静态语义仓库”升级为“动态决策画布”。

**适用场景：**

1. 需要快速部署、但不能/不想训练导航策略的机器人平台（低成本、无 GPU 训练资源）；
2. 查询模态经常切换、且子任务目标之间存在空间关联的室内终身导航（如“去厨房拿之前见过的蓝色杯子，再找主人”）；
3. 作为更复杂导航系统的**高层决策模块**，底层可替换为任何经典规划器或控制器；
4. 研究“VLM 如何理解结构化空间记忆”的学术 benchmark，其事件图序列化格式可作为后续工作的参照。

**最终结论一句话概括：**

> STEGNav 通过空间轴（语义-导航双层图）与时间轴（双窗口记忆）的统一事件图表示，以完全免训练的方式在 GOAT-Bench 上取得了当前最优 SR（66.3%），并显著降低了实例混淆与重复探索，是模块化多模态终身导航中一个简洁、有效且可复现的新范式。
