## 摘要
我们提出了一种面向无人机（UAV）的实时语义导航框架，旨在提高目标目标导航（ObjectNav）任务的时间效率。我们方法的核心是一个大语言模型（LLM），它解释用户提供的自然语言指令，并基于检测到的物体和空间上下文进行语义推理，以优先考虑高概率搜索区域。该系统结合了实时目标检测、3D空间映射以及多项式样条插值，以实现平滑且可行的无人机轨迹规划。与依赖离线推理或受模拟器约束的动作空间的先前方法不同，我们的框架可以实时运行，根据新的观测结果不断更新语义相关性。在模拟和真实环境中的实验表明，在保持高搜索精度的同时，任务持续时间有所减少，这凸显了LLM引导推理在实现基于无人机的高效时间ObjectNav中的有效性。

## Abstract
We present a real-time semantic navigation framework for Unmanned Aerial Vehicles (UAVs) focused on improving time efficiency in the Object Goal Navigation (ObjectNav) task. Central to our approach is a Large Language Model (LLM) that interprets user-provided natural language instructions and performs semantic reasoning over detected objects and spatial context to prioritize high-probability search regions. The system combines real-time object detection, 3D spatial mapping, and polynomial spline interpolation for smooth and feasible UAV trajectory planning. Unlike prior methods that rely on offline reasoning or simulator-constrained action spaces, our framework can operate in real time, continuously updating semantic relevance based on new observations. Experiments in both simulated and real-world settings demonstrate reductions in mission duration while maintaining high search accuracy, underscoring the effectiveness of LLM-guided reasoning for time- efficient UAV-based ObjectNav.

## 1. 核心问题与整体含义（研究动机与背景）

- 论文聚焦于 **无人机（UAV）的物体目标导航（ObjectNav）** 任务：在未知环境中，根据用户自然语言指令，自主搜索并定位指定语义类别的目标物体。
- 现有方法存在三个主要缺陷：
  - 严重依赖离线推理或模拟器约束的离散动作空间（如前进、转身、停止），缺乏对真实物理运动学和连续轨迹的考虑，难以迁移到实际无人机系统。
  - 许多方法依赖计算量较大的视觉语言模型（VLM），推理速度慢，不适合机载实时运行。
  - 评价指标多侧重于成功率（SR）和路径加权成功率（SPL），忽略了实际应用中更关键的因素——搜索时间、实时响应能力和动态机动性。
- 本文提出一种 **轻量级、语言驱动的实时语义导航框架**，仅用目标检测器 + 大语言模型（LLM），在机载端实现实时语义推理，指导无人机优先搜索高概率区域，从而显著缩短任务时间并保持高搜索精度。

## 2. 方法论

### 总体流程
四阶段级联架构，后端采用概率相关性推理决策，前端采用实时感知与轨迹规划：

1. **视觉感知模块**：使用 YOLO 目标检测器处理相机图像，输出二维边界框、类别和置信度。
2. **3D 空间表示与位置估计**：
   - 使用 **OctoMap** 作为体素占据地图，区分自由空间、占据空间和未知空间。
   - 通过相机内参将像素坐标转换为3D方向向量，再从无人机位姿沿该方向做 **ray casting**，找到第一个被占据的体素作为目标物体的3D位置。
   - 对不同视角下的多次检测结果使用 **DBSCAN 聚类**，合并为统一物体表示。
3. **LLM 引导的概率相关性推理（核心）**：
   - 定义概率相关性评分 P(Oᵢ|D, T)，表示物体 Oᵢ 附近存在目标 T 的可能性。
   - 通过贝叶斯公式分解为先验 P(Oᵢ|T)（物体间语义关联/共现先验）和似然 P(D|Oᵢ,T)（当前观测数据支持度），由 LLM 隐式估计。
   - 构建提示词（Prompt），包含系统角色、用户指令、检测到的物体及3D坐标、已搜索区域，并要求 LLM 输出：相关性标志、最相关物体及其坐标、推理理由。
   - 若最相关物体的评分超过阈值，则无人机飞往该物体附近进行精细搜索；否则改用兜底策略（如沿墙扫描）收集更多数据。
   - 当评分超过高阈值时，判定找到目标；若搜索完仍无果，则降低该物体相关性，重新分配概率。
4. **轨迹规划与精细搜索**：
   - 在 3D 空间中使用 **A* 搜索** 生成离散路径，避开障碍物。
   - 使用 **7 阶多项式样条插值** 生成平滑、动力学可行的连续轨迹。
   - 精细搜索采用围绕相关物体的圆形（或半圆，适应场景）轨迹，从多角度扫描以发现被遮挡的小目标。

## 3. 实验设计

- **实验平台**：Crazyflie 2.1 纳米无人机，配备 AI Deck 和单色相机；无法携带 LiDAR，因此环境预先用外部 LiDAR 和 Cartographer SLAM 建图，生成 OctoMap。真实环境使用 OptiTrack 动作捕捉系统进行定位。
- **模拟环境**：Gazebo Garden，10 × 10 m 室内场景。
- **对比基准**：传统的 **lawn mower（割草式）全覆盖扫描策略**，即均匀往返扫描整个区域。
- **测试场景**（3 个）：
  - 场景 I：**香蕉**，部分被花瓶遮挡，指令提示“在用餐区”，测试遮挡推理能力。
  - 场景 II：**电脑鼠标**，指令仅说“找不到我的鼠标”，需要基于物体共现（显示器、办公桌）推理。
  - 场景 III：**玩具斑马**，在“有详细上下文提示（睡觉/卧室）”和“无上下文”两种条件下测试，考察指令信息量对搜索的影响。
- **评测指标**：成功率（SR）、搜索时间提升（STI）、路径长度减少（PLR）。

## 6. 主要结论与发现

- LLM 引导的语义搜索比割草式基线更高效：在三个场景中，成功率均达到 **100%**，而基线分别为 65%、75%、95%。
- 搜索时间平均降低 **24.83% ~ 36.02%**，路径长度降低 **43.50% ~ 52.26%**。
- 用户提供的自然语言上下文（如“香蕉在用餐区”“玩具斑马与睡觉相关”）显著影响语义先验的质量，是实现高效搜索的关键。
- 系统能够处理部分遮挡、小目标（如鼠标）以及上下文模糊的目标，验证了实践鲁棒性。
- 轻量级目标检测器 + LLM 的组合可在不依赖 VLM 的情况下实现实时语义推理，适合轻小型 UAV 部署。

## 7. 优点

- **实时性**：不同于许多离线推理或 VLM 重负载方法，该框架仅用 LLM 做高层语义推理，推理延迟低，并且后续推理与飞行并行，不增加总时长。

- **模块化设计**：感知、映射、定位、推理、规划各模块解耦，可替换不同检测器、地图表示或 LLM。
