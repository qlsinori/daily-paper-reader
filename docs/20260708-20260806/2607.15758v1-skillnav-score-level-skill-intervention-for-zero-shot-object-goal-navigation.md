## 摘要
视觉语言模型（VLM）智能体推动了零样本目标导航的发展，然而单帧推理缺乏具身导航器所需的跨步行为感知，导致重复性失败，如死胡同停滞、室内循环以及对已检测目标的迂回接近。基于提示的补救措施会膨胀多子模块回合中的令牌预算，并且仍然难以编码本质上空间性的信号，如角度、地图单元和视点坐标。在本文中，我们提出SkillNav，一种基于VLM的导航的可扩展行为技能框架，将现代VLM导航器已经维护的好奇价值图视为可写基底，可组合技能以零令牌成本在其上铭刻行为记忆。技能根据行为权威级别分为三层，即用于比例重新加权的软缩放、用于区域级保证的下界提升以及用于阈值触发强制动作的硬覆盖，并在固定组合顺序下跨层级协作，该顺序确立了技能之间可预测的、声明的优先级。这种设计将能力改进转变为技能注册：新行为无需重新训练VLM或干扰现有技能即可插入，为持续改进开辟了道路。一个最小的提示通道通过类别级语义提示补充了分数级技能，产生了一种双表示设计，其中空间记忆驻留在地图上，语义记忆驻留在短提示中。无需训练，SkillNav在MP3D（25.5）、HM3D v0.1（39.3）和HM3D v0.2（43.2）上建立了新的最先进SPL，与最强先前方法相比SPL绝对提高达6.0，并在HM3D v0.1（69.7）和v0.2（75.9）上实现了最高成功率。

## Abstract
Vision-Language Model (VLM) agents have advanced zero-shot object-goal navigation, yet single-frame reasoning leaves them without the cross-step behavioral awareness an embodied navigator requires, producing recurring failures such as dead-end stalls, in-room loops, and circuitous approaches to detected targets. Prompt-based remedies inflate token budgets across multi-submodule episodes and still struggle to encode inherently spatial signals such as angles, map cells, and viewpoint coordinates. In this paper, we propose SkillNav, an extensible behavioral skill framework for VLM-based navigation that treats the curiosity value map already maintained by modern VLM navigators as a writable substrate on which composable skills inscribe behavioral memory at zero token cost. Skills are stratified into three tiers by their level of behavioral authority, namely soft scaling for proportional reweighting, lower-bound boost for region-level guarantees, and hard override for threshold-triggered forced actions, and cooperate across tiers under a fixed composition order that establishes a predictable, declared priority among skills. This design turns capability improvement into skill registration: new behaviors plug in without retraining the VLM or disturbing existing skills, opening a path for continual refinement. A minimal prompt channel complements the score-level skills with category-level semantic hints, yielding a dual-representation design in which spatial memory lives on the map and semantic memory in short prompts. Training-free, SkillNav establishes new state-of-the-art SPL across MP3D (25.5), HM3D v0.1 (39.3), and HM3D v0.2 (43.2), improving SPL by up to 6.0 absolute over the strongest prior method, and achieves the highest Success Rate on HM3D v0.1 (69.7) and v0.2 (75.9).

# SkillNav 论文总结

## 1. 核心问题与研究动机

- **背景**：视觉语言模型（VLM）智能体在零样本目标导航（Object-Goal Navigation, ObjectNav）任务中取得显著进展，但现有方法大多基于单帧观测进行推理，缺乏跨步骤的行为感知能力。
- **核心问题**：单帧推理导致三类典型且重复的失败：
  - 在障碍物角落卡住，反复尝试同一条失败路径；
  - 在已确认无目标的房间内低效搜索，错过更短的出口路径；
  - 目标短暂出现在视野中后，因步伐过大而丢失目标。
- **现有补救方案的缺陷**：将完整历史轨迹写入文本提示（如 ReAct、Reflexion 风格）会导致 token 成本随回合长度线性膨胀，且难以有效编码角度、地图单元、视点坐标等本质空间信号。
- **论文主张**：现代 VLM 导航器已有的“好奇心价值图”可作为可写的空间记忆载体，在零额外 token 成本下注入跨步行为记忆，从而解决上述问题。

## 2. 方法论

- **总体架构**：SkillNav 是一个无需训练（training-free）的框架，在 VLM 管线中插入一个“精炼层”（Refinement Layer），位于分数评估与动作执行之间。
- **底层管线**：多模块 VLM 管线，包括：
  - **Predict VLM**：为每个离散朝向打分，生成好奇心分数 α(θ_k)；
  - **Plan VLM**：生成子目标文本和检测标志；
  - **Goal VLM**：精确实证目标物并返回像素坐标；
  - **Action VLM**：选择具体移动动作。
- **核心创新——分数级技能干预**：将行为记忆直接写入价值地图，通过三类操作符（skill operators）修正原始方向分数：
  1. **软缩放（Soft Scaling）**：对每个方向的分数乘以系数 γ_k，并限制在软上限 α_soft 以下。用于“房间耗尽”场景，抑制已探索方向、增强未探索方向或出口方向。
  2. **下限提升（Lower-Bound Boost）**：当目标被连续两步确认后，以目标锚点为中心设置圆形区域，区域内所有地图单元分数强制提升到 α_max，确保目标位置不被遗忘。
  3. **硬覆盖（Hard Override）**：当检测到卡死或振荡等关键状态时，完全绕过分数机制，强制指定方向或清除失败方向。
- **固定组合顺序**：`Hard Override ◦ Lower-Bound Boost ◦ Soft Scaling`，即先软缩放，再下限提升，最后硬覆盖。该顺序同时满足三项稳定性属性：
  - (P1) 地板保持：下限提升后的方向不会被后续软缩放压低；
  - (P2) 覆盖主导：硬覆盖的方向保持强制值；
  - (P3) 缩放中立：无操作时分数不变。
- **可扩展性**：新行为通过声明其所属操作符家族即可注册，无需重训练 VLM，也不会干扰既有技能。
- **辅助机制——经验提示注入**：使用有界提示通道（最多 L_max 条类别级提示），在回合开始时注入类别常识（例如“椅子必须有靠背”），用于解决感知歧义问题。该通道长度固定，不随回合增长而变化。
- **双表示设计**：空间记忆（行为状态）存储在地图上，语义记忆（类别知识）存储在短提示中，二者各司其职，互补配合。

## 7. 优点

- **零额外 token 成本**：行为记忆写在地图上，避免提示膨胀问题。

- **可扩展技能框架**：技能按三层权威分类，固定组合顺序使得冲突消解可预测，新增技能无需重新设计或训练。

- **实验验证充分**：多基准、多基线、消融、分类别分析，证据链条较完整。
