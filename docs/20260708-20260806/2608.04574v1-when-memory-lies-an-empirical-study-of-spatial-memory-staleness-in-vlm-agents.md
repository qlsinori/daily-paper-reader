## 摘要
记忆增强的VLM代理依赖持久化的空间知识行事，然而随着环境变化，这些知识会悄然变得陈旧。我们探究当代理必须调和自信的记忆主张与矛盾的观察时会发生什么，以及当前模型能否在冲突演变为安全相关错误之前捕捉到它。利用动态FrozenLake测试平台，我们将陈旧性检测任务与下游导航任务配对，在三种闭源模型和三种开放权重VLM上，分别以文本和图像输入进行测试（共1800次检测运行，以及基于四个LLM导航器在共享50种子规模下的12000次文本模式导航回合）。三项发现浮现：第一，文本可解性并不等同于视觉基础——能够可靠地从文本中标记陈旧条目的模型，在相同网格上其视觉F1分数却从0.887跨度至0.067，最弱的模型甚至持续做出流畅而自信却忽视图像的决策。第二，未经审计地使用陈旧记忆是一种安全负担：在我们的主要GPT-4o设置中，信任原始记忆的代理相比不提供任何记忆的同一代理，死亡频率高出两倍以上。第三，审计有帮助但未弥合差距：透明的读取时过滤器在文本模式下消除了大部分安全成本，然而即使在当前网格规模下，神谕级陈旧标签也未带来进一步显著增益，并且当视觉审计不可靠时，过滤未产生一致的效益。综合来看，这些结果将空间记忆陈旧性界定为一种安全失效模式，并将可靠的视觉基础以及记忆-观察冲突下的动作选择，孤立为记忆增强代理面临的核心开放挑战。

## Abstract
Memory-augmented VLM agents act on persistent spatial knowledge, yet that knowledge silently goes stale as the environment changes. We ask what happens when an agent must reconcile a confident memory claim with a contradicting observation, and whether current models can catch the conflict before it becomes a safety-relevant mistake. Using a dynamic FrozenLake testbed, we pair a staleness-detection task with a downstream navigation task across three closed-source models and three open-weight VLMs under both text and image inputs (1,800 detection runs, and 12,000 text-mode navigation episodes over four LLM navigators at a shared 50-seed scale). Three findings emerge. First, text solvability does not imply visual grounding: models that flag stale entries reliably from text nonetheless span vision F1 from 0.887 down to 0.067 on the identical grids, and the weakest keeps making fluent, confident decisions that ignore the image. Second, consuming stale memory without an audit is a safety liability: in our primary GPT-4o setting, an agent that trusts raw memory dies more than twice as often as the same agent given no memory at all. Third, auditing helps but does not close the gap: a transparent read-time filter removes much of the safety cost in text mode, yet even oracle stale labels bring no further significant gain on the current grid size, and when visual auditing is unreliable, filtering yields no consistent benefit. Together these results frame spatial-memory staleness as a safety failure mode and isolate reliable visual grounding and action selection under memory--observation conflict as the central open challenges for memory-augmented agents.

## 1. 论文的核心问题与整体含义

记忆增强的视觉语言模型（VLM）智能体在动态环境中依赖持久化的空间记忆来导航，但环境一旦发生变化，记忆中的空间信息会“悄然变得陈旧”。论文的核心问题是：**当智能体面对一个自信的旧记忆主张与当前观测相矛盾时，它能否识别出冲突，并据此做出安全决策？** 如果不能，这种“记忆陈旧”会造成怎样的安全代价？

研究动机有三层：
- **记忆是智能体的核心设计模式**：Voyager、GITM、Reflexion、MemGPT 等系统都依赖持久记忆来积累技能、轨迹或反馈，但既有研究主要关注记忆的构建、检索与复用，而忽略了“存储的空间主张在行动前可能已失效”这一问题。
- **现有工作存在交叉空白**：知识时效性研究处理的是文本事实，空间推理与幻觉基准评估的是静态观测，均未覆盖“已改变的空间记忆必须与当前观测调和后才会影响安全行动”这一环节。
- **安全后果严重**：实验表明，信任原始陈旧记忆的 GPT-4o 智能体死亡率比无记忆时高出两倍以上，因此空间记忆陈旧是一个需要被单独识别的安全失败模式。

整体含义：论文将空间记忆陈旧性定义为一种安全失效模式，指出可靠视觉基础（visual grounding）和记忆–观测冲突下的动作选择是记忆增强智能体的核心开放挑战。

## 2. 论文提出的方法论

### 2.1 核心思想
构建了一个名为 **SpatialSTALE** 的动态 FrozenLake 测试平台，将“陈旧性检测”与“下游导航”配对，使得记忆条目、世界状态、任务结果三者均可控、可观测、可归因。每个实例包含四个阶段：
1. 生成原始 8×8 网格及其自然语言记忆快照；
2. 在导航前或导航中改变若干单元格（F/H 翻转）；
3. 让模型审计所有记忆条目，判断其是否与当前文本或图像观测冲突；
4. 分别使用原始记忆、过滤后记忆或无记忆进行导航。

### 2.2 关键技术细节

- **记忆格式**：每条记忆是一个自然语言主张，例如 `SAFE at (2,5): Frozen ice - safe to walk`，并带唯一 ID 用于与 ground truth 对比。
- **陈旧性形式化**：
  - 定义危险映射 h(H)=1，h(F)=h(S)=h(G)=0；
  - 条目 `m_i` 在时间 t 的陈旧标签为 `y_i(t) = I[h(c0_i) ≠ h(g_t[p_i])]`；
  - 模型输出二元预测 `ŷ_i(t)`，计算条目级 Precision、Recall、F1。
- **三种受控变化制度（Change Regimes）**：
  - **L1（Spot）**：随机 5–7 个散点变化，一次性观测；
  - **L2（Cluster）**：在半径 2 邻域内聚集 12–16 个变化，一次性观测；
  - **L3（Online dynamic）**：导航过程中每 5 步有概率触发事件，每次翻转 2 个格子，并在事后重新审计。
- **文本/视觉模态**：文本模式下网格以坐标标注列表呈现；视觉模式下网格渲染为 384×384 RGB 图像，每个格子 48 像素，带坐标标签和颜色编码；记忆在两种模式下均为文本。
- **四种导航记忆策略**：
  - **NoMemory**：不提供任何记忆；
  - **NoFilter**：直接使用全部 64 条原始记忆；
  - **SelfVerify**：导航前由模型自行做一次性全量一致性检查并删除不一致条目；
  - **OMCD**（Optimal Memory–Observation Conflict Detection）：论文提出的受控过滤干预——将记忆分批次（B=10）交给模型做二元 is_stale 判断，删除被标记为陈旧的条目；在 L3 下，每次环境事件发生后重新审计。算法流程：对每一批记忆，模型基于当前观测输出每条记忆的 `is_stale` 与简短理由，若为 stale 则从活动记忆集中移除，最终返回过滤后的记忆视图。
- **Oracle 标签**：用 ground-truth 陈旧标签走 OMCD 的过滤流程，用于消融标签质量对下游的影响。

## 3. 实验设计

### 3.1 数据集 / 场景

- **导航任务**：模型逐动作选择 UP/DOWN/LEFT/RIGHT，到达终点奖励 +1，踩洞死亡奖励 −1，超时奖励 0（最大步数 50）。

## 6. 论文的主要结论与发现

1. **文本可解性不意味着视觉基础**：在相同网格上，文本检测 F1 接近天花板（闭源模型和 GLM 均 >0.88），但视觉 F1 跨度极大——Qwen 为 0.887，Claude 为 0.823，GPT-4o 约为 0.329，GLM-5.1 仅 0.067。最差的模型即使看到矛盾图像，仍持续发出流畅、自信但错误的判断。
2. **陈旧记忆是安全负担**：在 GPT-4o L2 文本模式下，NoFilter 成功率为 14.4%、死亡率为 74.4%；NoMemory 成功率为 28.8%、死亡率为 28.0%。即**信任原始陈旧记忆的死亡风险是无记忆的 2.7 倍**。其他模型也有类似的安全税。
3. **审计可以减少但不能完全消除风险**：OMCD 在文本模式下显著降低了死亡率（GPT-4o L2 从 74.4% 降至 31.6%）；但 Oracle 标签在 8×8 文本设置中相比 OMCD 没有进一步显著提升（|Δ| ≤ 0.02, p > 0.2），表明在可靠审计下，瓶颈已从标签准确率转向“在过滤后记忆上的动作选择”。
4. **视觉审计不可靠时，过滤无一致改善**：在视觉导航预览中，GPT-4o、Claude、GLM 的成功率均不超过 0.40，OMCD 未带来一致增益；而 Qwen 视觉检测与导航均保持高位，过滤提升空间有限。
5. **失败机制不同**：NoFilter 的死亡轨迹显著较短（GPT-4o 8.5 步、Claude 7.8 步），呈现“直奔洞”的陈旧记忆驱动特征；NoMemory 的死亡则表现为长时间探索后死亡（Claude 16.1 步）；OMCD 介于两者之间。
6. **模型的视觉审计失败模式各异**：GLM-5.1 是“记忆主导型幻觉”，对正确与错误条目给出几乎相同的 stale 标记率；GPT-4o 倾向于拒答或坐标标签交换，召回率大幅下降；Claude 则对致命 Thaw 类条目召回更高、对 Freeze 类较低。

## 7. 优点

- **问题设置精巧**：将“记忆陈旧性检测”与“安全敏感导航”紧密结合，利用 FrozenLake 的确定性结果把每次死亡归因到具体记忆条目，因果链路清晰。
- **双模态配对设计**：对同一实例提供文本和图像观测，能够严格区分“文本可解性”与“视觉基础”之间的鸿沟，避免了渲染质量作为混淆因素。
- **控制变量完整**：NoMemory/NoFilter/SelfVerify/OMCD/Oracle 五种条件，可以分别测量记忆的收益、陈旧记忆的代价、简单自检的效果、受控过滤的增益以及标签质量的极限。
- **可信的统计与诚实解读**：使用 50 个共享种子的配对检验，对不显著结果不做过度推断，明确区分“未检测到差异”与“等价”。
- **诊断深入**：轨迹长度分解、逐类召回（Thaw vs Freeze）、精确率–召回率误差分布、F1–成功率相关性等分析，帮助定位瓶颈到底在检测、过滤还是动作选择。
- **开放性与可复现性**：承诺发布代码、种子地图、完整模型轨迹和复现流水线。

## 8. 不足与局限

- **场景过于简化**：8×8 FrozenLake、符号化网格、完全可观测，与现实世界的连续导航、感知噪声、模糊变化相差较远；作者也承认数字是“干净环境下的下界”，而非现场估计。
