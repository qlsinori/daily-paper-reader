## 摘要
基于基础模型的视觉-语言导航（VLN）通过使机器人能够解释自然语言指令、识别语义目标并遵循用户指定的行为规则，推进了自主机器人导航的发展。然而，现有的VLN系统严重依赖云端托管的基础模型进行语言理解和语义接地，这限制了其在网络连接不可用且需要可靠度量目标定位的场景中的适用性。尽管近期的小语言模型（SLMs）实现了完全机载推理，但其对导航指令分解的适用性尚未被系统评估。本文为实现室外环境下的完全机载VLN做出了三项贡献。首先，我们提出了首个系统基准，对17个边缘可部署的SLM与4个在线API进行机器人导航指令分解的比较，评估了在三种计算平台上人工标注指令的准确性和延迟，并为选择机载语言模型提供了实用指导。其次，我们提出了一种轻量级混合语义-几何目标定位框架，结合开放词汇目标检测、提示分割和LiDAR几何来估计度量目标，同时在缺乏可靠几何观测时保持视觉方位引导。第三，我们将这些进展集成到Edge-BehAV中，这是BehAV架构的完全机载扩展，实现了不依赖云端的基于行为的导航。实验结果表明，最佳离线SLM在指令分解性能上与最强的云API相当，同时运行速度大约快9倍且无需网络连接。所提出的目标定位框架在较低计算成本下将平均目标距离误差从2.05米降低到0.20米，并且整个系统在32次闭环室外试验中成功完成了31次。

## Abstract
Foundation-model-based vision-language navigation (VLN) has advanced autonomous robot navigation by enabling robots to interpret natural-language instructions, identify semantic goals, and follow user-specified behavioral rules. However, existing VLN systems rely heavily on cloud-hosted foundation models for language understanding and semantic grounding, limiting their applicability where network connectivity is unavailable and reliable metric goal localization is required. Although recent small language models (SLMs) enable fully onboard inference, their suitability for navigation instruction decomposition has not been systematically evaluated. This paper makes three contributions toward fully onboard VLN for outdoor environments. First, we present the first systematic benchmark of 17 edge-deployable SLMs against 4 online APIs for robotic navigation instruction decomposition, evaluating accuracy and latency on human-annotated instructions across three computing platforms and providing practical guidance for selecting onboard language models. Second, we propose a lightweight hybrid semantic-geometric goal localization framework that combines open-vocabulary object detection, prompted segmentation, and LiDAR geometry to estimate metric goals, while maintaining visual bearing guidance when reliable geometric observations are unavailable. Third, we integrate these advances into Edge-BehAV, a fully onboard extension of the BehAV architecture that enables cloud-independent behavior-guided navigation. Experimental results show that the best offline SLM matches the instruction decomposition performance of the strongest cloud API while running approximately 9x faster and without network connectivity. The proposed goal localization framework reduces mean goal-distance error from 2.05 m to 0.20 m at lower computational cost, and the complete system succeeds in 31 of 32 closed-loop outdoor trials.

## 2. 论文提出的方法论

- **总体架构**：保留 BehAV 的四模块架构，将云端依赖的语言理解与语义感知模块替换为机载方案，并引入传感器接地的几何目标定位。

- **模块 1：离线语言分解（Offline Instruction Decomposition）**
  - 使用机载 SLM（推荐 Qwen2.5-7B，轻量备选 Qwen2.5-3B）替代云端 GPT-4。
  - 通过 Ollama 本地部署量化权重，对每条导航指令生成五个结构化字段：`landmarks`（目的地）、`navigation actions`、`behavioral actions`、`behavioral targets`、`behavioral costs`（用于构建 CLIPSeg 行为代价图）。
  - SLM 仅在任务启动时运行一次，无需网络连接。

- **模块 2：代价图（保留自 BehAV）**
  - 使用 CLIPSeg 进行开放词汇逐像素分割，将语义目标映射为行为代价图，支持 Stay/Avoid/Yield/Stop 四层行为成本。

- **模块 3：目标估计（核心创新）**
  - **Search-then-Segment 管线**：Florence-2 进行零样本开放词汇检测，获取目标包围框；Mobile-SAM 仅在该框内生成高质量分割掩膜，避免全图分割。
  - **LiDAR-视觉融合定位**：将 LiDAR 点云通过外参 `T_lidar→cam` 和相机内参 `K` 投影到图像平面，保留落在分割掩膜 `M` 内的点；对平面距离应用 IQR 离群点滤波（式 (2)）；若有效点数 ≥ Npts=7，用中位数稳健质心计算距离 `r` 和方位角 `ψ`（式 (3)），并通过里程计位姿锁定世界坐标系目标（式 (4)）。

## 3. 实验设计

- **语言分解基准（Instruction Decomposition Benchmark）**

- **跨平台评估**

- **地标检测基准（Landmark Detection Benchmark）**

  - 指标：F-score、平均像素误差（预测框与 GT 框质心的欧氏距离）、端到端时间。

- **距离估计基准（Distance Estimation Benchmark）**

- **全系统闭环实验（Full-System Closed-Loop Benchmark）**

  - 4 个室外场景，每个场景 8 次试验（共 32 次）：
    - Scn.1：动态行人避让。
    - Scn.2：从方位追踪到度量目标的切换（交通锥 + 避开水坑）。

  - Scn.3 和 Scn.4 同时运行原始 BehAV 作为系统级对比基线。

## 6. 论文的主要结论与发现

- 最佳离线 SLM（Qwen2.5-7B）的 Macro-F1 为 0.775，与最强云 API GPT-5.5（0.765）在统计上持平，且延迟低约 9 倍（1.13s vs 9.95s），完全离线运行。

- 纯文本 LLM 在指令分解任务上优于 VLM 变体，VLM 仅在需要同时进行图像接地时才有价值。
- 跨平台质量基本稳定（INT4 量化权重固定，质量仅微小波动），模型选择可在笔记本上完成并迁移到嵌入式设备。

## 7. 优点

- **首个导航专用 SLM 基准**：系统评估 17 个边缘可部署模型在导航指令分解任务中的质量-延迟权衡，并公开基准数据集，可复现、可扩展。
- **无需训练的端侧方案**：全部采用现成模型 + INT4 量化 + Ollama 部署，无任何训练开销，即插即用。
- **创新性混合定位框架**：将开放词汇检测、提示分割与 LiDAR 几何融合，用 IQR 滤波和中位数质心提升鲁棒性；bearing-only 回退机制保证了点云不足时的可用性，Stop-and-Measure 状态机解决了运动状态下的传感器时间同步问题。
- **行为代价的精细设计**：距离调度的障碍权重、排除目标自身点云、混合 MPC 目标，解决了接近目标时的行为/障碍代价冲突。
- **实车验证扎实**：32 次闭环试验覆盖多种复杂场景，指标全面（成功率、航向误差、距离误差、Fréchet 距离、行为遵循率），并与原系统同台对比。
