## 摘要
现有的自主代客泊车（AVP）方法通常依赖预建地图，这严重限制了其在未知环境和开放词汇目标上的可扩展性。受视觉语言模型（VLM）在视觉语言导航（VLN）任务中应用的启发，我们提出了VLN-AVP，一种用于AVP任务的零样本导航框架。通过将鸟瞰图（BEV）模型的精确空间感知与VLM的通用智能相结合，我们的框架1）消除了对预建地图的依赖，2）解释停车场景中的语义环境上下文，3）实现遵循自然语言指令的直观导航。具体而言，我们引入了一个混合记忆系统：短期感知记忆跟踪语义视觉线索，以解决现有方法中VLM单帧推理的局限性，而长期拓扑记忆则促进从过去经验中进行稳定的策略学习。为弥合现有基准的差距，我们还提供了VLN-AVP数据集和基准。该数据集包含10个高保真停车场景和超过1000个导航回合，拥有迄今为止最多的车库场景，并且是首个针对地下停车场的VLN基准。大量实验表明，在仿真中，与VLN方法相比，我们的方法成功率提高了超过25%，与其他自动驾驶方法相比提高了超过15%。此外，它在真实车辆实验中取得了领先的成功率，证明了其实际可行性。

## Abstract
Existing methods in Autonomous Valet Parking (AVP) typically rely on pre-built maps, which severely restricts their scalability to unseen environments and open-vocabulary targets. Inspired by the application of Vision-Language Models (VLMs) in Vision-Language Navigation (VLN) tasks, we propose VLN-AVP, a zero-shot navigation framework for AVP tasks. By combining the precise spatial perception of a Bird's-Eye-View (BEV) model with the general intelligence of VLMs, our framework 1) eliminates the dependency on pre-built maps, 2) interprets semantic environmental contexts in parking scenarios, and 3) enables intuitive navigation following natural language instructions. Specifically, we introduce a hybrid memory system: a short-term perception memory tracks semantic visual cues to address the limitations of VLM's single-frame reasoning in existing methods, while a long-term topological memory facilitates stable policy learning from past experiences. To bridge the gap in existing benchmarks, we also present the VLN-AVP dataset and benchmark. Featuring 10 high-fidelity parking scenes and over 1,000 navigation episodes, it has the largest number of garage scenes to date and is the first VLN benchmark for underground parking. Extensive experiments demonstrate that in simulation, our method achieves an over 25% improvement in success rate compared to VLN methods and an over 15% improvement compared to other autonomous driving methods. Furthermore, it attains a leading success rate in real-world vehicle experiments, proving its practical feasibility.

## 2. 论文提出的方法论

### 核心思想
将 **BEV 模型的精确空间感知**与 **VLM 的通用推理智能**相结合，构建一个四模块协作的导航系统：

| 模块 | 功能 | 频率 |
|---|---|---|
| BEV 感知与轨迹生成 | 空间感知、生成候选轨迹 | 高频 |
| VLM 决策核心 | 高层导航指令理解与语义推理 | 低频 |
| 混合长短期记忆 | 短期感知记忆 + 长期拓扑记忆 | 持续更新 |
| 分层决策模块 | 协调高层指令与低层执行 | — |

### 关键技术细节

1. **BEV 感知与候选轨迹生成**
   - 使用 **MapTR**（基于 Transformer 的 BEV 感知模型）处理四路环视相机图像，输出矢量化的车道中心线。
   - 轨迹优化器结合 **RS 曲线**（Reeds-Shepp）和车辆运动学模型，生成一组可行驶候选轨迹：
     
     $$T_t = f_{optim}(L_t) = \{\tau_i\}_{i=1}^{N_t}, \quad \tau_i = \{p_j\}_{j=1}^{M}, \ p_j \in \mathbb{R}^2$$
     
   - 每个轨迹 $\tau_i$ 代表一条潜在路径（直行、左转、右转等），构成下游控制器的动作空间。

2. **目标提取器（Target Extractor）**
   - 将用户的自然语言指令分解为一系列可执行的导航子目标（sub-goals）：
     
     $$G = f_{extract}(L_{user}) = (g_1, g_2, \ldots, g_{K_g})$$

3. **检测与短期记忆（STM）**
   - 使用 **Grounding DINO** 以高频检测前视图像中的导航线索（以“标牌/sign”为 prompt），检测结果格式化为带有时间戳、边界框和车辆偏航角的帧。
   - STM 为 **K_STM 帧队列**，通过三重过滤保持信息有效性：
     - **目标过滤**：基于 IoU 匹配替换同一目标的旧帧；
     - **方向过滤**：移除与当前车辆偏航角差异过大的帧；
     - **时间过滤**：移除过于陈旧的帧。

4. **VLM 决策核心**
   - VLM 接收复合 prompt：
     
     $$P = [I^{front} \oplus \{I^{detect}_j\}_{j=1}^{K_{STM}} \oplus S \oplus g]$$
     
   - 输出高层元动作 $a_{vlm} \in \{forward, left, right, stop\}$，存入动作缓存供分层决策模块使用。

5. **长期拓扑记忆（LTM）**
   - 构建有向拓扑图 $G = (V, E)$：
     - **交汇节点**（Junction Nodes）：记录路口中心坐标；
     - **地标节点**（Landmark Nodes）：在任务完成点（stop 动作）记录；
     - **边（Edges）**：记录节点间行驶轨迹的方向向量，通过轨迹倒数第 5 点到终点的单位方向计算：
       
       $$d = \frac{p_M - p_{M-4}}{\|p_M - p_{M-4}\|_2}$$
   - 记忆更新机制：根据用户反馈和系统触发结果更新节点/边的有效性位 $v \in \{0, 1\}$。

6. **分层决策模块**
   - 决策顺序：直行（仅一个候选轨迹）→ 查询 LTM（图搜索 → 方向余弦相似度匹配轨迹）→ 查询 VLM 动作缓存（按角度偏差映射轨迹）→ 低层控制器执行。

## 6. 论文的主要结论与发现

1. **仿真性能显著领先**：
   - Regular 任务：SR 65.2%（比最佳 AD 基线 LaMPilot 49.7% 高 15.5 个百分点），比 VLN 方法最高提升 >25%。
   - Challenging 任务：SR 45.4%，NE 指标降至 18.4m，全面优于所有基线。

2. **消融实验证实记忆模块价值**：
   - 去掉 LTM 和 STM 后，SR 从 65.2% 降至 42.2%（Regular），从 45.4% 降至 31.1%（Challenging），表明两个记忆模块均有正向贡献。

3. **长期记忆具备学习能力**：
   - 50 次导航尝试中，SR 和 SR/OSR 比率稳定上升——智能体不仅能找到目标，还能逐渐学会在**精确位置**停止。

4. **长期记忆降低推理成本**：
   - 使用 LTM 后，VLM 调用次数从 1,403 次降至 317 次（减少 77.4%），导航时间从 262.7s/episode 降至 161.7s，API 成本从 $1.06 降至 $0.24。

5. **短期记忆提升语义线索识别**：
   - 在 20 个关键路口中，STM 将标牌识别率从 57.7% 提升至 84.6%，决策成功率从 60% 提升至 85%。

6. **实车实验验证可行性**：
   - SR 63.3%（vs. LaMPilot 36.7%），并展示了基于用户反馈进行错误纠正的人机交互能力。

   - 论文提到计划发布数据集，但未提及开源代码；部分模块（如 MapTR、Grounding DINO、Gemini-3-flash）依赖第三方实现和商业服务。

7. **长期记忆的鲁棒性风险**：
   - 当环境发生结构性变化（如施工改道）时，系统依赖有效性位机制标记失效边，但该机制依赖用户反馈和系统检测，在无人监督的完全自主运行中可能积累错误经验。

---

## 总结

VLN-AVP 为自主代客泊车提供了一种真正意义上的零样本、无地图、语言驱动的导航方案，在方法设计（BEV + VLM + 混合记忆）、数据集构建（10 个 3DGS 场景、首个地下 VLN 基准）和实验验证（仿真 + 实车）三个维度均有实质贡献。其主要短板在于对商业大模型 API 的依赖、实

车验证规模有限（仅 2 个车库、30 次试验），以及对传统 VLN 指标体系的依赖——尚未对真实泊车精度、用户体验、安全性等维度进行系统评估。这些短板并不否定其核心贡献，而恰恰指明了后续工作的重要方向。

## 9. 未来研究方向

1. **增强 VLM 的空间推理能力**：
   - 作者明确将“方向感与空间推理不足”列为待改进项，未来可引入显式的几何约束（如将 BEV 坐标直接注入 VLM 的 token 序列）或通过思维链（Chain-of-Thought）引导 VLM 进行多步空间推理。
   - 可探索多帧 BEV 视频输入而非单帧图像，使 VLM 获得时序运动信息。

2. **降低对商业 API 的依赖**：
   - 探索边缘端可部署的开源 VLM（如 Qwen-VL、InternVL 系列）蒸馏方案，或轻量化视觉语言模型与规则校验器的混合架构。
   - 发展离线场景下的本地化推理方案，减少网络往返延迟和 API 成本。

3. **扩展长期记忆的鲁棒性**：
   - 引入环境变化检测机制（如 BEV 差异对比），使 LTM 在结构变化时自动触发失效标记，而非依赖用户反馈。
   - 探索多智能体共享记忆（云端拓扑地图叠加），跨车积累泊车经验。

4. **丰富数据集与任务复杂度**：
   - 增加多楼层地下车库、多层环形结构、极端光照（暗光/逆光）与动态障碍（行人、车辆交汇）场景。
   - 扩展语义任务类型：从“导航至某处”升级为“寻找带充电桩车位并泊入”，将泊车执行精度纳入评估。

5. **建立更完整的评测体系**：
   - 引入端到端安全指标（最小距离裕度、碰撞率）、人机交互质量评估（指令理解率、纠错效率），以及真实泊车完成率。
   - 考虑将 VLN-AVP 嵌入完整的泊车流程（导航 → 候选车位识别 → 泊入控制），实现全链路评估。

## 10. 对领域的影响与启发

1. **对 AVP 的范式重塑**：
   - 传统 AVP 依赖“建图-定位-规划”链路，VLN-AVP 证明了“感知-理解-决策”的端到端语言驱动范式在封闭场景的可行性，为下一代无地图自主泊车提供了新的技术路径。

2. **对 VLN 研究的场景拓展**：
   - 首次将 VLN 从室内/室外导航延伸至地下停车场这一结构化但视觉退化（光照差、纹理稀疏）的真实场景，为 VLN 模型的鲁棒性研究提供了更具挑战性的基准。

3. **对记忆机制设计的启示**：
   - 混合长短期记忆的架构——高频感知记忆（STM）解决 VLM 单帧视野局限、低频拓扑记忆（LTM）实现跨 episode 经验积累——为其他大模型驱动决策系统（如室内服务机器人、仓库搬运）提供了可复用的设计模式。

4. **对数据构建方法的示范**：
   - 利用手持 LiDAR + 3DGS 重建高保真场景，相比传统手工建模/游戏引擎，大幅降低了仿真环境构建成本，且渲染质量更接近真实，为自动驾驶仿真数据生产提供了低成本、可扩展的方案。

## 结语

VLN-AVP 的核心价值在于它展示了一个近乎"无成本"的通用智能组合方案：利用 BEV 模型提供几何精度、利用 VLM 提供语义理解、利用记忆结构桥接两者在时间尺度上的鸿沟，最终在完全无地图、零样本的条件下实现了地下停车场中的自然语言导航。它并非一个完美系统——依赖云端大模型、空间推理薄弱、实车验证有限——但它成功地将两个原本独立的研究社区（VLN 与 AVP）连接在一起，并提供了一个高质量的开源基准与清晰的技术路线图。对于所有试图将大语言模型/视觉语言模型落地到物理世界的尝试而言，这篇工作具有明确的参考意义。
