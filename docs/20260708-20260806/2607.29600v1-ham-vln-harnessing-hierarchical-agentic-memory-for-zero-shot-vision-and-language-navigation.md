## 摘要
视觉-语言导航（VLN）使机器人能够在未见过的环境中遵循指令。近期出现了一种免训练范式：机器人查询多模态大语言模型以理解其观测并规划下一步动作。然而，基于图像流或稠密地图的长时程导航不可避免地会引入不断增长的记忆与推理瓶颈。我们提出HAM-VLN，一种决策耦合、由智能体自主撰写的记忆，它为机器人配备了一个持久的、基于深度的世界图。在与选择下一动作相同的大模型调用中，HAM-VLN还会记录语义与反思信息——包括房间类型、物体、导航进度和失败备注。最近的路标点以逐字形式保留在受限窗口内，而较旧的历史仅通过按相关性、近因性和显著性评分（并结合一跳拓扑扩展）的检索重新进入上下文。该设计在每路标点单次决策之外不产生额外的大模型调用。与以往方法相比，HAM-VLN不仅提升了各项导航指标，还将上下文长度减少了65%以上。具体而言，HAM-VLN在VLN-CE R2R上达到61.0%的成功率（SR），在VLN-CE RxR上达到52.7%的SR，在HM3D-v2 ObjectNav上无需任何训练即达到79.7%的SR。

## Abstract
Vision-and-language navigation (VLN) enables robots to follow instructions in previously unseen environments. Recently, a training-free paradigm has emerged: the robot queries a multimodal LLM to understand its observations and plan the next action. However, long-horizon navigation based on either image streams or dense map inevitably introduces a growing memory and reasoning bottleneck. We present HAM-VLN, a decision-coupled, agent-authored memory that equips the robot with a persistent, depth-grounded world graph. In the same model call used to select the next action, HAM-VLN also records semantic and reflective information---including room type, objects, navigation progress, and failure notes. Recent waypoints remain verbatim within a bounded window, while older history re-enters the context only through retrieval scored by relevance, recency, and salience, together with one-hop topological expansion. This design requires no additional LLM calls beyond the per-waypoint decision. Compared to previous methods, HAM-VLN not only improves various navigation metrics but also reduces the context length by more than 65%. Specifically, HAM-VLN achieves 61.0% Success Rate (SR) on VLN-CE R2R, 52.7% SR on VLN-CE RxR, and 79.7% SR on HM3D-v2 ObjectNav without any training.

# HAM-VLN 论文总结

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言导航（VLN）要求机器人在未见环境中根据自然语言指令导航并停在目标位置。近年出现免训练范式：利用多模态大语言模型（MLLM）直接理解观测并规划下一步。
- **核心问题**：长时导航中，基于原始图像流或稠密语义地图的历史表示会带来持续增长的记忆与推理开销——图像流随轨迹增长，稠密地图随区域增长，且无法有效标记“已失败分支”。MLLM 无法在无限膨胀的上下文中有效检索关键信息。
- **论文含义**：作者提出 **HAM-VLN**，将导航历史存储为“深度接地世界图”（depth-grounded world graph），并结合分层智能体记忆（工作、情景、语义、反思）实现选择性保留与检索，在不牺牲甚至提升导航性能的前提下大幅降低上下文长度。该方法是完全免训练的（zero-shot / training-free）。

## 2. 方法论

### 2.1 总体架构：双过程系统

- 采用双过程架构：
  - **System 2（慢思考/规划）**：每个路标点调用一次大型 MLLM，读取指令、当前观测和记忆上下文，输出高层决策（前进方向、回溯、停止），并同时结构化写入记忆信息。
  - **System 1（快策略/接地）**：轻量级 MLLM 将高层方向语义接地到像素空间（预测边界框），再通过深度相机内参反投影到 3D，经快速行进控制器执行运动。
- 策略分解公式：
  - `At = πrobot( φ1( φ2(T, Ot, Mt), Dt, Pt, Kcam ) )`
  - 其中 `φ2` 为规划器，`φ1` 为接地模型，`πrobot` 为运动控制器。

### 2.2 分层智能体记忆

- **记忆状态组成**：
  - `Wt`：工作记忆，最近 `K` 个路标点的原始视觉帧，K=1 时仅保留最近一帧。
  - `Lt`：指令进度记录，按序排列的子目标列表。
  - `Gt`：长期世界图（地点-物体图）。
  - 上下文组装：`Mt = Wt ⊕ Lt ⊕ R(Gt, qt)`，其中 `qt` 为当前子目标，`R` 为检索算子。
- **世界图结构**：
  - 地点节点 `VPt`：由增量单链聚类形成，包含空间锚点、语义描述、访问统计、失败证据。
  - 物体节点 `VOt`：通过 Grounding DINO + SAM 检测并投影深度，得到深度接地物体锚点。
  - 边：地点-地点导航边（拓扑），地点-物体语义边（具有置信度）。
- **决策耦合更新**：
  - System 2 每次输出结构化记录 `Jt = (at, wt, rt)`，其中 `wt` 为语义/进度信息，`rt` 为动作理由。
  - 更新进度：`Lt+1 = UL(Lt, wt)`；更新世界图：`Gt+1 = UG(Gt, wt, Γ(Ot, Dt, Pt))`。
  - 记忆写入不额外调用 LLM，与决策共用一次调用。
- **功能视图**：
  - **工作记忆**：保留最近原始帧，即时感知。
  - **情景记忆**：提供地点访问的时间近因性。
  - **语义记忆**：提供地点-物体的内容相关性和拓扑。
  - **反思记忆**：将回溯时产生的失败证据附加到地点，检索时原样返回，指导后续避免相同错误。

### 2.3 子目标条件检索

- 地点排序得分：
  - `st(p) = α·rel(qt,p) + β·rec_t(p) + γ·sal(p)`
  - `rel`：子目标与地点摘要的余弦相似度（本地 bge-large-en-v1.5 编码）。
  - `rec_t(p)`：基于最后访问时间的指数衰减近因性。
  - `sal`：地标/物体丰富度显著性。
  - 超参数 α=1.0, β=0.3, γ=0.3，衰减率 ρ=0.85。
- 拓扑读取：
  - 取 `Ks=3` 个高分地点作为种子，一跳拓扑扩展，最终保留 `Kp=5` 个地点，序列化后进入上下文。
  
### 2.4 接地失败记忆与回溯

- 当 System 2 决定回溯到已访问路标点 `bt` 时，将回溯轨迹后缀关联到地点节点，并把动作理由 `rt` 写成失败证据。
- 该证据是咨询性的，不修改检索得分，也不阻止访问；只有在后续检索到相关区域时才重新进入上下文，使 System 2 能在新子目标下重新解读旧失败。
- 算法 1 完整描述了控制、记忆写入、检索与回溯的循环。
