## 摘要
本文在无训练设置下解决了空中视觉-对话导航（AVDN）任务，以实现资源高效的高空无人机导航。直接应用多模态大语言模型（MLLMs）会因方向接地能力弱和缺乏显式空间记忆而导致导航不可靠。为解决这些问题，我们提出了PSC-AVDN，一种将三阶段“解析-搜索-确认”推理流程与结构化空间记忆（SSM）紧密耦合的无训练框架。解析阶段使用大语言模型（LLM）将模糊的对话指令转换为稳定的几何方向与目的地线索。随后，搜索思维链（S-CoT）在高空观测下执行逐步目标探索，确认思维链（C-CoT）在候选区域周围进行细粒度验证以解决视觉模糊性。同时，SSM整合了三类互补的空间线索，包括多尺度视觉观测、空间视觉记忆和结构化几何记忆，以提供全局空间上下文和长程一致性。在ANDH和ANDH-Full上的大量实验表明，PSC-AVDN在无训练设置下达到了新的最先进性能，匹配甚至超越了若干微调方法。代码将公开于：https://github.com/QY6616/PSC-AVDN

## Abstract
In this paper, we tackle the Aerial Vision-and-Dialog Navigation (AVDN) task in the training-free setting for resource-efficient high-altitude UAV navigation.Naively applying MLLMs leads to unreliable navigation due to weak directional grounding and the lack of explicit spatial memory.To address these issues, we propose PSC-AVDN, a training-free framework that tightly couples a three-stage Parsing-Search-Confirmation reasoning pipeline with a Structured Spatial Memory (SSM).The parsing stage uses an LLM to convert ambiguous dialogue instructions into stable geometric directional and destination cues.A Search Chain-of-Thought (S-CoT) then performs stepwise target exploration under high-altitude observations, and a Confirmation Chain-of-Thought (C-CoT) conducts fine-grained verification around candidate regions to resolve visual ambiguity.Meanwhile, SSM integrates three complementary sources of spatial cues, including multi-scale visual observation, spatial visual memory, and structured geometric memory to provide global spatial context and long-horizon consistency.Extensive experiments on ANDH and ANDH-Full show that PSC-AVDN establishes new state-of-the-art performance in the training-free setting, matching or surpassing several finetuned methods.Code will be publicly available at: https://github.com/QY6616/PSC-AVDN

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **任务背景**：本文研究的是空中视觉-对话导航（Aerial Vision-and-Dialog Navigation, AVDN）任务，即无人机（UAV）在跟踪自然语言指令的同时，通过与用户进行多轮对话来消除歧义、解释上下文线索，最终在复杂高空场景中定位目标。相比低空城市环境，高空俯视视角覆盖范围更广、地标尺度更小且纹理稀疏，这给目标的细粒度定位与跟踪带来了更大的挑战。
- **现有方法的局限**：已有 AVDN 方法（如 HAA-T、TA-GAT、FELA 等）依赖监督式微调，存在计算成本高、标注工作量大、跨环境泛化时需要重新标注和反复训练等问题。
- **直接应用 MLLM 的失败**：构建一个将当前视角图像与对话指令直接输入 MLLM 的基线会发现其效果非常不可靠，原因有二：
  1. **方向接地弱**：MLLM 的训练数据以地面视角为主，缺乏高空几何推理能力，无法将“向左转一点”“朝你 10 点钟方向”这类抽象表达转换为有效的几何线索，同时也难以在纹理稀疏、尺度微小的高空俯视地标与文本指令间建立对齐；
  2. **缺乏全局空间理解与时间状态跟踪**：有效的 AVDN 需要维护已访问区域的空间意识并随时间更新环境信念，而 MLLM 的自回归、语言驱动推理范式缺乏结构化的地图构建或长程空间一致性机制，导致每一步都在孤立地解释当前视图。
- **本文的整体意义**：为解决上述问题，本文提出 PSC-AVDN——一个完全无训练（training-free）的 AVDN 框架，将“解析-搜索-确认”三阶段推理管线与结构化空间记忆（Structured Spatial Memory, SSM）紧密耦合，在不经过任何任务特定训练的情况下，实现了资源高效、可泛化、稳定可靠的高空无人机导航。这一工作证明：通过精心设计的推理策略和空间记忆机制，可以充分释放 MLLM 在复杂高空场景中的视觉感知与推理潜力。

## 2. 论文提出的方法论

### 2.1 核心思想

PSC-AVDN 的核心思路是**将方向理解与高空目标定位解耦**，以弥补 MLLM 的缺陷。具体包含两大部分：（1) 三阶段“解析-搜索-确认”（Parsing-Search-Confirmation, PSC）推理管线；（2）结构化空间记忆（SSM）模块。

### 2.2 三阶段推理管线

**① 解析阶段（Parsing）**

- 使用通用 LLM（DeepSeek-V3）对对话指令 U 进行结构化分解，提取移动方向短语 $s_{\text{dir}}$ 与目的地描述 $s_{\text{des}}$。
- 由于方向短语有多种形式（如“3 点钟方向”“120°”“东北”等），设计了**航向解析（Heading Resolution, HR）模块**，通过规则解析器将异构表达统一转换为规范的角度表示，并基于无人机当前方位角计算相对航向：
  $$\delta = \text{wrap}(\alpha - \varphi)$$
  其中 $\alpha$ 为绝对角度，$\varphi$ 为无人机当前方位角，$\text{wrap}(\cdot)$ 将角度归一化到 $[0, 2\pi)$ 范围。
- 最终将相对航向 $\delta$ 与目的地描述 $s_{\text{des}}$ 一并送入后续推理阶段。

**② 搜索阶段（Search）**

- 设计**搜索思维链（Search Chain-of-Thought, S-CoT）**，将目标搜索分解为四个有序的子推理步骤：
  1. **目标分析**：对目的地描述进行语义分析，提取目标类别、显著参考线索与空间关系等任务相关先验。
  2. **场景理解**：利用 SSM 模块提供的多尺度视觉观测与空间视觉记忆，构建对当前视野的整体理解。
  3. **参考网格图生成**：提示 MLLM 将主视图划分为 N×N 网格，并为每个网格单元分配语义标签，生成结构化几何记忆 $R_t$。
  4. **目标定位**：基于视觉特征与目的地信息，在主视图中识别候选目标区域。
- 通过显式的分步推理机制，S-CoT 逐步缩小候选区域，增强 MLLM 在复杂空中目标搜索任务中的稳定性和可解释性。

**③ 确认阶段（Confirmation）**

- 由于高空视角下目标尺寸小、尺度变化大、地标区分度弱，仅靠 S-CoT 难以精确定位，因此引入**确认思维链（Confirmation Chain-of-Thought, C-CoT）**。
- C-CoT 强制模型基于目的地描述生成可验证的逐步推理：首先识别目标主体，再检查空间/关系约束（如“红色建筑在仓库左侧”），逐步排除错误候选，最终确认唯一目标位置并输出边界框及置信度与视觉证据说明。

### 2.3 结构化空间记忆（SSM）

SSM 模块由三个核心组件构成，在推理链中逐步运作以提供互补的空间线索：

**多尺度视觉观测（Multi-scale Visual Observation，MVO）**：对全局遥感图像按不同缩放因子 $s_i$ 重采样得到多个尺度的裁剪图像 $V_t^i = \text{Resample}(I, s_i)$，组合形成分层感知，兼顾大尺度场景布局与细粒度几何细节。文中默认使用缩放因子 (3, 5, 7)。

**空间视觉记忆（Spatial Visual Memory，SVM）**：在全图坐标系统中维护一个固定大小的记忆画布，每步将上一步的记忆地图与当前视图中间尺度特征拼接，结合历史轨迹与朝向信息 $T_t \oplus \theta_t$，通过凸包运算生成统一的覆盖掩码，从而构建连续、稳健的轨迹表征，抑制长程漂移：
$$M_t = (M_{t-1} \oplus V_t) \oplus (T_t \oplus \theta_t)$$

**结构化几何记忆（Structured Geometric Memory，SGM）**：提示 MLLM 生成参考网格图，将主视图划分为 N×N 网格，为每个网格单元赋予从数据集中统计出的 12 类高频语义标签之一，形成结构化的空间位置表征，并随时间步持续更新，为多步空间推理提供稳定支撑。

## 6. 论文的主要结论与发现

1. **无训练设定下的新 SOTA**：PSC-AVDN 在 ANDH 和 ANDH-Full 两个数据集上的三个评估指标中全面超越现有无训练方法，且性能与多个监督微调方法相当甚至更好。

3. **SSM 各组件均有增益**：SVM（历史轨迹融合）改善长程一致性；MVO（多尺度裁剪）增强局部-全局感知；SGM（参考网格图）提供结构化空间推理支撑；三者联合达到最优（SPL 17.8，SR 22.6，GP 39.2）。
4. **超参数选择敏感**：5×5 网格和 (3, 5, 7) 缩放因子组合为最优配置，过大或过小均会导致性能下降。
5. **核心方法论启示**：将显式的链式推理（CoT）与结构化空间记忆相结合，可以不依赖任务特定训练，仅通过优秀提示设计充分释放 MLLM 的视觉感知能力，为高空具身导航提供一种可扩展、可泛化的新范式。

- **对外部 MLLM/LLM API 的依赖**：方法依赖 DeepSeek-V3 和 Qwen-VL-Max 等商业模型接口，虽然免训练，但推理成本、延迟和 API 可用性均受第三方服务制约；同时，模型版本变更可能导致性能波动，方法的确定性存疑。
- **算力信息缺失**：论文未披露实验的具体硬件配置、推理延迟和总体计算开销，使得资源高效这一主张在定量层面缺乏充分证据。
- **上限受限于 MLLM 能力**：虽然框架本身与模型无关，但推理质量仍直接受后端 MLLM 的视觉感知和指令遵循能力影响（论文在附录提到不同 MLLM 有性能差异），本地部署较弱模型时效果可能明显下降。
- **实验覆盖仍有局限**：仅在 ANDH/ANDH-Full 两个同源数据集上验证，未在 CityNav、OpenUAV 等更大规模或不同视角的航拍数据集上测试；对失败案例（附录）的分析深度有限；消融实验中组件间的部分交互效应未被充分解释（如 SVM+MVO 的联合增益模式）。
- **轨迹更新与可扩展性的实践问题**：每次导航中需要在推理链中传递历史轨迹、记忆画布和多尺度图像，随步数增加 token 消耗和上下文长度持续增长，在超长轨迹上的实际可扩展性有待验证。此外，SGM 网格更新依赖 MLLM 的视觉标注质量，在高噪声环境下可能存在误差累积风险。
