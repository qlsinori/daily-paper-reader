## 摘要
零样本物体目标导航旨在使智能体无需特定目标训练即可在陌生环境中探索并导航到未知类别的物体。在零样本导航任务中，通常使用预训练大模型，利用其先验知识指导智能体的导航。然而，现有基于大语言模型（LLM）的零样本物体目标导航方法仅将LLM用作平面推理工具，直接关联物体或区域，缺乏从类人房间语义到物体定位的分层空间认知建模，导致探索盲目性强、语义关联准确性不足，且未能充分释放LLM的常识推理潜力。本文提出了一种LLM驱动的分层房间到物体（HRO）零样本物体目标导航框架，以由粗到细的方式引导智能体探索并导航至目标物体。在Gibson和HM3D数据集上的实验验证了我们的HRO框架在成功率与泛化性上优于现有基于LLM的方法，凸显了LLM在零样本物体目标导航中的强大潜力。

## Abstract
Zero-shot object-goal navigation aims to enable an intelligent agent to explore and navigate to objects of unknown categories in an unfamiliar environment without specific target training. In zero-shot navigation tasks, pre-trained large models are usually employed to leverage their prior knowledge for guiding the agent's navigation. However, existing zero-shot object-goal navigation methods based on large language models (LLMs) merely utilize LLMs as flat reasoning tools to directly associate objects or regions. They lack the hierarchical spatial cognition modeling of human-like room semantics to object localization, which leads to strong blindness in exploration, insufficient accuracy in semantic association, and failure to fully unleash the common-sense reasoning potential of LLMs. This paper proposes an LLM-driven hierarchical room-to-object (HRO) framework for zero-shot object-goal navigation, which guides the agent to explore and navigate to the target object in a coarse-to-fine manner. Experiments on Gibson and HM3D datasets verify that our HRO framework achieves superior success rate and generalization over existing LLM-based methods, underscoring LLMs' strong potential for zero-shot object-goal navigation.

- **核心研究问题**：如何将人类式的“房间→物体”分层空间认知建模引入 LLM 驱动的零样本导航，从而提升导航成功率与泛化性？

## 2. 方法论与关键技术细节

### 2.1 核心思想
- 模仿人类“首先判断场景，再寻找目标”的认知逻辑，将零样本物体导航分解为**高层房间语义推理、中层目标导向的区域选择、低层路径规划与动作执行**三个层级，形成“物体→房间→目标”的推理链路。

### 2.2 高层模块：LLM 驱动的房间类型推理（Room Type Inference）
- **输入**：由语义分割（Mask R-CNN）构建的 2D 语义地图（通道数为 C+2：障碍物、已探索区域、C 个语义类别）。
- **候选前沿点获取**：对障碍图进行膨胀处理，从已探索区域中减去膨胀障碍图获得初始前沿单元；经连通性聚类、去除小簇，并使用混合准则评分（Mixed Criteria Scoring）筛选出 n=4 个候选前沿点。
- **房间类型集合**：预定义 7 种常见室内房间：客厅、卧室、浴室、厨房、餐厅、办公室、走廊。
- **LLM 推理方式**：对每个候选前沿点的局部窗口内的观测物体集合 O，构造提示模板 `Prompt(O, r) = "A room containing ... is likely a ..."`，利用 GPT-2 计算语言建模损失作为兼容性得分（score = -loss），再经 softmax 得到房间类型概率分布 `P(r|O)`。该设计无需训练或标注，即可实现零样本房间语义分类。

### 2.3 中层模块：目标导向语义亲和力评分（Semantic Affinity Scoring）
- 构建常识知识库 `M: G → 2^R`，将目标物体映射到它最可能出现的房间类型集合，例如 `M(bed) = {bedroom}, M(tv) = {living room, bedroom}`。
- 对每个候选前沿点，基于其房间概率分布，计算目标物体与该前沿点的亲和力得分：
  `S_Affinity(fi)(g, O) = max_{r∈M(g)} P(r|O)`
  即取目标相关房间类型的最大概率值，确保对任一相关房间的强证据都能产生高分。

### 2.4 低层模块：路径规划与执行
- 最终前沿优先级分数为亲和力得分与几何得分的加权和：
  `S_fi = α * S_Affinity(fi) / max(S_Affinity) + (1-α) * S_MC(fi)`
- 选择得分最高的前沿点，使用快速行进法（Fast Marching Method）规划最短路径，并执行动作（前进、转向等）实现避障与移动。
- 上述过程循环进行，直到找到目标或任务终止（最大步数 Tmax=500）。

## 6. 主要结论与发现

- HRO 在 HM3D 上达到 **SR 53.0%、SPL 24.5%**，在 Gibson 上达到 **SR 84.0%、SPL 46.5%**，均超越所有对比方法。
- 相比基于 GPT-3.5 的 VoroNav 和 ESC，基于 GPT-2 的 HRO 在 HM3D 上 SR 分别高出 **11.0% 和 13.8%**，说明**更强的语言模型并不必然带来更好性能，合理的分层推理结构才是关键**。
- 与同为 GPT-2 的 L3MVN 相比，HRO 的层级“房间→物体”推理显著优于平面“物体→物体”关联，验证了分层空间认知建模的有效性。
- 消融实验表明：房间类型推理（+1.3% SR）和目标导向语义亲和力评分均贡献正向收益；引入真实语义分割后性能大幅跃升（SR 从 53.0% 到 64.9%），揭示**上游语义分割精度是当前方法的主要性能瓶颈**。

## 7. 优点

- **方法创新性**：首次将“房间类型”作为中间语义表征，构建完整的层级推理链（房间推理→区域决策→动作执行），更符合人类空间认知，填补了现有 LLM 导航方法缺乏层级建模的空白。
- **零样本与免训练**：无需任何任务特定微调或标注数据，直接利用 LLM 常识与预训练分割模型即可适应未知物体和场景，泛化性强。
- **模块化设计**：三个模块职责清晰、可插拔，便于后续替换或改进（如更换更强 LLM、接入更精确分割模型）。
- **实验验证充分**：在两大基准上与多种类型基线对比，并通过消融和逐类别分析揭示各模块贡献与误差来源，结论有说服力。
- **可解释性**：通过“物体→房间→目标”的推理过程，智能体的决策逻辑更透明，便于人机交互与错误分析。

## 8. 不足与局限

- **语义分割依赖**：实验结果严重依赖 Mask R-CNN 的分割质量，真实分割与预测分割之间差距显著（SR 相差约 12 个百分点），在复杂真实场景中分割噪声可能导致性能下降。
- **数据集覆盖有限**：仅测试了 Gibson（5 场景）和 HM3D（20 场景）两个数据集，未覆盖更广泛的室内环境（如 MP3D、RoboTHOR）或非家庭场景，泛化结论的普适性有待进一步验证。
- **房间类型集合固定**：预定义了 7 类常见房间，对开放式空间、特殊功能房间（如储物间、阳台）或酒店、办公室等非典型住宅场景适应性不足。
- **与并发工作对比缺失**：文中提及的 LROGNav 虽涉及房间-物体关系，但未作为基线进行实验对比，削弱了与最相关工作的直接对照。
- **算力与细节报告不足**：未报告推理时间、内存占用、单次 episode 的平均耗时等工程性能指标；也未给出多次随机种子的方差，统计显著性无法确认。
