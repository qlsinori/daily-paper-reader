## 摘要
视觉-语言导航（VLN）要求具身智能体理解自然语言指令，并根据时间排序的视觉观测预测动作。将多模态大语言模型应用于VLN需要视觉-语言对齐、紧凑的时间输入、动作空间接地以及在目标硬件上的稳定训练。本技术报告介绍了PGN（盘古导航器），一个基于OpenPangu-7B构建的离线VLN动作预测系统。训练分为两个阶段。首先，PGMM通过训练Q-Former和两层MLP投影器，将冻结的EVA-ViT-G/14视觉编码器与冻结的语言骨干对齐。其次，PGN利用五观测窗口、依赖epoch的时间采样以及“推理-然后-动作”的输出格式，使对齐后的模型适应专家导航轨迹；此阶段冻结对齐的视觉通路，并更新三个结构令牌嵌入和LoRA适配器。实现结合了混合精度计算、选择性FP32计算以及DeepSpeed ZeRO-2，运行在八块昇腾910B NPU上。在500条保留专家轨迹上进行的教师强制开环评估中，V9报告了62.29%的归一化动作匹配（NAM）和100.00%的非空率（NER）。这些指标量化的是离线专家动作对齐，而非闭环导航成功率；评估误差累积、路径效率和目标完成度仍是未来工作。

## Abstract
Vision-Language Navigation (VLN) requires an embodied agent to interpret a natural-language instruction and predict actions from temporally ordered visual observations. Adapting a multimodal large language model to VLN requires visual-language alignment, compact temporal inputs, action-space grounding, and stable training on the target hardware. This technical report presents PGN (Pangu Navigator), an offline VLN action-prediction system built on OpenPangu-7B. Training proceeds in two stages. First, PGMM aligns a frozen EVA-ViT-G/14 vision encoder with the frozen language backbone by training a Q-Former and a two-layer MLP projector. Second, PGN adapts the aligned model to expert navigation trajectories using five-observation windows, epoch-dependent temporal sampling, and a reasoning-then-action output format; this stage freezes the aligned visual pathway and updates three structural-token embeddings and LoRA adapters. The implementation combines mixed-precision computation, selective FP32 computation, and DeepSpeed ZeRO-2 on eight Ascend 910B NPUs. Under teacher-forced, open-loop evaluation on 500 held-out expert trajectories, V9 reports a 62.29% Normalized Action Match (NAM) and a 100.00% Non-empty Rate (NER). These metrics quantify offline expert-action alignment rather than closed-loop navigation success; evaluating error accumulation, path efficiency, and goal completion remains future work.

- 然而，将通用MLLM（尤其是7B规模模型）适配到连续导航任务中，面临四个核心挑战：
  1. 视觉特征与语言模型之间的对齐；
  2. 如何紧凑地表示时间上连续的观测；
  3. 如何将生成的文本“接地”到有限的动作空间；
  4. 在目标硬件（昇腾NPU）上保持训练稳定与高效。
- 论文提出PGN（Pangu Navigator）系统，基于OpenPangu-7B，通过两阶段训练实现视觉-语言对齐和导航任务适配，并报告了在离线、开环条件下的动作预测性能，强调其并非闭环导航成功率的证明。

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

### 2.1 整体框架
- PGN采用“冻结骨干 + 可训练适配器”的轻量微调模式：冻结视觉编码器、语言模型和视觉-语言对齐通路，仅更新少量参数，降低训练成本并保持预训练知识。

### 2.2 导航问题形式化
- 在每个时间步 \(t\)，输入为指令 \(I\) 和有序观测窗口：
  \[
  O_t = (o_{t-4s}, o_{t-3s}, o_{t-2s}, o_{t-s}, o_t)
  \]
  其中 \(s\) 为时间采样步长，窗口固定包含5帧观测。
- 动作空间为四个语义动作：\(\{forward, left, right, stop\}\)，其中前进0.25米、转向15度。
- 输出为“推理文本 + 规范动作”：
  \[
  P(r_t, a_t | I, O_t) = P(r_t | I, O_t) P(a_t | r_t, I, O_t)
  \]
  即先生成中间推理 \(r_t\)，再生成最终动作 \(a_t\)。

### 2.3 模型组件与特征处理
- 每个224×224的观测先由EVA-ViT-G/14提取patch级视觉特征；
- 32个可学习查询token通过Q-Former的交叉注意力生成固定大小的视觉表征；
- 两层MLP将768维的查询表征映射到OpenPangu-7B的4096维嵌入空间；
- 五个观测经同一视觉通路处理后，保持时间顺序拼接到语言模型输入；
- 引入三个结构token分别标记图像开始、图像结束和帧边界；
- 语言模型输入还包括导航助手身份提示和导航指令；
- 语言骨干通过LoRA适配器进行参数高效更新，而不做全模型微调。

### 2.4 两阶段训练流程
- **Stage 1：视觉-语言对齐（PGMM）**  
  在COCO和Visual Genome图像-文本对上训练Q-Former和MLP投影器，视觉编码器与语言骨干保持冻结，使视觉输入适配语言模型。

- **Stage 2：导航任务适配**  
  使用专家轨迹进行监督式行为克隆。冻结对齐后的完整视觉通路和基础语言模型，仅训练三个结构token嵌入和LoRA适配器。

### 2.5 数据采样与训练策略
- 数据采集：使用DAgger风格流程，但固定 \(\beta=1\)，即完全由专家策略产生所有动作标签，不做迭代式在线交互，本质是“专家数据 + 行为克隆”。
- 时间采样：窗口长度固定为5，但通过改变起始索引 \(i_{\text{start}} = e \bmod s\)（\(e\) 为epoch）在多个时间偏移间轮转，以增加时间多样性。
- 动作感知采样：在训练中使用 \((s, p)\) 组合，其中 \(p\) 为用转向/停止样本替换前向主导样本的概率，用于缓解动作类别不平衡。实际记录的三阶段配置为：
  - \((s,p) = (4,0.1)\)
  - \((s,p) = (6,0.6)\)
  - \((s,p) = (8,0.2)\)
- 优化实现：混合精度训练，个别FP16注意力掩码操作出现数值溢出时改用FP32；使用DeepSpeed ZeRO-2数据并行。

## 3. 实验设计：数据集、场景与基准

- **训练数据**：
  - Stage 1：Microsoft COCO 和 Visual Genome 图像-文本对，用于视觉-语言对齐预训练。
  - Stage 2：通过模拟器采集的专家导航轨迹，清洗后包含 **19,699条轨迹** 和 **1,567,487帧观测**。每条轨迹由自然语言指令和每步专家动作标注组成。
- **评测数据**：
  - 500条保留的专家轨迹（validation split），用于离线评估。
  - 评测同样采用教师强制（teacher-forced）方式：模型使用专家轨迹中的历史观测作为上下文，预测动作后不执行该动作获取下一观测，而是继续使用专家下一帧观测。
- **评测指标**：
  - **EM（Exact-string Match）**：生成响应与规范动作字符串完全一致的比例；
  - **NAM（Normalized Action Match）**：将“forward/left/right/stop”等表达归一化后与专家动作匹配的比例；
  - **NER（Non-empty Rate）**：生成了任意非空响应的比例。
- **对比方法**：论文未对比任何其他VLN方法（如R2R、VLN-CE上的SOTA模型），也没有与LLM/VLM基线系统比较，仅报告自身版本迭代结果（V3、V5、V6、V8、V9）。

## 6. 论文的主要结论与发现

- PGN成功将OpenPangu-7B适配到“离线VLN动作预测”任务，证明了7B级多模态大模型结合轻量适配可以产生较高的专家动作对齐度。
- 关键结果：

## 7. 优点

- **方法结构清晰**：两阶段训练（视觉对齐 → 导航适配）将通用多模态能力与任务特定能力解耦，便于模块化替换和复用。
- **参数高效**：冻结大部分模型，仅训练Q-Former、MLP、结构token和LoRA，在7B模型上显著降低显存和计算需求。
- **时间建模实用**：固定五帧窗口 + 步长轮转 + 结构边界token，是一种简洁的时序压缩方案，避免了长序列的高计算开销。
- **面向国产硬件适配**：在昇腾910B上解决FP16不稳定问题，采用选择性FP32和DeepSpeed ZeRO-2，展示了非NVIDIA平台训练大型多模态模型的可行性。
- **评测透明度高**：明确区分离线动作匹配与闭环导航成功，不夸大结果；保留并报告了原始版本演进数据，方便追溯。

## 8. 不足与局限

- **评测场景过于简化**：仅使用500条离线轨迹、4类离散动作（前进、左转、右转、停止）、固定增量（0.25m/15°），无法代表真实连续环境的复杂性和动态障碍物，也缺乏对指令多样性、视觉干扰的覆盖。
- **缺少闭环验证**：教师强制评估不反映错误累积、状态恢复、目标可达性等能力，不能与主流VLN基准（如R2R、VLN-CE）上的Success Rate或SPL直接比较。
- **无消融实验**：时间采样、动作感知采样、推理输出、身份提示等设计共同变化，无法判断各组件是否有效，以及其贡献大小。
- **数据采集不完整DAgger迭代**：文中提到β=1的专家数据收集，未利用在线学习或交互式校正，模型可能面临分布偏移（在专家轨迹上表现好，但自导航时出错）。
- **指标定义与报告相互不一致**：不同版本间EM/NAM/NER口径变化，V3数据不完整，V8/V9只保留汇总，缺乏逐动作错误统计，难以进行详细错误分析。
- **未与其他方法对比**：作为技术报告，缺少与已有VLN方法或多模态导航模型的同条件对比，无法定位其相对水平。
- **动作空间受限**：缺少转身角度控制、速度调节、后退等动作，距离真实应用仍有差距。
