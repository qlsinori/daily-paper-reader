## 摘要
连续环境中的视觉与语言导航（VLN-CE）要求智能体在低延迟执行动作的同时，保持长时间跨度的视觉历史以实现轨迹一致性。现有的基于视频的VLN方法通常难以同时满足这两个需求。为应对这些挑战，我们提出了MemVLN，一种新颖的VLN框架，以实时推理效率（14 FPS）实现了最先进的性能。MemVLN利用视觉编码器处理连续观测，并使用大语言模型（LLM）解释指令并生成动作。我们方法的核心是一种采用金字塔分辨率的情景记忆管理机制。该机制将计算集中在即时感知上，同时保留压缩的长期历史。作为该设计的补充，我们引入了程序性记忆，通过紧凑的原子级中层动作词汇来实现快速动作，从而绕过自回归解码延迟。在VLN-CE上的实验表明，MemVLN-4B在R2R中超越基线Qwen3-VL-4B架构5.8%的SR，在RxR中超越9.7%的SR，同时推理延迟实现了7倍的加速。

## Abstract
Vision-and-Language Navigation in Continuous Environments (VLN-CE) requires agents to maintain long-horizon visual history for trajectory consistency while executing actions with low latency. Existing video-based VLN approaches typically struggle to satisfy both demands simultaneously. To address these challenges, we propose MemVLN, a novel VLN framework that achieves state-of-the-art performance with real-time inference efficiency (14 FPS). MemVLN utilizes a visual encoder to process continuous observations and a Large Language Model (LLM) to interpret instructions and generate actions. Central to our approach is an Episodic Memory management that applies pyramidal resolutions. This mechanism concentrates computation on immediate percepts while retaining compressed long-term history. Complementing to this design, we introduce Procedural Memory for fast action with a compact vocabulary of atomic mid-level actions to bypass auto-regressive decoding latency. Experiments on VLN-CE show that MemVLN-4B surpasses the baseline Qwen3-VL-4B architecture by 5.8\% SR in R2R and 9.7\% SR in RxR, while achieving a 7$\times$ speedup in inference latency.

## 一、核心问题与整体含义

- **研究背景**：视觉与语言导航（VLN）要求智能体在连续环境中（VLN-CE）根据自然语言指令从起点导航至目标，且需处理长时间跨度的视觉历史以保证轨迹一致性，同时保持低延迟执行以支持实时控制。
- **核心痛点**：现有视频式VLN方法面临两难困境——固定帧采样（如仅取8帧）牺牲时间密度；视觉token压缩（如token merging）则破坏空间细节与现代架构（如M-RoPE、DeepStack）的兼容性。
- **研究目标**：在同时满足长时视觉历史保持与低延迟（实时性，≥10 FPS）的前提下，实现VLN-CE上的最优导航性能。
- **整体方案**：提出受生物记忆机制启发的 MemVLN 框架，以金字塔分辨率情景记忆管理视觉观测，以程序性记忆（快速动作模块）绕过LLM自回归解码瓶颈，最终实现14 FPS实时推理与SOTA性能的双重突破。

## 二、方法论

### 2.1 总体架构
- 以Qwen3-VL（4B/8B）为骨干，采用视觉编码器处理连续RGB观测，LLM理解指令并生成动作。
- 任务设定：每个时间步 t，输入当前观测 v_{t-1} 和历史观测 H_{t-1}，输出原子动作 a_t ∈ {move_forward, turn_left, turn_right, stop}。

### 2.2 情景记忆（Episodic Memory）：金字塔分辨率策略

- **观察注意力分析**：实验发现最近4帧占据全部视觉注意力权重的50%以上；最当前帧权重显著高于旧帧；注意力随时间衰减。这说明近期观测对决策起决定性作用，而早期观测多数被忽略。
- **为什么不做token merging**：现有方法的token merging在语义空间聚类token，破坏均匀2D空间网格，与现代位置编码M-RoPE和DeepStack框架不兼容。金字塔分辨率在像素空间下采样，保持严格均匀空间拓扑，无缝支持现代架构。
- **具体方案**：按时间距离将帧分为三个层级——immediate（立即）、short-term（短期）、long-term（长期），由两个时间边界B_short和B_long分隔，分辨率分别为512×512、256×256、128×128（默认配置），形成降序分辨率金字塔：
  - 近期帧：高分辨率，保持精细局部导航信息
  - 远期帧：低分辨率，压缩保留全局路径地标
  - 分辨率设置保证长期序列总token数不超过单帧立即分辨率token数
- **三种变体比较**：U型（首尾高分辨率，中间低）、降序型（早期高分辨率）、上升型（近期高分辨率）。实验确认**上升型最优**，因近期观测对即时决策最为关键。

### 2.3 程序性记忆（Procedural Memory）：快速动作模块

- **延迟分析**：自回归解码是主要瓶颈——首个token生成（pre-filling）耗时最长（约5200ms/170 tokens），后续token随数量线性增长（约360ms/10 tokens）；即便优化KV-cache，多token生成仍远超实时控制阈值。
- **核心方案**：将导航重定义为一个单次前向的中级动作预测任务。在输出词表上增加原子级中级动作token集合 A_aug（10个动作）：stop、前移25/50/75cm、左转15°/30°/45°、右转15°/30°/45°。每个token编码一个完整动作或短时动作序列，从而**完全绕过自回归迭代解码循环**。

### 2.4 训练目标与数据

- **目标函数**：采用标准交叉熵（CE）损失，监督单次预测的增强动作token：
  L = -(1/T) Σ_{t=1}^{T} log P(a*_t | F_t, I; θ)
  其中F_t为金字塔视觉特征，I为语言指令。
- **训练数据**：R2R、RxR及EnvDrop增强变体；ScaleVLN随机采样416K对（HM3D+Gibson）；557K人类导航轨迹；278K DAgger合成数据。

## 六、主要结论与发现

- **MemVLN达到SOTA性能**：MemVLN-8B在R2R上取得65.3% OS/58.4% SR，在RxR上取得66.0% SR/57.3% SPL，仅用单目RGB即超越依赖全景、深度、里程计的各种基线。
- **实时性突破**：快速动作模块实现单次前向动作决策，将推理从2 FPS加速至14 FPS（7×速度提升），同时SR性能还有1.0-2.1个百分点的提升——效率与精度双赢。
- **金字塔分辨率有效性**：在相同token预算下（保持总token数恒定），金字塔机制比无金字塔基线在R2R上SR +1.2、SPL +1.9；在RxR上SR +1.5、SPL +1.3。上升型最佳，验证了"近期观测最大化保留"的设计直觉。
- **数据扩展性**：训练数据规模与性能正相关，DAgger策略性交互数据贡献最大增益（RxR上OS +4.6%、SR +3.5%）。
- **跨数据集泛化能力**：仅用R2R训练即可在RxR上零样本达到47.9 OS/38.4 SR，超越NaVILA（34.3 SR）约12个百分点。
- **细节发现**：RxR上性能优于R2R，归因于RxR指令更详细、语义锚点更丰富。

## 七、优点

- **生物启发设计**：从认知科学中的人类情景记忆（时间锚定的经验回溯）和程序性记忆（技能自动化执行）获得灵感，映射为两套实用的工程模块，思路新颖且可解释性强。
- **直击核心瓶颈**：准确识别出自回归解码是VLN实时性瓶颈，用紧凑动作词表将其转化为单次前向预测，方案简单有效；同时用注意力分析支撑金字塔分辨率的设计决策，有理有据。
- **架构兼容性**：像素空间下采样（而非token merging）保证与M-RoPE、DeepStack等现代LVLM机制完全兼容，有前瞻性。
- **仅单目RGB输入**：不依赖深度、里程计、全景图，更贴近真实机器人部署条件，降低传感器依赖。
- **效率与性能兼得**：同步实现14 FPS实时推理和SOTA效果，打破VLN-CE领域"性能-速度"难以两全的局面。
- **系统性训练数据工程**：整合5种数据源（原始数据、增强数据、大规模合成数据、人类轨迹、DAgger交互数据），并检验各数据子集的独立贡献。

## 八、不足与局限

- **资源依赖**：训练仍需8×H200高端GPU集群，且推理依赖GPU加速；作者自述在轻量边缘设备或低功耗移动机器人上难以部署。
- **模型规模受限**：未验证在更大规模（如百亿/千亿参数）模型上的可扩展性。
- **基准覆盖有限**：仅在R2R-CE和RxR-CE的Val-Unseen划分上评估，未涉及更广泛的VLN-CE测试集（如Test-Unseen）或更多本体平台（如真实机器人、足式机器人）；虽有RxR验证，但仍局限于室内场景。

- **安全性验证不足**：未讨论真实物理环境中放大动作（如45°转向、75cm前移）带来的碰撞与安全事故风险。
