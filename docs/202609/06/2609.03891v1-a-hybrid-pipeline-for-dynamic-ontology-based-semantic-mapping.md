## 摘要
语义映射在机器人交互物体、操作和导航复杂环境的能力中起着关键作用。最常见的语义映射流水线包括几何映射与定位（SLAM）、感知、语义融合和语义表示。然而，较新的工作也在其应用中整合了一种先验知识形式，最值得注意的是知识图谱或语义场景图，以提高对环境的上下文理解。在本文中，我们提出了一种用于语义映射的混合流水线。我们的系统结合了使用单应性投影的外部校准相机进行几何映射和定位，并与对象检测、持久对象跟踪和本体驱动的语义更新相结合，以构建动态的语义世界模型。线性回归模型也用于修正真实世界坐标的估计值。系统基于实时传感数据持续更新对象实例、空间属性和语义关系。本体被选作知识表示的形式，因为它们具有层次结构、语义表达力和对动态世界建模的支持。

## Abstract
Semantic mapping plays a crucial role in the ability of a robot to interact with objects, operate and navigate a complex environment. The most common pipeline for semantic mapping consists of geometric mapping and localization (SLAM), perception, semantic fusion and semantic representation. However, more recent works also integrate a form of prior knowledge in their application, most notably knowledge graphs or semantic scene graphs, to improve contextual understanding of the environment. In this paper, we present a hybrid pipeline for semantic mapping. Our system incorporates an external calibrated camera using homography projection for geometric mapping and localization, combined with object detection, persistent object tracking and ontology driven semantic updates to build a dynamic semantic world model. Linear regression models are also used for correction of the estimated values of real world coordinates. The system continuously updates object instances, spatial properties and semantic relations based on real time sensory data. Ontologies are selected as form of knowledge representation due to their hierarchical structure, semantic expressiveness and support for dynamic world modelling.

- **现有方法的不足**：

  - 知识库通常是**静态**的，无法随实时传感数据动态更新；
  - 物体的空间位置在知识表示中往往被假定为固定不变，无法适应真实动态环境。
- **本工作目标**：构建一种**基于动态本体的语义映射混合流水线**，使外部相机感知到的实时信息能够持续更新一个具有推理能力的本体知识库，从而形成动态更新的语义世界模型。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 总体架构

系统由五个核心模块组成：

1. **外部校准相机（Tapo C501GW）** ：PoE/IP网络相机，悬挂于墙面3–3.5米处俯拍场景，采集实时视频流（RTSP协议），避免使用机器人自身相机的硬件限制；
2. **几何映射与定位**：基于相机标定、图像去畸变和**单应性变换（Homography）** 实现像素坐标到真实世界坐标的映射；
3. **对象检测**：使用**YOLOv11s**模型从视频流中检测10类实验室常见物体；
4. **机器人定位**：通过头顶**ArUco标记**检测NAO机器人的位置与朝向；
5. **本体驱动的语义更新**：本体作为先验知识与动态语义存储结构，每5秒根据新的观测数据动态更新。

### 2.2 关键技术细节

- **相机校准与去畸变**：基于棋盘格标定法（9×6棋盘格），利用OpenCV计算相机内参矩阵 K 和畸变系数，再通过 `getOptimalNewCameraMatrix()` 和 `undistort()` 对每帧图像进行去畸变处理；
- **单应性投影**：用户在去畸变图像中选取4个对应真实世界坐标的点（[0,0]、[180,0]、[180,240]、[0,240]），计算3×3单应矩阵 H，将任意图像坐标 (u,v) 变换为真实世界坐标 (x,y)，测试区域约180×240 cm²；
- **对象位置定义**：以检测框底边中点（物体与地面的接触点）作为对象位置；对ArUco标记则以四个角点均值作为标记中心；
- **线性回归坐标校正**：由于相机斜视角、透视压缩与残余畸变导致初始坐标估计误差较大（物体MAE：x轴5.3cm、y轴17.8cm；NAO机器人MAE：x轴17.7cm、y轴28.1cm），作者根据数据的高度线性关系（R²≈0.99），分别针对物体的x/y轴和NAO机器人的x/y轴建立了4个独立的线性回归模型进行校正，最终误差降至3cm以内，满足预设精度目标（MAE < 3cm，即测试区域对角线长度的1%）；
- **本体设计**：使用Protégé编辑器构建本体，包含35个类，分为"physical_entity"和"abstract_entity"两大子类。通过数据属性和对象属性实现对观测历史和当前状态的区分管理；本体初始不含人工创建的个体，所有个体均由系统动态添加、更新和删除；
- **动态更新策略**：

  - 每5秒处理一帧（引入帧延迟）；
  - 引入约5cm的位置变化阈值，避免检测抖动导致的本体频繁更新；
  - 多物体同类别共存时创建多个独立个体；
  - 利用最近邻匹配关联前后帧中同一物体；
  - 物体暂时缺失时不立即删除，连续多帧（3帧）缺失后才从本体移除；
  - "is_near_to"对称对象属性基于欧氏距离（阈值10cm）动态计算并更新，表示机器人与物体的任务级邻近关系。

### 2.3 核心公式

- 相机内参矩阵 K = [[fₓ, 0, cₓ], [0, f_y, c_y], [0, 0, 1]]
- 单应性变换：λ[x, y, 1]ᵀ = H·[u, v, 1]ᵀ
- 物体的图像坐标（2D检测框底边中点）：cₓ = (x₁+x₂)/2, c_y = y₂
- ArUco标记中心坐标：cₓ = (1/4)Σxᵢ, c_y = (1/4)Σyᵢ
- 线性回归校正模型示例：
  - 物体x轴：x_cor = 5.352 + 0.905·x_est（MAE=2.8cm）
  - 物体y轴：y_cor = −44.476 + 1.168·y_est（MAE=8.5cm）
  - NAO x轴：x_r_cor = 17.574 + 0.749·x_r_est（MAE=1.6cm）
  - NAO y轴：y_r_cor = 37.930 + 0.912·y_r_est（MAE=1.6cm）

### 2.4 运行算法流程

```
while RTSP stream is active do
  获取帧 → 去畸变 → 检测ArUco标记并估计机器人位姿 → 运行YOLOv11s
  对每个检测对象：像素坐标→真实世界坐标→回归校正→创建本体观测→更新本体
  帧延迟 → 清理丢失对象 → 计算is_near_to属性 → 保存本体
```

## 7. 方法优点

- **混合架构具有实用性**：无需依赖机器人搭载的昂贵传感器，外部PoE相机即可完成场景感知与定位；将经典几何方法（相机标定+单应变换）与现代深度学习方法（YOLO）有机结合，技术选型务实；
- **坐标校正方法简洁有效**：基于数据线性关系采用独立线性回归模型，轻量且可解释性强，针对不同对象（物体vs NAO机器人）和不同轴（x/y）分别建模，体现了细致的误差分析；
- **本体设计合理**：区分历史观测（observation）与当前状态（current_X/current_Y）两组属性，兼顾了时间历史和实时更新的需求；全部个体动态生成，无需人工实例化；
- **实验验证层次分明**：从误差测量→回归建模→同源数据校正→新数据泛化测试，形成较完整的精度验证链条；
- 明确设定了工程精度目标（MAE < 3cm），使系统性能有明确衡量标准。
