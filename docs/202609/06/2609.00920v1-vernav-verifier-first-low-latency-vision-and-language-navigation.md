## 摘要
视觉-语言导航（VLN）要求智能体根据自然语言指令在未见过的3D环境中导航。显式推理可以改善指令理解和语义基础，但每一步的自回归生成会在多步导航中累积较大的决策阶段延迟。我们提出了VerNav，一个用于低延迟基于LLM的VLN的验证器优先框架。验证器通过用批处理动作验证替代逐步自回归生成来降低决策阶段延迟，而基于熵的自适应生成器仅在不确定决策时被调用，以生成紧凑的状态证据。为了进一步提高验证器的导航性能，我们引入了一种两阶段对齐方案：（i）VPO改进了静态验证器训练中的局部动作偏好对齐，以及（ii）步级强化学习微调在动态任务执行期间为多步导航回滚提供密集的进展奖励。在Room-to-Room（R2R）基准上的实验表明，VerNav的纯验证器决策路径在代表性的基于LLM的VLN智能体中达到了具有竞争力的导航性能，同时与自回归方法相比，平均每步决策阶段的LLM延迟降低了超过$10\times$。

## Abstract
Vision-and-Language Navigation (VLN) requires an agent to navigate through unseen 3D environments according to natural-language instructions. Explicit reasoning can improve instruction understanding and semantic grounding, but autoregressive generation at every step accumulates large decision-stage latency over multi-step navigation. We propose VerNav, a verifier-first framework for low-latency LLM-based VLN. The verifier reduces decision-stage latency by replacing per-step autoregressive generation with batched action verification, while an entropy-based adaptive generator is invoked only for uncertain decisions to produce compact state evidence. To further improve navigation performance with the verifier, we introduce a two-stage alignment scheme: (i) VPO improves local action-preference alignment in static verifier training, and (ii) step-level reinforcement fine-tuning provides dense progress rewards over multi-step navigation rollouts during dynamic task execution. Experiments on the Room-to-Room (R2R) benchmark show that the verifier-only decision path of VerNav achieves competitive navigation performance among representative LLM-based VLN agents while reducing average decision-stage LLM latency per step by more than $10\times$ compared with autoregressive methods.

## 1. 论文的核心问题与整体含义

- **研究背景**:
  - **任务定义**: Vision-and-Language Navigation (VLN) 要求智能体依据自然语言指令在未知的3D环境中进行多步导航。近年来，基于大语言模型（LLM）的VLN方法因其强大的显式推理能力而备受关注。
  - **核心矛盾**: 这类LLM-based智能体为了提升指令理解和语义基础，往往在**每一步**都进行自回归的CoT（思维链）推理来生成导航决策。这种在每一步都进行完整生成的方式，在多步导航任务中会累积出**巨大的决策阶段延迟**，严重阻碍了实际应用。
- **核心研究问题**: **如何让LLM-based的导航智能体在高延迟的推理路径之外，拥有一条低延迟的决策路径，并且仅在当前决策确实需要额外语义线索时才触发昂贵的生成过程？**
- **整体含义**: 本论文从计算效率的视角重新审视了LLM在VLN中的角色，提出将“生成者”与“验证者”解耦。其核心思想是，LLM的绝大多数推理步骤都是冗余的，因此可以将默认决策路径设计为一种轻量、高速的“验证”过程，而非每一步都“重新生成”。这一范式为构建具备实时响应能力的具身导航智能体提供了新的可能。

## 2. 论文提出的方法论

论文针对上述问题提出了 **VerNav** 框架，其核心思想是**将动作选择问题从一个逐步的自回归生成问题，转化为一个批量的、可并行的验证问题**。该方法主要包含三个关键组件：

### 2.1 验证器优先的低延迟决策接口
- **核心思想**: 构建一个纯验证框架，不再让LLM逐字生成推理过程和动作，而是让LLM扮演一个“裁判”，对每一个候选动作进行打分。
- **技术细节**:
  - 在时间步 $t$，将指令 $I$、历史 $H_t$、候选视角描述 $D_t$ 和**单个**查询动作 $a$ 构造成一个验证指令 $\rho_t(a)$。
  - 将所有候选动作的查询指令组合成一个批次，通过一次前向传播，得到每个候选动作Yes token的logit值 $s_t(a)$，作为其验证分数。
  - 选择分数最高的动作作为最终决策。
- **初步发现**: 实验（表1）证明，这种"Raw Verifier"方法虽然延迟极低（0.05-0.08秒/步），但其成功率极低（<1%）。通过对现有方法生成的CoT token进行角色分解（表2），作者发现仅有约46%的token用于"输入重述"和"通用格式化"这类可复用的内容，而"状态更新"内容虽然占比约14%，但在相邻步骤间高度冗余。这表明，原始验证器并未具备导航所需的决策和状态更新能力，且这些能力无需每步生成。

### 2.2 熵触发的生成器-验证器协作框架
- **核心思想**: 解决验证器在复杂、不确定状态下决策能力不足的问题。通过引入一个基于熵的"开关"，来决定是否调用一个成本更高的生成器来提供补充信息。
- **技术细节**:
  - **不确定性度量**: 将验证分数 $s_t(a)$ 归一化为概率分布 $p_t(a)$，并计算其香农熵 $u_t$。熵越高，代表各候选动作的得分越接近，验证器对决策越不确定。
  - **触发机制**: 当熵 $u_t$ 超过预设阈值 $\gamma$ 时，才触发自适应生成器。
  - **生成器**: 生成器 $G_\phi$ 被调用，输入当前导航上下文，生成一个紧凑的状态证据摘要 $z_t$（如总结当前路线进度、观察到的地标等）。
  - **重新验证**: 将生成的证据 $z_t$ 与原始上下文一同拼接成新的指令，由验证器重新进行批量打分。

### 2.3 两阶段验证器训练对齐
- **核心思想**: 确保验证器的分数与导航任务的成功目标对齐。由于VLN是长时序任务，因此论文设计了一个静态+动态的两阶段训练方案，来分别解决“当前步动作偏好”和“长期轨迹优化”问题。
- **技术细节**:
  - **静态训练（VPO）**: Verifier Preference Optimization (VPO)，基于DPO的对比学习思想。从标注轨迹中构建“好/坏”动作对 $(a_t^+, a_t^-)$。例如，在**标准上下文**中，跟随路线标注的动作是正样本($a_t^+$)，其他为负样本($a_t^-$)。此外，还设计了**恢复上下文**，即假设智能体走错一步，然后如何纠错的动作对。训练目标是最大化正样本与负样本之间的分数间隔（使用ranking loss with margin）。
  - **动态微调（RFT）**: Step-level Reinforcement Fine-Tuning，使用GRPO风格的强化学习在策略诱导的rollout上进行训练。鉴于轨迹级奖励稀疏，论文设计了一个**步骤级的密集奖励**函数 $r^s_t$。该奖励结合了两个部分：
    - **基础进度奖励** $R_{s_t, base}$: 如果执行动作后离目标更近（$d_{t+1} < d_t$）或发现了新地标（$|\Delta F_t \cap L(I)| > 0$），则给予正向奖励。
    - **循环惩罚** $R_{s_t, loop}$: 如果执行动作后回到了已访问过的视角 (loop)，则给予惩罚。
    - 最终的动作价值函数结合了步骤级优势 $A_{step}$ 和回合级优势 $A_E$（基于任务是否成功）。

## 6. 论文的主要结论与发现

- **验证器优先可以大幅降低延迟**: VerNav的"验证器优先"决策接口通过批量验证替代逐步自回归生成，成功将决策阶段的每步LLM延迟降低至0.08秒，相比代表性的LLM-based方法实现了**超过10倍的加速**。
- **两阶段训练是性能的基石**: 原始验证器（Raw）几乎不具备导航能力，通过VPO（静态对齐）和RFT（动态强化）进行训练后，其成功率从0.38%提升至39.63% (val-unseen)，达到了与SOTA LLM-based方法相当的水平。
- **熵是可靠的不确定性信号**: 基于验证分数熵的触发机制能够在验证器真正“犹豫”时（即候选动作区分度低或轨迹更复杂）精准调用生成器。生成的紧凑证据能有效降低不确定性并提升决策质量（约+6-8% SR），证明了状态证据按需刷新的有效性。
- **效率与性能的平衡**: VerNav证明了在LLM-based的导航任务中，“效率”与“性能”并非绝对对立，通过将复杂的查询/推理/状态更新等过程分离、按需调用，可以找到一个极具吸引力的平衡点。

- **依赖强视觉特征提取器**: 论文将视觉观测转换为文本描述依赖外部视觉模型（如BLIP-2）。这一前置过程可能成为新的延迟瓶颈，决策阶段可能不是唯一瓶颈。此外，文本描述会不可避免地丢失视觉细节和空间关系，这可能是限制导航性能的瓶颈之一。
- **实验规模与基准时效性**: 主要对比的LLM-based基线方法较早期（多为GPT-4或LLaMA2时代），未与更新的前沿模型（例如基于GPT-4o、Qwen-VL或其他更新框架的低延迟方法）进行全面对比。缺乏在更具挑战性的基准（如REVERIE、R2R-CE或实际仿真器）上的验证，其泛化性有限。
- **生成器评估缺失**: 生成器（DeepSeek-V4-Pro）作为核心组件之一，其自身的延迟和成本没有纳入主实验的每步延迟统计（对比时称Ours为0.294s，但也可能是将生成器和验证器的整体推理时间混在一起导致的）。并未给出触发和不触发时的开销明细，这可能让读者对整体端到端延迟有误解。
- **风险与偏差**:
  - **奖励函数设计的主观性**: 设计的奖励函数（例如将“是否离目标更近”定义为奖励，或是“发现新地标”）是人为定义的简单代理指标，可能鼓励智能体在某些布局复杂的场景中产生行为偏差。
  - **评测协议的“统一”问题**: 论文中给定的自回归方法的延迟是在“统一决策阶段协议”下测量的，如果每个方法的提示词上下文构造方式不同（例如是1-shot还是5-shot），可能会导致公平性上的细微偏差。
- **应用限制**: 本文是在仿真环境的R2R数据上进行，其状态信息和动作空间是结构化的。验证器+选择器的模式是否能在真实世界的嘈杂传感器数据上同样有效，尚未得到验证。
- **状态证据生成与模型幻觉问题**: 生成器可能生成看似合理但其实并不存在的场景证据（幻觉），本文并未对这个在落地应用中非常关键的原生风险进行深入探讨。
