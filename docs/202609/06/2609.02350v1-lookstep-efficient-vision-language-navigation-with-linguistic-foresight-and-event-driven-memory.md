## 摘要
视觉-语言导航（VLN）要求具身智能体在未知环境中遵循自然语言指令。最近的进展主要由多模态大语言模型（MLLMs）推动。现有方法遵循下一步动作预测范式，仅监督专家动作，这需要大量数据进行训练。它们还依赖认知地图、累积的历史帧或外部3D工具来维护状态，导致较高的计算和内存开销。为了实现资源高效的VLN，我们提出了LookStep，一个统一的端到端框架，结合了以语言为中心的未来状态建模和事件驱动滚动记忆，利用语言标签为每个候选动作生成粗粒度的导航进度和未来状态，同时自主决定是否将每个观察结果以语义角色写入有界滚动记忆。我们通过实验验证了LookStep。在VLN-CE任务上，LookStep在相同训练设置下优于现有方法，在R2R-CE Val-Unseen上实现了49.7%的成功率，同时具有更好的内存效率和更少的数据使用。代码和模型可在https://github.com/kunyang-YU/LookStep获取。

## Abstract
Vision-Language Navigation (VLN) requires an embodied agent to follow natural-language instructions in unseen environments. Recent progress has been largely driven by Multimodal Large Language Models (MLLMs). Existing methods follow a next-step action prediction paradigm, supervising only the expert action, which requires a high quantity of data for training. They also rely on cognitive maps, accumulated historical frames, or external 3D tools to maintain states, leading to high computational and memory overhead. To realize resource efficiency VLN, we propose LookStep, a unified end-to-end framework that combines Language Centric Future State Modeling and Event Driven Rolling Memory that uses language labels to generate coarse-grained navigation progress and future states for each candidate action, while autonomously deciding whether to write each observation into a bounded rolling memory with a semantic role. We validate LookStep empirically. On VLN-CE tasks, LookStep outperforms existing methods under the same training settings, achieving a 49.7\% success rate on R2R-CE Val-Unseen with better memory efficiency and less data usage. Code and model is available at https://github.com/kunyang-YU/LookStep.

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 统一范式

LookStep 将导航决策建模为，在给定指令 I、当前观察 x_t 和历史观察 O_{t−1} 的条件下，让 MLLM 一次性预测三部分信息：

```
MLLM(I, O_{t−1}, x_t) = {P_t, M_t, a_{t+1}}
```

其中，`P_t`为语言中心的未来状态预测（Language Centric Future State Modeling, LFS），`M_t`为记忆管理决策（Event Driven Rolling Memory, EDRM），`a_{t+1}`为最终动作。该框架将传统的直接动作模仿分解为“先推理后果、再选择动作”的结构化过程。

### 2.2 语言中心未来状态建模（LFS）

**核心思想**：不再直接从上下文预测动作，而是先让模型为动作空间中的每个候选动作分配语言标签，描述其可能导致的未来导航状态，并估计当前粗粒度导航进度，再做最终动作判别。

- **进度标签（Progress）**：采用 `{start, early, middle, late, near_goal}` 集合描述当前处于整条轨迹的位置阶段。
- **候选动作后果标签（Outcome）**：针对当前动作空间中的每个候选动作，从预设集合（如 advance、start_turn、finish_turn、too_early、overshoot_goal、premature_forward、wrong_turn 等15种）中选出与专家轨迹映射的标签，表示该动作在真实环境中的语义后果。
- **结构化输出序列**：使用 `<progress>...</progress>` 和 `<outcomes>...</outcomes>` 标签组织语言序列，确保输出可解析、可约束。

**训练目标**：通过标准自回归交叉熵对所有标签同时监督，即一起预测进度、预期后果、动作、记忆标签。该设计强迫模型将动作选择“经由”未来状态推理完成，而非直接映射，从而将监督信号从“模仿”提升为“轨迹级因果推理”。

**理论保证**：论文提供了oracle-level互信息分析，从信息论上证明，未来状态标签F*可以降低动作预测的条件熵：
```
R*_base - R*_oracle-fsm = I(a_t+1; F_t | X_t) ≥ 0
```
即条件互信息不会减少，且当且仅当互信息>0 时严格降低动作的不确定性。该分析说明未来状态标签蕴含真实的动作判别信息——比直接监督动作监督信号更充分。

### 2.3 事件驱动滚动记忆（EDRM）

**核心思想**：维护一个固定容量（默认长度8）的滚动历史记忆队列，不统一采样，也不全量存取，而是让模型自主判断当前帧是否需要写入以及以何种“语义角色”写入。

- **写标签（MemoryWrite）**：`keep` 或 `drop`，决定当前观察是否进入长期记忆。
- **语义角色标签（MemoryRole）**：如 `start_view`、`turn_start`、`turn_end`、`post_turn_alignment`、`stop_evidence`、`goal_approach`、`recent_only` 等，对观察在导航进程中的角色定性。
- **在线滚动更新**：推理中当模型的 write 标签为 keep 时写入记忆队列；当队列超过容量时以 FIFO 淘汰最早条目。
- 该机制在测试时无需任何参数更新，可视为记忆空间中的在线自适应，显著提高了长期导航中的历史利用率且近乎零计算开销。

### 2.4 自动标签生成

所有中间标签均来自离线专家轨迹，基于确定性规则自动生成的，无需人工标注：
- 动作后果标签基于当前专家动作、所在转向段位置、以及后续 K=5 步的未来动作推断； counterfactual 标签（非专家选择的动作后果）通过规则构造；
- 进度标签根据轨迹中的相对位置划分；
- 记忆写及角色标签依据转向起止、转向后首次前进、STOP 前目标证据等事件触发。

## 6. 主要结论与发现

1. LookStep在R2R-CE Val-Unseen 取得了50%上下（具体49.7% SR，45.3% SPL）的成功率，在同样训练数据条件下高于NaVid、NaVILA*、StreamVLN等模型3~5个百分点，同时比JanusVLN显存降低一半、推理速度快约3倍。
2. 在仅使用单片RGB、无深度、无里程计、无3D几何工具、无额外外部数据情况的条件下，仍接近或持平（R2R）甚至保持相当竞争力（RxR，SR 46.9%）地正面竞争包含全景输入或VGGT外部工具的现有模型，说明高效的决策建模可部分弥补感知输入的简化。
3. **LFS与EDRM都不可或缺**。消融结果显示去掉LFS，SR降约2.8%；在推断期去除EDRM（换成固定均匀采样），SR大幅下降12.3%、SPL下降23%——表明语义性的记忆写入机制远比“多塞原始帧”更有利于长序列导航中的状态确认与停止决策。
4. EDRM模型能高准确率识别转向开始、转向结束、停止证据等关键事件（>99%），在未见场景中保持强一致性；启用语言未来状态标签后对候选动作的语义后果判断呈现出置信和指令相关性，验证了理论信息的可习得性。
5. LookStep 完全无需在线参数更新或模拟器交互即可应用，结合低显存和低延迟，展示了向低成本具身机器人导航系统转化的真正潜力。

- **扩展验证齐全**：包括可控对照、真实机器人视频/图片验证、以及HM3D-OVON迁移实验，从多个层面巩固核心索引。
- **写作清晰**：主文图表、对比表与附录提示信息完整，可复现性好（训练代码开源）。

## 8. 不足与局限

- **性能与极致效果仍有差距**：虽然显存大幅节省，R2R-CE绝对SR仍比JanusVLN +data低约11个百分点；论文明确承认，相比采用DAgger式交互或规模更大数据的方法仍存在性能上升空间。
- **真实性泛化受限于场景单一性**：真实实验只在一个工作室环境进行，目标距离单位（1米）的判定及衡量程序不够严格精细化。
- **方法与统计鲁棒性**：未报告置信区间或多个随机种子，关键实验只训练一次，较难完全排除偶发性；
- **信息压缩上限风险**：语言标签集合为固定离散集合，虽然约束输出稳定性较好，但描述复杂几何拓扑、空间关系 (如物体相对位置变化) 的表达，其容量仍有限，推理时亦无法完全消除中间预测误差对动作的连带影响。
- **时间抽象局限**：EDRM对细微但连续的状态漂移（如转身幅度过小/过大）未提供连续计数或步长反馈，对于这类“连续性失误”未见明显修复机制。
- **特殊环境适配性**：对细小目标、长走廊、对称结构或高度相似物体场景仍有失败案例（文中已承认），视觉相似物体混淆是一个开放挑战。
- **模型骨架的单点性**：所有实验均基于 Qwen3-VL 8B，并没有在1B/72B或更多不同架构上进行“方法无关性”的跨骨架验证。
