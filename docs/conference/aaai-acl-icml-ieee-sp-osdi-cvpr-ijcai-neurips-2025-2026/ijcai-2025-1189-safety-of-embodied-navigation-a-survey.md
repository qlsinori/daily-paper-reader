# 论文详细中文总结

## 1. 核心问题与整体含义

- **研究背景**：近年来，大语言模型（LLMs）的快速发展推动了具身人工智能（Embodied AI）的显著进步。具身导航（Embodied Navigation）作为具身AI的核心任务之一，要求智能体在陌生环境中通过感知、交互和适应，向指定目标移动。该技术广泛应用于机器人导航、自动驾驶等安全关键领域。
- **核心问题**：尽管具身导航系统具有广阔的应用前景，但其依赖的深度神经网络（DNNs）和LLMs存在固有的安全漏洞，容易受到对抗性攻击（adversarial attacks）。这些攻击可能使智能体误解环境、偏离正确路径，甚至与环境中的障碍物碰撞，造成严重的安全事故。
- **研究意义**：现有工作要么专注于防御方法，要么聚焦于安全基准构建，缺乏对具身导航安全性的系统性梳理。本文是**第一篇**系统研究具身导航安全问题的综述，围绕三个关键问题展开：
  - (1) 具身导航智能体面临哪些安全风险？
  - (2) 有哪些方法可以缓解这些风险、增强系统可靠性？
  - (3) 有哪些指标可以用于评估具身导航智能体的安全性？

## 2. 方法论

论文采用**分类学框架**（Taxonomy）对具身导航安全性研究进行系统梳理，分为三大板块：

### 2.1 攻击（Attack）

按照攻击来源与技术特征，将攻击划分为两类：

- **物理攻击（Physical Attack）** ：通过改变物理环境来误导导航感知。
  - **2D像素空间攻击**：早期攻击如Brown等人（2017）提出的通用对抗贴片；Chen等人（2018）在停车标志上施加对抗扰动。
  - **3D空间攻击**：利用期望变换（EOT）方法模拟旋转、缩放、模糊等真实世界变化，生成稳健的3D对抗样本，如对抗T恤（Xu et al., 2020）、3D对抗物体外观优化（Yang et al., 2024）、车辆全身伪装（Wang et al., 2021）等。
  - **多视角攻击**：针对导航任务中视角变化问题，采用多视角贴片攻击（Hu et al., 2023b; Chen et al., 2024）。
  - **对抗光线攻击**：利用投影仪、电磁信号注入、激光发射器等非接触手段干扰智能体感知（Hu et al., 2023a; Zhang et al., 2024b; Sun et al., 2024）。

- **模型攻击（Model-based Attack）** ：直接针对模型本身的安全漏洞。
  - **强化学习（RL）攻击**：利用强化学习优化攻击策略（Sun et al., 2024; Mu et al., 2024）。
  - **联邦学习（FL）后门攻击**：恶意客户端通过操纵本地训练数据来控制全局模型（Zhang et al., 2022）。
  - **LLM后门攻击**：通过基于词、场景、RAG等技术植入隐藏触发器（Jiao et al., 2024; Wang et al., 2024a）。
  - **LLM越狱攻击**：通过精心构造的提示词绕过安全机制，如基于语音交互的越狱（Zhang et al., 2024a）、简单词语后缀（Lu et al., 2024）、定向与非定向攻击（Liu et al., 2024）。

### 2.2 防御（Defense）

- **物理防御（Physical Defense）** ：
  - **被动防御**：包括对抗补丁检测与去除（Xu et al., 2023）、自然对抗贴片检测框架（Wu et al., 2024b）、小感受野CNN认证防御（Xiang et al., 2021; Xiang et al., 2024）。
  - **主动防御**：利用循环反馈与环境上下文主动对抗3D环境中的对抗补丁（Wu et al., 2024a），即**具身主动防御**（Embodied Active Defense, EAD）方法。
- **模型防御（Model-based Defense）** ：
  - **提示聚合机制（PBA）** ：通过分析视觉-语言对齐方差检测恶意客户端（Zhang et al., 2022）。
  - **LLM防御**：直接部署防御模型（如Llama-Guard-2、Llama-Guard-3、Harmbench），并探索提示级和模型级防御策略（Jiao et al., 2024; Lu et al., 2024）。

### 2.3 评估（Evaluation）

- **数据集分类**：按模型参数量分为经典模型数据集（如Li et al., 2023; Kim et al., 2024; Khanna et al., 2024; Li et al., 2024）和LLM数据集（如Choi et al., 2024; Zhu et al., 2024; Yin et al., 2024; Wang et al., 2024b）。
- **指标分类**：分为三类——
  - **基于人的评估**：直接引入人工判断，成本高但准确可靠。
  - **基于公式的评估**：使用预定义公式，核心指标包括：
    - 成功率（SR）= (1/M) Σ s_k
    - 按路径长度加权的成功率（SPL）= (1/M) Σ s_k · d_k / max(d_k, p_k)
    - 按片段长度加权的成功率（SEL）= (1/M) Σ s_k · d_k^a / max(d_k^a, p_k^a)
    - 目标条件成功（GC）= (1/M) Σ c_k / C
  - **基于模型的评估**：使用GPT-4等大模型评估执行计划的合理性和有效性（如Yin et al., 2024）。

## 6. 主要结论与发现

- **威胁分类体系**：具身导航面临的两大类安全威胁——物理攻击（环境因素）与模型攻击（模型自身漏洞）——各有多种具体实现方式，且两者有时结合使用。
- **防御与攻击的对齐**：防御方法的设计需与攻击类型相匹配。物理防御侧重对抗环境扰动，模型防御主要针对LLM的后门与越狱风险。
- **评估框架的必要性**：安全评估需综合考虑数据集、指标和评估方式的多样性。当前缺乏统一的评估标准，不同研究使用的数据集和指标各异，导致结果难以直接对比。
- **关键研究缺口**：
  - 动态复杂环境下的攻击/防御方法尚不成熟。
  - 多模态大模型的攻击策略研究不足。
  - 物理防御在具身导航中的研究非常有限。
  - 缺乏定量、统一的评估方法和验证框架（如鲁棒性阈值、理论性能边界）。
