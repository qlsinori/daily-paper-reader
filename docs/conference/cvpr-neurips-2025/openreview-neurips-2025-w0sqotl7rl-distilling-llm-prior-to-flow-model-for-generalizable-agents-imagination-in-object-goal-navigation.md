## Abstract
The Object Goal Navigation (ObjectNav) task challenges agents to locate a specified object in an unseen environment by imagining unobserved regions of the scene. Prior approaches rely on deterministic and discriminative models to complete semantic maps, overlooking the inherent uncertainty in indoor layouts and limiting their ability to generalize to unseen environments. In this work, we propose GOAL, a generative flow-based framework that models the semantic distribution of indoor environments by bridging observed regions with LLM-enriched full-scene semantic maps. During training, spatial priors inferred from large language models (LLMs) are encoded as two-dimensional Gaussian fields and injected into target maps, distilling rich contextual knowledge into the flow model and enabling more generalizable completions. Extensive experiments demonstrate that GOAL achieves state-of-the-art performance on MP3D and Gibson, and shows strong generalization in transfer settings to HM3D.

- **任务背景**：论文聚焦于 **物体目标导航（Object Goal Navigation, ObjectNav）** 任务。该任务要求智能体在**未知的室内环境**中，仅凭对指定物体类别的语义理解，通过探索与推理，自主定位并抵达目标物体所在的区域。
- **关键挑战**：由于智能体无法直接观察到整张地图，必须**"想象"（imagine）未观察区域**的语义内容——即根据已观察到的局部线索，推断房间布局、物体可能出现的空间位置等。这一能力被称为"智能体的想象力"。
- **既有方法的不足**：以往的主流方法采用**确定性判别模型（deterministic and discriminative models）**对局部语义地图进行补全。这类方法将语义地图补全视为一个回归问题，输出单一、确定的预测结果，其核心缺陷在于：
  - 忽略了**室内布局的固有不确定性**（例如：同一扇门背后可能是客厅、厨房或卧室，这是多模态、概率性的）；
  - 导致模型在**未知（unseen）环境**中泛化能力不足，难以应对训练集中未出现过的布局模式。
- **核心洞察**：室内布局虽存在不确定性，但并非完全随机。**大语言模型（LLM）**蕴含了丰富的常识性空间先验（例如"厨房通常在餐厅附近""沙发常出现在客厅"），这些知识可以作为引导智能体想象力的有效监督信号。论文由此提出将LLM的空间先验融入生成模型，以概率化方式补全语义地图。
- **整体含义**：这项工作从**判别式补全**转向**生成式补全**，并将LLM先验以可蒸馏的形式注入生成模型，从而提升智能体在未知环境中的布局泛化能力——这是对ObjectNav任务中语义地图补全范式的一次重要革新。

### 2. 提出的方法论（GOAL框架）

#### 核心思想
提出 **GOAL（Generative flow-based framework with LLM priors）**，一个基于**生成流模型（flow-based generative model）**的框架。其核心策略是：**将可观测区域的语义观测与LLM增强的全场景语义地图桥接起来**，对室内环境的语义分布进行概率建模，而非输出确定性补全。

#### 关键技术细节
1. **语义地图与观测编码**：
   - 智能体在环境中移动时构建**局部语义地图**（观测区域）。
   - 为了预测全局语义地图，需要一个条件生成模型：以当前观测为条件，生成完整的目标语义地图（全场景语义地图）。
2. **LLM空间先验的注入**：
   - 训练阶段，利用**大语言模型（LLM）**推断室内场景中可能存在的空间关系与物体布局先验（例如各物体类别之间的空间关联、房间功能分区等）。
   - 这些从LLM中提取的空间先验被编码为**二维高斯场（2D Gaussian fields）**——即每个可能的物体位置由二维高斯分布来表示其不确定性范围。
   - 随后，该高斯场被**注入目标语义地图**，为流模型提供稠密的空间监督信号。
3. **LLM先验蒸馏（Distillation）**：
   - 关键设计在于：**仅在训练阶段使用LLM先验**，通过蒸馏的方式将其"压缩"进流模型参数中。
   - 推理阶段不再需要调用LLM，因此避免了额外计算开销，同时模型已经内化了LLM的布局常识，从而实现对未见环境的**更泛化的语义补全**。
4. **概率化语义补全**：
   - 流模型通过可逆变换学习从简单分布（如高斯噪声）到目标语义地图分布的映射。
   - 在给定观测条件下，模型能够采样出**多种可能**的全场景语义地图，比判别模型更贴合室内布局的多模态特性。

#### 算法流程（文字描述）
- **训练阶段**：
  1. 智能体采集局部观测，构建当前语义地图。
  2. 利用LLM推断场景级空间先验 → 编码为二维高斯场。
  3. 将高斯场与目标语义地图融合作为训练目标。
  4. 流模型以观测为条件，学习语义地图的概率分布，并通过蒸馏机制将LLM先验编码进模型参数。
- **推理阶段**：
  1. 仅输入局部观测语义图。
  2. 流模型直接采样生成全场景语义地图分布，用于指导导航策略（如选择探索区域）。
