## 摘要
视觉-语言导航（VLN）已逐步从室内扩展到室外环境。然而，现有的户外VLN数据集仍依赖于固定的离散拓扑图进行构建，这无法与快速变化的真实户外环境保持一致，并阻碍了VLN智能体从模拟到真实的迁移。为解决这一局限，我们提出了DaViNCi（\textbf{D}yn\textbf{a}mic \textbf{Vi}sion-and-Language \textbf{N}avigation in \textbf{C}ont\textbf{i}nuous Environment），这是首个同时引入连续与动态因素的户外VLN数据集。智能体不仅能在户外环境中通过连续动作移动，还需处理不可预测的动态元素。该数据集包含六个不同地图，共6,933条轨迹。通过全面的对比实验，我们发现与先前数据集相比，在离散环境下DaViNCi上的成功率下降了超过10\%，而在连续设置中下降更为显著，这体现了DaViNCi的挑战性。此外，我们阐明了动作粒度与动态元素的影响。这些结果表明DaViNCi在推动户外VLN向更真实环境发展方面具有实用价值。网站：https://xzh0312.github.io/DaViNCi/。

## Abstract
Vision-and-Language Navigation (VLN) has progressively expanded from indoor to outdoor environments. However, existing outdoor VLN datasets still rely on fixed discrete topological graphs for construction. It fails to align with the rapidly changing real-world outdoor environments and impedes the sim-to-real transfer of VLN agents. To address this limitation, we propose DaViNCi (\textbf{D}yn\textbf{a}mic \textbf{Vi}sion-and-Language \textbf{N}avigation in \textbf{C}ont\textbf{i}nuous Environment), the first outdoor VLN dataset that simultaneously introduces both continuous and dynamic factors. The agent not only moves in the outdoor environment using continuous actions but is also required to handle unpredictable dynamic elements. The dataset encompasses six distinct maps with a total of 6,933 trajectories. Through comprehensive comparative experiments, we find that the success rate on DaViNCi decreased by more than 10\% in discrete environments compared to previous datasets. And there is an even greater decline in continuous settings, demonstrating the challenge of DaViNCi. Furthermore, we clarify the impact of action granularity and dynamic elements. These results demonstrate the practical value of DaViNCi in advancing outdoor VLN toward more realistic environments. The website is https://xzh0312.github.io/DaViNCi/.

### 1. 论文的核心问题与整体含义

- **研究背景**：视觉-语言导航（VLN）任务要求智能体根据自然语言指令进行视觉感知与路径规划。尽管 VLN 已从室内扩展至室外，现有户外 VLN 数据集（如 Touchdown、Talk2Nav）仍存在两大结构性问题：
  - **离散性**：依赖固定离散拓扑图约束智能体的运动空间，与真实车辆连续行驶的方式不符；
  - **静态性**：环境信息不随时间变化，无法模拟真实道路中行人、车辆等动态元素。
- **核心动机**：上述缺陷导致已有方法与真实户外驾驶场景之间存在较大 gap，阻碍模型从仿真环境向真实世界迁移（sim-to-real transfer）。
- **论文贡献**：提出 **DaViNCi（Dynamic Vision-and-Language Navigation in Continuous Environment）**，据称是**首个同时引入连续动作与动态元素**的户外 VLN 数据集，包含 6 个地图、6,933 条轨迹，推动户外 VLN 从离散、静态向连续、动态的范式转变。

### 2. 方法论

- **数据集构建流程**：
  - **场景选择**：基于 CARLA 仿真器，选取 6 个地图（Town01–Town05 与 Town10），覆盖乡村、城镇、高速、复杂城市道路等多种场景；
  - **路径生成**：在没有动态元素干扰的环境中，随机初始化自动驾驶车辆自由行驶，并以 1 秒间隔采集车辆位姿来生成连续的地面真值路径；
  - **指令生成与对齐**：录制第一人称驾驶视频，结合轨迹数据先提取转向事件作为先验约束，再利用视觉语言模型（VLM）生成导航指令；采用“数学量化 + 视觉语义生成”的两阶段策略，并辅以人工精修；
  - **视觉信息采集**：与先前数据集预存全景图不同，DaViNCi 在 agent 请求视觉信息时实时渲染第一视角图像，以满足动态需求；
  - **动态元素注入**：每条路径固定后，在仿真环境中随机生成自动驾驶车辆与行人，使相同路径在不同 trial 中呈现不同环境信息；
  - **质量控制**：剔除碰撞、违反交通规则的不合理路径，并对文本逻辑进行检查，最终保留 6,933 条高质路径。

- **连续环境基线方法（COVL-RL）**：
  - 基于强化学习的在线视觉-语言导航框架，输入为全局文本指令 $I$、当前视觉观测 $V_t$ 和历史轨迹上下文 $H_t$，输出动作 $a_t \sim \pi_\theta(a_t \mid I, H_t, V_t)$；
  - 历史上下文 $H_t = \{V_1, A_1, V_2, A_2, \ldots, V_{t-1}, A_{t-1}\}$；
  - 动作空间包含 7 种连续动作：sharp left / left / straight / right / sharp right / lane change / stop；
  - agent 的直接位置由动作推进，而非原地旋转，并且动态受实时路况监控约束，以保证遵守交通规则。

### 6. 主要结论与发现（续）

- **动态元素的干扰效应**：消融实验表明，注入动态元素（行人、车辆）后，agent 的成功率与平均导航误差均出现明显劣化，且动态元素数量越多（30 车 + 30 行人），性能下降越显著。这一结果直接验证了动态环境对导航决策的干扰是真实且不可忽略的，也侧面说明 DaViNCi 所引入的动态维度确实带来了额外挑战。
- **动作粒度的影响**：在步长消融中，5 m 步长在部分地图上表现出优于 3 m/4 m 的指标，但作者指出这一结果并非简单归因于“大步长更优”，而可能与地图拓扑结构、指令中转向点的分布密度以及动态障碍规避难度有关。3 m 步长因高频决策成本与累积误差放大，在多数场景中表现相对较差。
- **随机基线的对比意义**：COVL-RL 在 ANE 与 APC 上显著优于两种随机策略，说明该基线能够从语言指令中有效提取导航意图，而非依赖随机探索或简单的前向直行启发式。
- **跨地图泛化仍是开放难题**：在未见地图（unseen scenes）上，所有方法的性能均较训练地图大幅下滑，尤其是 Town02（仅 5.8% 成功率）与 Town05（6.3%）等场景，表明跨场景泛化能力依然是连续户外 VLN 面临的核心瓶颈。

### 7. 局限性分析

- **数据集规模的潜在争议**：虽然论文声称包含 6,933 条轨迹，但相对 CARLA 仿真器所能提供的近乎无限的环境采样空间，该规模在覆盖真实世界道路多样性（天气、光照、交规差异、突发交通事件等）上仍显不足；
- **指令生成的保真度问题**：尽管采用 VLM + 人工精修的两阶段策略，指令文本仍可能存在与视觉轨迹不完全对齐的噪声，且均匀分布的指令句式可能诱导模型“走捷径”（如仅依赖路名或全局方向而非局部视觉细节）；
- **动态元素的行为真实性有限**：CARLA 中的动态行人/车辆虽然具备基础运动能力，但与真实交通参与者（如手势交互、人类驾驶员博弈行为、非机动车不规则穿插）仍有差距，动态模拟的现实感有待增强；
- **缺少全面的跨数据集迁移评测**：论文验证了既有模型在 DaViNCi 上性能下降，却未验证 DaViNCi 上训练的模型能否迁移回 Touchdown/Map2Seq 等其他数据集，导致其对 sim-to-real 迁移的论证链条不够完整；
- **连续环境评估指标单一**：仅依赖成功率、平均导航误差等终点型指标，未引入如碰撞率、违规率、路径平滑度等安全与驾驶质量相关指标，难以全面反映真实驾驶安全性。

### 8. 创新点评估

- **范式层面**：首次将户外 VLN 从“离散 + 静态”推进到“连续 + 动态”，方向具有明确的现实意义与前瞻性；
- **数据层面**：引入实时按需渲染机制以支持动态环境，并采用两阶段 VLM 指令生成方案，在数据构建流程上有工程创新；
- **基线层面**：提出 COVL-RL 作为连续动态环境下统一评测的强化学习基线，为后续研究提供可复现的比较起点；
- **局限中的创新**：论文没有掩盖其主动放弃额外传感器（如 GPS、LiDAR）的做法，符合 VLN 任务“仅依赖视觉与语言”的设定，也强化了任务难度与纯度之间的权衡。

### 9. 个人思考与未来方向

- **未来工作可从多模态信息融合入手**：当前模型仅依赖视觉与文本，而真实驾驶还可利用方向盘转角、刹车/油门状态等低成本车载信号作为弱监督信号，辅助降低导航误差；
- **更细粒度的安全评估**：建议在连续动态环境中加入碰撞率、紧急制动次数、偏离车道时间等安全指标，以增强对实际部署安全性的衡量；
- **引入长尾场景扰动**：如大雨、夜间、施工区域等，才能使动态连续 VLN 更接近真实道路复杂度；
- **从强化学习迈向模仿学习或离线 RL**：连续动作空间中大范围在线探索成本高昂，可探索利用大规模预收集轨迹进行离线 RL 或行为克隆，以提升样本效率；
- **对动态元素建模的先验整合**：如预测行人轨迹、车辆意图的辅助模块，与导航策略协同训练，有望在动态环境下获得更稳健的决策。

综上，DaViNCi 在户外视觉-语言导航的数据范式上实现了重要突破，但当前基线性能与跨场景泛化仍远未成熟，后续在安全性评估、多模态融合与更丰富的动态仿真上仍存在较大改进空间。
