## 摘要
零样本目标导向导航（ZSON）在开放词汇场景中具有挑战性，因为它要求机器人在未经任务特定训练的情况下，在未知环境中定位任意指定的目标。目前，由于冗余的感知流程以及缺乏可靠确认目标的充分证据，该任务仍存在高延迟和精度受限的问题。在本信中，我们将ZSON重新定义为一种证据驱动的感知-决策问题，并提出AECNav，一种基于三个组件的免训练流程：i) 证据门控感知，利用所有推理阶段共享的编码来建立统一的语义基础并消除冗余计算；ii) 证据整合，将检测结果聚合成聚类级别的对数几率信念。这明确地将真实目标支持与视觉相似干扰物的虚假置信度区分开来，同时将预期检测的缺失视为负面证据；以及iii) 主动证据获取，通过选择以最小遍历成本最大化信息增益的前沿，在弱语义线索下维持有效的探索。因此，AECNav显著优于先前方法，在HM3D-v2、HM3D-OVON和MP3D上分别达到了84.7%、57.3%和51.3%的最先进成功率，同时推理开销大幅降低，并在物理四足机器人上以约5Hz的频率在40次试验中实现了95%的成功率。代码将在接收后公开发布。

## Abstract
Zero-shot object-goal navigation (ZSON) in open-vocabulary scenarios is challenging, as it requires a robot to locate an arbitrarily specified object in an unseen environment without task-specific training. Currently, the task still suffers from high latency and limited accuracy due to redundant perception pipelines and insufficient evidence for reliable target confirmation. In this letter, we reframe ZSON as an evidence-driven perception-to-decision problem and present AECNav, a training-free pipeline built on three components: i) Evidence-gated perception, which utilizes a shared encoding across all reasoning stages to establish a unified semantic basis and eliminate redundant computations; ii) Evidence consolidation, which aggregates detections into cluster-level log-odds beliefs. This explicitly separates genuine target support from the false confidence of visually similar distractors, while treating the absence of expected detections as negative evidence; and iii) Active evidence acquisition, which sustains productive exploration under weak semantic cues by selecting frontiers that maximize information gain at minimal traversal cost. As a result, AECNav significantly outperforms previous methods and achieves state-of-the-art success rates of 84.7%, 57.3%, and 51.3% on HM3D-v2, HM3D-OVON, and MP3D, respectively, with substantially lower inference overhead, and attains 95% success across 40 trials on a physical quadruped robot at roughly 5Hz. Code will be made publicly available upon acceptance.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

零样本开放词汇目标导航（ZSON）要求移动机器人在无任务特定训练的条件下，根据任意自然语言目标描述，在未知环境中定位并导航至目标物体。该任务面临两大核心挑战：

- **高延迟**：现有感知流程高度冗余，不同推理阶段（如前沿选择、目标确认）使用相互独立的视觉编码模型，导致同一观测被重复处理，推理开销巨大。
- **低准确性**：开放词汇下的目标确认缺乏可靠的证据积累机制。单帧高置信度检测可能来自真实目标、视觉相似的干扰物，或瞬时的误检，但现有方法难以有效区分这些情况。

此外，现有探索策略在弱语义线索下效率低下，常常导致机器人在低信息收益的前沿之间徘徊。

**本文的核心立场：**

作者将ZSON重新定义为"证据驱动的感知-决策问题"，主张通过统一的语义基础、持续的证据积累以及信息感知的主动探索，同时解决效率与准确性两大瓶颈。

## 2. 论文提出的方法论

### 核心思想

AECNav是一个免训练的端到端流水线，由三个紧密耦合的组件构成：

| 组件 | 核心功能 | 解决的问题 |
|------|---------|------------|
| 证据门控感知 | 共享C-RADIOv4编码器，按需触发分割 | 消除冗余计算，统一语义基础 |
| 证据整合 | 聚类级对数几率信念累积 | 区分真实目标与视觉相似干扰物 |
| 主动证据获取 | 综合考虑语义相关性与信息增益的前沿选择 | 弱语义线索下维持高效探索 |

### 关键技术细节

**① 证据门控感知**

- 使用单个C-RADIOv4编码器一次性提取场景级summary token和局部patch tokens；
- summary token经SigLIP2适配器与目标文本嵌入对齐，获得场景相关性评分并投影到俯视价值图（value map）；
- 当patch-level最大相似度超过阈值 τgate=0.08 时，才触发SAM3分割；否则跳过分割；
- 该机制可跳过约62.5%的SAM3调用，每步延迟降低约2.3倍。

**② 证据整合**

- 将分割检测结果反投影为3D点云，按几何邻近聚成空间簇；
- 每个簇维护对数几率信念 l(Ck)，采用累加式更新：

```
l(Ck) ← l(Ck) + Δlsem(Ck) + Δlmiss(Ck)
```

- **语义证据（Δlsem）**：同时用SAM3提示目标与LLM生成的干扰物类别（最多3个），根据目标分数与干扰物分数的比较，决定正向强化、负向抑制或保持不变；
- **缺失证据（Δlmiss）**：若簇具有正信念但在视野内未被检测到，则扣减信念，抑制假阳性；
- 停止决策要求信念超过阈值 τstop=1.0 且在5帧中连续满足≥2次，同时距离目标簇足够近，防止过早停靠。

**③ 主动证据获取**

- 当信念不足以做决策时，按综合效用选择前沿：

```
Ut(f) = S̃t(f) + λinfo·G̃t(f) − λdist·C̃t(f)
```

- 语义项 S 源自VLFM式价值图；
- 信息增益项 G 通过沿BFS路径采样视点、投射光线统计可见未知栅格数；
- 成本项 C 为最短可通行路径长度；
- 三者经min-max归一化后加权求和，默认 λinfo=1.0，λdist=1.0。

## 6. 论文的主要结论与发现

1. **导航精度显著提升**：AECNav在HM3D-v2上SR达84.7%（较SOTA提升6.6%），MP3D上达51.3%（提升5.9%），HM3D-OVON上达57.3%（提升9.0%），均取得最先进水平。

2. **推理效率大幅提高**：平均每episode仅需24.39秒，比VLFM快2.2×；步数减少33%以上，消除了大量冗余计算。

3. **证据整合的效果得到验证**：仅对数几率信念累积本身即可带来约10% SR提升（71.9%→81.9%），干扰物抑制与缺失检测分别额外增加1.8%和1.3% SR。

4. **信息增益与路径代价的配合是关键**：单独使用信息增益几乎无效（81.9% vs 81.8%），但与路径代价结合后效果显著（84.3%）；过度加权任一term会产生反效果。

5. **真实世界可用性**：在物理四足机器人上取得95%成功率，决策频率约5Hz，验证了方法的实际可行性。

## 7. 优点

- **统一的语义基础**：所有视觉推理阶段共享C-RADIOv4编码，既消除了模型间语义不一致，又大幅降低计算冗余，这是设计上非常优雅的整合。

- **证据驱动而非阈值驱动**：将对数几率信念引入目标确认，把"单帧识别"升级为"时序证据积累"，能自然应对干扰物与误检，理论框架严谨（受occupancy grid mapping启发）。

- **探索目标明确**：将前沿选择形式化为信息增益与遍历成本的联合优化，而非单纯依赖语义相关性，在弱语义线索条件下更鲁棒。

- **免训练、开箱即用**：不依赖任务特定的模型训练，依赖预训练基础模型（C-RADIOv4、SAM3、SigLIP2）和离线缓存的LLM生成干扰物类别，工程落地成本低。

- **实验报告相对完整**：同时覆盖模拟与真实场景，并提供了细致的延迟分析、门控阈值分析、组件消融和参数敏感性分析，透明度较高。

- **消融实验具有可解释性**：Table V展示了每种负面证据类型的功能分离，增量收益近乎可加，显示了模块设计的正交性。

## 8. 不足与局限

- **实验覆盖仍可扩展**：真实世界仅4个场景、8类目标，覆盖的物体类型和场景复杂度有限；模拟数据集中的目标类别与真实世界仍存在偏差（如真实实验中引入了"water refill station"这样超出基准词汇的类目，但数量偏少）。

- **统计效力与可复现性**：未提供多次运行的标准差或置信区间，部分对比（如trajectory量）可能在更大的随机种子下有所波动；参数扫描结果仅基于HM3D-v2，其最优权重（λinfo=1.0、λdist=1.0）在其他场景中的最优性未系统性论证。

- **对基础模型的依赖**：感知质量高度依赖C-RADIOv4、SAM3、SigLIP2等第三方模型的能力，模型版本迭代可能带来性能波动；未报告这些模型中各组成部分的中文或低资源语言适应性。

- **场景限制与Sim-to-Real差距**：模拟器中深度信息理想化，真实环境对传感器的噪声更敏感；虽在真实测试达到95%成功率，但失败案例揭示了关键问题——目标位于从未被前视相机观察到的角落时会被漏掉，且大开阔区域容易耗尽步数预算。

- **方法对参数较敏感的部分**：门控阈值τgate、证据权重(αsem, αmiss)、停止阈值τstop等超参数缺乏自适应性，若场景分布发生变化可能需要重新调整，论文对如何自动调节这些参数未给出方案。

- **应用限制**：当前系统假设目标是静态物体，对移动目标或可变形目标（如衣物）可能失效；同时导航依赖点目标策略的预训练能力，若底层策略较弱，上层框架的收益可能受限。

- **模型大小与部署资源**：虽然免训练，但C-RADIOv4和SAM3的体积较大，边缘端推理能力仍有限（文中运行在RTX 4090上）；对更轻量级平台（如嵌入式设备）的适配没有讨论。
