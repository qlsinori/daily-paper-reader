## 摘要
分层开放词汇目标导航（OVON）要求智能体在未知环境中遵循自由形式的指令，这些指令可能通过场景级、房间级、区域级和实例级线索来指定目标。尽管近期工作LangMap已将这一设定形式化，但在部分观测下可靠地解决该问题仍具挑战性：空间定位需要持久的场景级证据，而目标验证则需要清晰且具有判别性的候选视角。我们提出SAP-Nav，一个完全在线、零样本的框架，通过主动感知满足上述两项需求。SAP-Nav从主动获取的房间视角中增量构建可查询的空间语义表征，使得任意探索位置都能进行空间语义查询。它还采用主动视角验证机制来评估当前观测是否提供了充分证据，并在必要时将智能体重定位到更具信息量的视角，再依据类别和属性约束对候选目标进行验证。尽管SAP-Nav针对分层OVON设计，但它无需任务特定训练或预计算场景地图，即可同时支持分层和标准类别级OVON。在LangMap和HM3D-OVON上的实验表明，SAP-Nav取得了整体最佳性能，其中在区域级导航上相较于基于训练的方法SR提升了12.2%。真实机器人实验进一步验证了其实用可行性。代码将在论文被接收后公开。

## Abstract
Hierarchical open-vocabulary object navigation (OVON) requires agents to follow free-form instructions that may specify targets through scene-, room-, region-, and instance-level cues in unseen environments. Although recent work LangMap has formalized this setting, reliably solving it under partial observations remains challenging: spatial grounding requires persistent environment-level evidence, whereas target verification requires clear and discriminative candidate views. We present SAP-Nav, a fully online, zero-shot framework that addresses both requirements through active perception. SAP-Nav incrementally constructs a Queryable Spatial-Semantic Representation from actively acquired room views, enabling spatial semantic queries from any explored location. It further employs Active Viewpoint Verification to assess whether the current observation provides sufficient evidence and, when necessary, reposition the agent to a more informative viewpoint before verifying candidates against category and attribute constraints. Although designed for hierarchical OVON, SAP-Nav supports both hierarchical and standard category-level OVON without task-specific training or precomputed scene maps. Experiments on LangMap and HM3D-OVON show that SAP-Nav achieves the overall best performance, including a 12.2% improvement in SR over training-based methods on region-level navigation. Real-world robot experiments further demonstrate its practical feasibility. Code will be made publicly available upon acceptance.

## 1. 核心问题与整体含义

论文聚焦**分层开放词汇目标导航（Hierarchical Open-Vocabulary Object Navigation, OVON）** 问题。与标准 OVON 仅给定物体类别不同，分层 OVON 的指令可能同时包含场景、房间、区域和实例级线索（例如“找到客厅里白色装饰壁炉旁的黑色玻璃茶几”）。该设定更贴近真实人类导航需求，但给智能体带来了双重挑战：

- **空间语义定位**要求对探索过的环境形成持久、整体的房间级证据（例如判断“哪个房间是客厅”“是否存在两个客厅”）；
- **目标验证**要求获得清晰、具判别性的候选目标视角（例如区分“黑色玻璃茶几”和非目标物体）。

现有方法存在明显不足：依赖完整 3D 扫描的方法（离线预构建）不适用于在线部署；仅被动积累偶然观测的方法容易产生视角偏差，无法保证空间语义覆盖和验证可靠性。因此，论文提出 SAP-Nav，其核心思想是**通过主动感知，在 探索过程中同时获取空间语义证据和高质量目标视角**，从而在完全在线、零样本、无需预计算场景地图的条件下解决分层 OVON。

整体含义：该工作表明，主动感知（主动选择何时看、从哪看）是连接空间语义理解与目标验证的关键桥梁，为复杂语言指令下的具身导航提供了新的可行范式。

## 2. 方法论

### 2.1 总体架构

SAP-Nav 由两个主动感知模块组成：

1. **可查询空间语义表征（QSSR, Queryable Spatial-Semantic Representation）**
2. **主动视角验证（AVV, Active Viewpoint Verification）**

整体流程：视觉-语言引导的前沿探索 → 在线构建 QSSR → 候选目标与指令中的空间约束匹配 → 触发 AVV → 验证通过则接近目标，失败则黑名单化并继续探索。

### 2.2 QSSR：构建可查询的空间语义表征

QSSR 是混合表征，包含一个存储房间语义类型的空间语义 BEV 地图，以及一个将主动获取的房间快照与具体房间实例关联的视觉记录。构建过程分为三个阶段：

- **S1 在线房间分割**：基于障碍物地图，利用入口（门）投影在时间窗口内累积，将探索的自由空间划分为房间实例，并为每个房间记录进入方向。
- **S2 主动房间感知**：在三个时机主动获取全景房间快照：
  - 初始化：复用起始位置的全景图；
  - 首次进入新房间：面向房间内部旋转采集 N 帧并拼接成快照；
  - 扩展更新：当房间面积显著增大时，朝向新增区域采集新快照。
  
  每张快照由 VLM 预测房间类型，累积形成该房间的语义类型集合。

- **S3 子房间语义细化**：利用预训练场景编码器对图像 patch 产生房间类型概率，并通过静态先验限制到室内房间类型词汇表，将概率反投影到 BEV 网格并跨时间步累积，形成子房间语义概率场，以处理开放式或欠分割区域。

**空间语义查询**：候选物体的投影分割覆盖 BEV 网格后，QSSR 根据房间类型集合或累积概率场判断物体所在房间类型；若指令提及区域（特定房间实例），则使用房间快照进行 VQA 匹配。

### 2.3 AVV：主动视角验证

AVV 包含三个子模块：

- **充分性评估（SE）**：向 VLM 同时提供候选物体裁剪图和完整第一视角图像，分别评估两个标准——可见性（visibility）和视角质量（perspective），各自打分 1–5，总分 ≥ τ 则认为当前视角可验证，否则需重新选位。
- **视角选择（VS）**：
  - 围绕候选物体中心以 5 个半径（0.8m–2.4m）、24 个角度采样候选视角；
  - 过滤条件：处于已探索可通行区域、满足最小距离约束（避免低目标超出垂直视场）；
  - 基于在线 2.5D 高度地图进行射线投射，计算每个候选视角对目标覆盖区域的平均可见率，选择最优视角。
  
  最多重新定位 3 次；仍不满足则用历史最高分视角进行验证。

- **目标验证（TV）**：视角充分时，VLM 结合上下文确认类别；若指令含属性约束，先用 LLM 解析为结构化属性集合，再逐属性验证。被拒绝的候选加入黑名单，避免重复查询。

- 房间语义类型累积：

- **HM3D-OVON**（标准场景级 OVON 基准）：379 个开放词汇类别，Val Unseen 划分包含 3K+ episodes，49 个类别。

## 6. 主要结论与发现

- SAP-Nav 在 LangMap 所有粒度上取得最佳性能，在区域级导航上比最强的训练方法（PlaNaVid）提升显著（使用 Qwen3-VL-235B 时 SR 达 47.7%，较最强训练基线高 12.1 个百分点，对应论文标题中的 12.2% 提升）；
- 在标准 HM3D-OVON 上，SAP-Nav 以 49.7% SR 排名第一，证明其可泛化到非分层任务；
- QSSR 和 AVV 各自显著贡献：QSSR 的完整版本（S1+S2+S3）相比仅几何分割（S1）在 Room/Region 上分别提升 7.8% 和 6.6%；AVV 的 SE、VS、TV 三个组件均能提升成功率，且 SE 可缓解 VS 带来的路径效率下降；
- 主动感知（主动房间快照 + 主动视角重定位）优于被动观测，是解决分层 OVON 的关键；
- 真实机器人实验证明了方法在物理环境中的可行性。

## 7. 优点

- **完全在线、零样本、无预计算地图**：突破了传统方法依赖完整扫描或离线预处理的限制，更贴近真实部署；
- **双主动感知设计新颖**：同时针对“环境级空间语义”和“候选级目标验证”两阶段引入主动视角控制，两者互补；
- **统一框架**：既能处理分层 OVON，也能直接用于标准 OVON，无需修改；
- **模块化、可解释**：QSSR 和 AVV 职责清晰，消融实验证明每个组件都有正贡献；
- **鲁棒性机制**：黑名单避免重复验证，首次入场/扩展触发快照采集，SE 判断避免不必要的重定位，这些设计提升了实际可用性；
- **验证充分**：大规模仿真基准 + 真实机器人，对比方法覆盖 SOTA 训练方法和训练无关方法。

## 8. 不足与局限

- **路径效率受损**：AVV 主动重定位会增加移动距离，导致 SPL 低于某些高效方法（如 NavFoM、MetaNav），论文将其解释为可靠性优先的合理取舍，但并未尝试优化；
- **视角选择基于几何可见性**：未考虑语义信息量、运动成本或视角美学，可能选择“能看到但不一定能判别”的视角；
- **QSSR 不能跨任务保留**：每个 episode 重建，无法进行终身学习或知识复用；
- **真实实验缺乏定量指标**：仅展示定性案例，无法量化真实环境中的成功率或失败模式；
- **VLM 依赖性强**：性能随骨干模型规模显著提升（7B→9B→235B），但论文未分析模型规模与其他模块的交互作用，也未报告推理延迟/计算成本；
- **部分观测下的房间分割不保证鲁棒**：依赖门检测的时间窗口累积，开放式布局或门缺失时可能分割错误，影响后续所有语义查询；
- **属性解析与验证均依赖 LLM/VLM 能力**：对于长尾属性或模糊描述，可能产生错误解析或误判，论文没有专门分析这类失败案例。
