## 摘要
层次化开放词汇目标导航（OVON）要求智能体遵循自由形式的指令，这些指令可能通过场景级、房间级、区域级和实例级线索在未见环境中指定目标。尽管最近的工作LangMap已经形式化了这一设置，但在部分观测下可靠地解决它仍然具有挑战性：空间定位需要持久的环境级证据，而目标验证需要清晰且有区分度的候选视图。我们提出了SAP-Nav，一个完全在线、零样本的框架，通过主动感知同时满足这两个要求。SAP-Nav从主动获取的房间视图逐步构建可查询的空间语义表示，从而能够从任何已探索位置进行空间语义查询。它还采用主动视点验证来评估当前观测是否提供了足够的证据，并在必要时将智能体重新定位到更具信息量的视点，然后根据类别和属性约束验证候选对象。虽然是为层次化OVON设计的，SAP-Nav无需任务特定训练或预计算场景地图即可支持层次化和标准类别级OVON。在LangMap和HM3D-OVON上的实验表明，SAP-Nav取得了整体最佳性能，包括在区域级导航中成功率（SR）比基于训练的方法提高了12.2%。真实机器人实验进一步证明了其实用可行性。代码将在论文接收后公开。

## Abstract
Hierarchical open-vocabulary object navigation (OVON) requires agents to follow free-form instructions that may specify targets through scene-, room-, region-, and instance-level cues in unseen environments. Although recent work LangMap has formalized this setting, reliably solving it under partial observations remains challenging: spatial grounding requires persistent environment-level evidence, whereas target verification requires clear and discriminative candidate views. We present SAP-Nav, a fully online, zero-shot framework that addresses both requirements through active perception. SAP-Nav incrementally constructs a Queryable Spatial-Semantic Representation from actively acquired room views, enabling spatial semantic queries from any explored location. It further employs Active Viewpoint Verification to assess whether the current observation provides sufficient evidence and, when necessary, reposition the agent to a more informative viewpoint before verifying candidates against category and attribute constraints. Although designed for hierarchical OVON, SAP-Nav supports both hierarchical and standard category-level OVON without task-specific training or precomputed scene maps. Experiments on LangMap and HM3D-OVON show that SAP-Nav achieves the overall best performance, including a 12.2% improvement in SR over training-based methods on region-level navigation. Real-world robot experiments further demonstrate its practical feasibility. Code will be made publicly available upon acceptance.

## 2. 论文提出的方法论

### 2.1 核心思想

SAP-Nav 的核心思路是将"主动感知"应用到两个互补阶段：
1. 构建**可查询空间语义表示**（Queryable Spatial-Semantic Representation, QSSR），提供环境级空间语义证据；
2. 执行**主动视点验证**（Active Viewpoint Verification, AVV），在验证候选目标前主动获取信息量充足的观测视角。

### 2.2 整体流程

给定自然语言指令 `G`（任意粒度）、RGB-D 观测、里程计位姿，SAP-Nav 通过以下流程运作：
- 使用视觉-语言引导的前沿探索（VLFM 风格）导航环境；
- 在探索过程中在线构建 QSSR；
- 每当检测到候选目标，查询 QSSR 判断该候选是否满足指令中的空间约束（房间/区域级）；
- 仅对空间一致的候选触发 AVV，主动改善视角并进行细粒度验证；
- 被拒绝的候选加入黑名单，恢复探索；被接受的候选则直接逼近。

### 2.3 可查询空间语义表示（QSSR）

QSSR 是混合表示，由两部分组成：
- **空间语义 BEV 地图**：每个网格单元存储房间类型语义；
- **视觉记录**：将主动获取的整体房间快照与对应房间实例关联。

构造过程分三个阶段：

- **S1——在线房间分割（Online Room Segmentation）**：在在线障碍物地图上，通过在时间窗口 m 帧内累积门投影来划分房间实例。每个门边界标志进入新房间，并提供向内方向用于捕捉整体房间快照。
- **S2——主动房间感知（Active Room Perception）**：将每个房间实例 `Rk` 关联到一组语义类型 `Ck` 和视觉记录 `Vk`（即 `Rk → (Ck, Vk)`）。在三种条件下获取快照：
  1. **初始化**：复用开局全景图作为起始房间的初始观测；
  2. **首次进入**：智能体沿门的内向法线面向房间内部，原地旋转捕获 Nv 帧并拼成房间快照；
  3. **扩展更新**：当已分类房间面积显著增长时，朝向新探索部分质心获取新拼接视图。
  
  每个房间快照 `vkn` 输入 VLM 预测语义类型 `ckn`，预测结果累积为：
  
  ```
  cnk = VLM_cls(vnk),  Ck = { c_nk | v_nk ∈ Vk }
  ```

- **S3——子房间语义细化（Sub-Room Semantic Refinement）**：使用预训练场景编码器 ϕ（如 Places）产生逐图像块房间类型 logit，通过室内房间类型词表 T 约束后，反投影到 BEV 网格，随时间累积得到子房间语义概率场：

  ```
  Φt(u) = Σ_{i=1}^{t} φ̃ᵢ(u)
  ```

  这有助于在开放式或欠分割空间中区分不同功能区域。

**空间语义查询**：当检测到候选物体 o 时，通过其分割足迹覆盖的 BEV 单元 U(o) 查询 QSSR，确定候选所在房间类型 ĉ(o)；若指令涉及区域约束，则使用 Vk 进行 VQA 判断房间实例是否匹配。

### 2.4 主动视点验证（AVV）

AVV 包含三个组件：

- **充分性评估（Sufficiency Evaluation, SE）**：从两个标准评估候选对象是否可被可靠验证：
  - **可见性**：候选是否清晰可见；
  - **视角**：视角是否揭示足够的判别细节。
  
  将候选裁剪图和完整第一人称图像同时输入 VLM，分别打分（1–5），总分 s ∈ {2, ..., 10}。若 s < τ，则认为当前视角不足。

- **视点选择（Viewpoint Selection, VS）**：当需要更优视角时：
  1. 以候选分割足迹中位点 c 为中心，沿同心圆（半径 0.8–2.4 m，24 个方向角）采样视点候选；
  2. 过滤条件：位于可导航已探索空间；满足自适应最小距离约束（保证目标在垂直视野内）；
  3. 通过维护在线 2.5D 高度图，对视点执行射线投射可见性评分；
  4. 选择可见性得分最高的视点：

  ```
  v* = arg max_{v∈V} (1/|U(o)|) Σ_{f∈U(o)} vis(v, f)
  ```

  到达新视点后重新评估充分性；若三次重定位后仍不足，则使用已收集的最高分观测进行验证。

- **目标验证（Target Verification, TV）**：充分性达标后，将高亮候选区域及其周围上下文输入 VLM，判断是否匹配目标类别；若指令含属性约束，先用 LLM 解析为结构化属性描述集，再让 VLM 逐属性验证，所有属性满足才接受候选。

## 6. 论文的主要结论与发现

1. **性能最优**：SAP-Nav 在 LangMap 四个粒度级别上均达到最佳 SR；使用 Qwen3-VL-235B-A22B-thinking 时实现全粒度 SOTA；
2. **无需训练即可超越训练方法**：使用 Qwen3.5-9B 即超过最强基于训练的方法 PlaNaVid；在区域级 SR 上较训练方法**提升 12.2%**；
3. **跨任务泛化**：为主任务设计的 SAP-Nav 在标准 HM3D-OVON 上也取得**最高 SR（49.7%）**，证明其在类别级 OVON 上同样有效；
4. **每个模块都有贡献**：QSSR 的三个阶段按序组合逐步提升房间级和区域级 SR；AVV 的三个组件（SE、VS、TV）各有增益，其中 TV 贡献最大；
5. **效率与可靠性的权衡**：AVV 主动重定位增加了路径长度、降低了 SPL，但显著提高目标识别可靠性——论文认为在真实应用中成功找到正确目标比路径效率更重要；
6. **主动感知的价值**：被动观测不足以支撑层次化 OVON；主动获取整体房间快照和主动选择验证视点是可靠完成任务的关键。
