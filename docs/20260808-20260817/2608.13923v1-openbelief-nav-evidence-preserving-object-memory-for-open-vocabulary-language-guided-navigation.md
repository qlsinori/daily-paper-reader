## 摘要
开放词汇3D场景图为语言引导导航提供了紧凑的语义记忆，但映射对象通常通过单个融合特征或提交的语义标签来暴露。这种提交可能会从任务时接口中移除少数但任务相关的假设。我们提出了OpenBelief-Nav，一种保留证据的对象记忆，它保留观察级短语、可靠性提示和帧掩码来源，同时维护单独的聚合几何与视觉表示。语义相关的短语被合并为与词汇无关的对象信念，任务特定的读取器从中执行固定词汇投影或自由形式检索。在五个ScanNet200和八个Replica场景上，全信念投影的mIoU分数分别为0.2742和0.2912，而匹配的早期提交读取方案为0.2393和0.2701。在78次HM3D-YCB导航试验中，共识和早期提交检索各达到60/78次成功，而信念加权检索为58/78次，DualMap为55/78次。在20次Unitree G1运行中，组织为10个匹配的评估案例，允许最多两次验证候选尝试的纠正策略将目标确认成功率从6/10提高到8/10，相对于仅top-1执行。代码将在接受后发布在https://openbelief-nav.github.io/。

## Abstract
Open-vocabulary 3D scene graphs provide compact semantic memory for language-guided navigation, but mapped objects are often exposed through a single fused feature or committed semantic label. Such commitment can remove minority yet task-relevant hypotheses from the task-time interface. We present OpenBelief-Nav, an evidence-preserving object memory that retains observation-level phrases, reliability cues, and frame-mask provenance while maintaining separate aggregate geometric and visual representations. Semantically related phrases are consolidated into a vocabulary-independent object belief from which task-specific readouts perform fixed-vocabulary projection or free-form retrieval. On five ScanNet200 and eight Replica scenes, full-belief projection achieves mIoU scores of 0.2742 and 0.2912, compared with 0.2393 and 0.2701 for a matched early-commit readout. Across 78 HM3D-YCB navigation trials, consensus and early-commit retrieval each achieve 60/78 successes, compared with 58/78 for belief-weighted retrieval and 55/78 for DualMap. Across 20 Unitree G1 runs organized as 10 matched evaluation cases, a correction policy permitting at most two verified candidate attempts improves target-confirmation success from 6/10 to 8/10 relative to top-1-only execution. Code will be released upon acceptance at https://openbelief-nav.github.io/.

### 1. 论文的核心问题与整体含义

**研究背景与动机：**

- 语言引导导航要求机器人将自然语言概念（如“带我去灭火器”）锚定到持续的空间记忆中。
- 现有的开放词汇3D场景图（如ConceptGraphs、HOV-SG、FSR-VLN、DualMap）提供紧凑的语义记忆，但其任务时接口**主要依赖单一聚合描述符、选定视图或共识对象状态**，而非暴露多个语义假设供读取。
- 这种“早期语义承诺”（Early Semantic Commitment）存在三个关键后果：
  - **证据丢失**：不同视角对同一物体的描述可能不一致（因遮挡、距离、分割噪声或基础模型不确定性），主导标签可能错误，而正确概念仍存于观测历史中，却已无法恢复。
  - **单一读取并非最优**：封闭词汇分割需要投影到固定标签集，导航检索需要接地自由形式查询，不同任务需要不同的语义读取方式。
  - **最高排名目标在执行中仍是假设**：语义上合理的节点可能是干扰物，或无法从到达观测中确认。机器人需要验证并对失败情况重新接地。

**核心贡献（整体意义）：**

- 该论文的核心论点：**语义承诺的时机应被延迟**——即语义决策不应在建图过程中完成，而应在任务时和工作流中根据需求动态计算。
- OpenBelief-Nav 提供了一种**证据保留的对象记忆**（evidence-preserving object memory），将对象节点视为“证据的仓库”而非“决策的终局”，使得多个下游任务能够基于同一份存储证据以不同方式消费语义信息，并支持物理执行中的查询特定候选纠正。

### 2. 论文提出的方法论

**总体框架：**

OpenBelief-Nav 是一个对象级开放词汇语义记忆框架，其核心是**延迟语义承诺**（delayed semantic commitment）。整个方法分为四个阶段：证据获取、几何–视觉关联、信念构建、任务时读取与执行验证。

**2.1 对象节点表示**

每个对象节点 Bi 存储完整证据而非单一决策：

```
Bi = {Pi, fᵥᵢ, Oi, Vi, pi, fᵗᵢ, ρi}
```

- Pi：点云（聚合几何）
- fᵥᵢ：聚合视觉嵌入（独立维护）
- Oi：语言观测列表（保留观察级短语、可靠性线索、帧–掩码来源）
- Vi：概念证据向量
- pi：归一化相对支持分布
- fᵗᵢ：共识文本特征
- ρi：信任状态（trusted / degraded）

关键**分离不变性**：视觉通道与语言通道独立维护，在映射期间永不破坏性融合，所有跨模态融合延迟到任务时读取。

**2.2 多模态证据获取**

- 视觉–语言模型（Qwen3-VL-4B-Instruct）为每帧提出对象短语。
- SAM 3 将短语接地为掩码，每个掩码保留其产生短语、帧索引、掩码索引、分割置信度、有效点数、反投影点云和归一化视觉特征。
- 单位观测为 oe = (je, le, ce, ne, Pe, fᵥₑ)——即单个观测，而非一个对象。

**2.3 几何–视觉对象关联**

- 采用保守的基于几何的关联策略，视觉相似性仅用于拒绝不一致匹配：
  - oe ~ oe′ ⟺ Ωr(Pe, Pe′) ≥ τg ∧ ⟨fᵥₑ, fᵥₑ′⟩ ≥ τv
- 对象实例作为该关系的连通分量形成。
- 偏向高精度关联（避免错误合并造成不可逆的证据混杂），而非高召回。

**2.4 证据保留的语义信念构建**

- **可靠性权重**：we = ce·√ne（利用分割置信度和3D支持的平方根，因VLM短语无可用逐对象置信度）。
- **同义词感知概念整合**：将语义相似短语嵌入共享文本空间并聚类为对象级概念假设，公式为：Vik = Σ(we)，避免同义词造成的票数分裂。
- **低证据正则化**：Dirichlet启发式对称伪计数平滑：pik = (Vik + α) / (ΣVij + αKi)，保留竞争假设的非零支持；同时设 ρi = degraded 当观测数小于 m_min。
- **共识文本特征**：fᵗᵢ = normalize(Σ pik·gik)，作为评分摘要但非替代底层信念。

**2.5 任务时语义读取**

三种自由形式检索读出（查询 q 的归一化嵌入 fq）：

| 读出 | 公式 | 含义 |
|------|------|------|
| 共识（Consensus） | Hᶜᵒⁿᵢ = ⟨fᵗᵢ, fq⟩ | 信念加权共识特征 |
| 早期承诺（Early-commit） | Hᵉᵃʳˡʸᵢ = ⟨gᵢₖ⋆ᵢ, fq⟩ | 仅最高支持概念 |
| 信念加权（Belief-weighted） | Hᵇᵉˡᵢ = Σ pik·⟨gik, fq⟩ | 全信念加权 |

对象得分：S⁽ʳ⁾ᵢ(q) = λᵢ⟨fᵥᵢ, fq⟩ + (1−λᵢ)H⁽ʳ⁾ᵢ(q)，其中 λᵢ 根据语言证据是否存在、信任状态调整（无语言时为1.0，degraded为0.7，trusted为0.2）。

固定词汇投影（延迟承诺）：保留概念信念 pi，待基准词汇已知后，用视觉证据在保留的语义支持内重排序（支持保留性修正），再通过概念到类亲和度投影到基准标签集：bpᵢ(c) = (1−λvis)·Σ epᵢₖ·Wikc + λvis·vi(c)。视觉证据仅能在保留假设内提升次要假设，不引入新概念。

**2.6 执行接地的候选纠正（Algorithm 1）**

- 检索到的目标节点被视为**假设**而非已确认目标。
- 到达后获取局部RGB-D观测，执行三项顺序检查：可见性检验（不足时一次有界重观测）、语义检验（查询–掩码相似度）、几何检验（掩码与存储候选重叠度）。
- 不通过即加入查询特定排除集（Rq），**原查询不改变**，在剩余映射候选中重新接地；持久图不修改；最多尝试 Kmax 次。
- 终止条件：候选确认 / 无未尝试候选 / 达到预算。
- 明确不执行：缺失目标推断、一般动态图修复、位置不在图中的目标恢复。

### 6. 论文的主要结论与发现

1. **延迟语义承诺改善固定词汇分割**：在 ScanNet200 上，全信念投影 mIoU 达 0.2742，优于早期承诺投影（0.2393）15%相对提升；在 Replica 上为 0.2912 vs. 0.2701。
2. **不同任务需要不同读出**：没有任何单一读出在所有任务中占优——全信念投影在分割中最佳；共识和早期承诺检索在导航中并列最佳（76.9%）；早期承诺在场景00829中最强，共识在00848中最强。这验证了“单一提交表示并非普遍最优”的动机。
3. **优于现有系统**：导航成功率（76.9%）超过 DualMap（70.5%）、ConceptGraphs（61.5%）和 HOV-SG（52.6%）。
4. **执行纠正确实有效**：在真实世界 Unitree G1 中，查询保持的候选纠正将目标确认成功率从 6/10（60%）提升到 8/10（80%）；在“混淆干扰”条件下从 1/5（20%）提升到 3/5（60%），平均访问 1.40 个候选。
5. **同步消融验证设计选择**：统一证据加权会同时降低分割和导航性能；移除低证据正则化导致最大的导航性能下降；同义词整合带来小幅改进。
6. **证据保留的记忆机制可提升鲁棒性与可部署性**：通过保留多视角观测证据并将语义决策推迟至任务时，系统能更充分地利用早期观测信息，提升开放词汇导航的准确性和实际部署效果。

- **问题定义精准**：明确提出“早期语义承诺”问题，并区分了三个不同层面的承诺时机（建图、任务时读取、物理验证），问题建模清晰。
- **分离不变性原则**：视觉聚合特征与语言观测独立维护、永不破坏性融合，保持了两种模态的互换性，支持不同任务的灵活消费方式。
- **词汇无关的信念表示**：概念整合发生在自由文本空间而非基准特定标签，使同一图可服务任意下游词汇。
- **证据保留的实用性**：保留短语、可靠性线索、帧掩码来源——比仅保留CLIP嵌入提供更丰富的可追溯信息。
- **轻量级信念机制**：伪计数平滑、信任状态等方法无需训练、计算开销低，工程上易于落地。
- **算法设计诚实且边界清晰**：明确指出执行纠正是“查询特定候选排除”而非一般动态图修复或缺失目标推断，边界界定明确。

**实验设计亮点：**

- **严格的控制变量**：内部读出对比使用完全相同的图、观测和几何，确保差异仅来自读出选择。
- **仿真+真实双重验证**：在仿真中大规模定量验证，在真机上做试点验证（Unitree G1人形机器人），增强说服力。
- **配对案例设计**（真机实验）：同一图、查询、配置、起始位姿进行方法对对比，最大限度降低环境因素干扰。
- **多维度评估**：分割（mIoU/F-mIoU/mAcc）+导航（SR@1m）+真机确认率+消融，覆盖全面。

### 8. 不足与局限

**实验覆盖限制：**

- **真实世界规模有限**：仅10个配对案例（20次运行），为试点研究；论文明确承认未评估缺失目标拒绝、已移除目标检测、一般图修复或广泛领域泛化。
- **场景类型单一**：全部为室内场景（ScanNet200 5个、Replica 8个、HM3D 3个），未涵盖室外、半开放或动态环境；导航在静态环境中评估，未测试动态障碍下性能。
- **数据集时间戳异常**：论文引用年份为2025/2026的文献，数据集为HM3D，对象为YCB，但评估只用了3个HM3D场景，规模中等有限。
- **仿真导航未报告分层或类别粒度结果**：例如哪些YCB对象更容易/更难检索。

- **基线对比公平性存在隐患**：论文未明确说明 ConceptGraphs、HOV-SG、DualMap 的结果是重新实现获得，还是直接引用原论文数值。若直接引用，则不同实验环境、导航栈、视觉编码器甚至场景分割协议下的数值对比，都可能对本文方法有利或不利，削弱结论的可比性。

### 10. 参考价值与启示

尽管存在上述不足，本文对开放词汇机器人语义记忆研究具有较明确的参考价值：

- **概念层面**：“延迟语义承诺”是对现有3D场景图“建图即决策”范式的重要反思。它提醒研究者重新审视语义记忆中“何时做决定”这一基本设计问题，而非仅关注特征和网络结构。
- **工程层面**：将视觉证据、语言观测、概念信念分离存储，并在任务时组合读取，是一种实现简洁、可扩展性好的架构。该设计可被移植到动态场景图、长期记忆更新和多智能体共享地图等方向。
- **验证层面**：论文的实验框架（分割+导航+真机配对验证）本身可作为后续开放词汇记忆系统评测的参考模板，尤其是“相同图、仅改读出”的控制变量思路值得推广。

### 11. 总体评价

OpenBelief-Nav 是一篇问题意识清晰、方法设计有原则、实验布局较完整的工作。它不是靠更强的视觉模型或更大的数据集取胜，而是通过重新思考“语义承诺时机”提供了一个轻量、可解释、任务自适应的记忆框架。其最大的价值在于把“证据保存”与“延迟决策”这两个概念落地为可计算的对象表示和可工程化的读取流程，并以分割和导航两组任务验证了“不同任务需要不同语义读取”的核心观点。受限于真机实验规模、时间性能数据缺失和对比公平性细节不足，本文尚不能证明该系统在大规模、动态、开放环境中的绝对优势，但其方向和思路具有较强启发意义，值得后续工作在此基础上拓展。
