## 摘要
开放词汇的3D场景图为语言引导导航提供了紧凑的语义记忆，但映射出的对象通常通过单一融合特征或确定的语义标签来呈现。这种确定化处理可能会从任务时界面中移除少数但任务相关的假设。我们提出了OpenBelief-Nav，一种证据保留的对象记忆，它保留观察级短语、可靠性线索和帧掩码来源，同时维护独立的聚合几何和视觉表示。语义相关的短语被整合为一种与词汇无关的对象信念，任务特定的读取器从中执行固定词汇投影或自由形式检索。在五个ScanNet200和八个Replica场景上，完整信念投影的mIoU分数分别为0.2742和0.2912，而匹配的早期确定化读取器的mIoU分数为0.2393和0.2701。在78次HM3D-YCB导航试验中，共识检索和早期确定化检索各取得60/78的成功率，而信念加权检索为58/78，DualMap为55/78。在组织为10个匹配评估案例的20次Unitree G1运行中，一项允许最多两次验证候选尝试的校正策略，相对于仅执行第一候选方案，将目标确认成功率从6/10提高到8/10。代码将在论文接收后发布于https://openbelief-nav.github.io/。

## Abstract
Open-vocabulary 3D scene graphs provide compact semantic memory for language-guided navigation, but mapped objects are often exposed through a single fused feature or committed semantic label. Such commitment can remove minority yet task-relevant hypotheses from the task-time interface. We present OpenBelief-Nav, an evidence-preserving object memory that retains observation-level phrases, reliability cues, and frame-mask provenance while maintaining separate aggregate geometric and visual representations. Semantically related phrases are consolidated into a vocabulary-independent object belief from which task-specific readouts perform fixed-vocabulary projection or free-form retrieval. On five ScanNet200 and eight Replica scenes, full-belief projection achieves mIoU scores of 0.2742 and 0.2912, compared with 0.2393 and 0.2701 for a matched early-commit readout. Across 78 HM3D-YCB navigation trials, consensus and early-commit retrieval each achieve 60/78 successes, compared with 58/78 for belief-weighted retrieval and 55/78 for DualMap. Across 20 Unitree G1 runs organized as 10 matched evaluation cases, a correction policy permitting at most two verified candidate attempts improves target-confirmation success from 6/10 to 8/10 relative to top-1-only execution. Code will be released upon acceptance at https://openbelief-nav.github.io/.

## OpenBelief-Nav：面向开放词汇语言引导导航的证据保留对象记忆 —— 中文总结

### 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：在开放词汇的语言引导导航任务中，现有的开放词汇3D场景图（如 ConceptGraphs、HOV-SG、DualMap）在构建地图时，通常采用“早期语义承诺”（Early Semantic Commitment）策略，即把每个对象压缩成单一融合特征或一个固定的语义标签。这种策略会带来三个问题：
    - **证据丢失**：不同视角下对同一物体的观察可能不一致，早期选定的主导标签可能是错误的，而少数但正确的假设（如正确的类别或描述）已从观测历史中被永久丢弃，无法恢复。
    - **单一接口不通用**：一种语义读取方式无法在所有任务中达到最优。例如，固定词汇的语义分割需要将对象投影到指定标签集，而导航检索需要匹配自由形式查询，两者对对象表示的需求不同。
    - **检索结果不可靠**：在物理执行时，排名第一的目标只是一个假设，可能是干扰项或无法证实的实例，需要一种机制来验证并纠正这一假设。
- **整体含义**：本文主张将“语义承诺”从地图构建阶段延迟到任务执行时刻，通过保留物体观察级的原始证据（如短语、掩码、可靠性线索），让不同的下游任务在同一个固定的对象图上，使用不同的“读取器”来提取最适合自身需求的信息，从而提升导航的鲁棒性和准确性。

### 2. 论文提出的方法论：核心思想、关键技术细节与公式
- **核心思想**：**延迟语义承诺**。将对象节点视为“证据的集合”，而非“已做出的决策”。每个对象节点`B_i`存储多种信息，包括：点云、聚合视觉特征、语言观察列表、概念-证据向量、归一化相对支持度分布、共识文本特征以及信任状态。
- **关键步骤**：
    1.  **多模态证据采集**：使用视觉-语言模型（VLM）对每帧图像提出物体短语，并通过分割模型（SAM）生成掩码。每个掩码作为一条独立观测`oe`被存储，包含源帧、掩码索引、短语、分割置信度、有效点数、点云和视觉特征。
    2.  **几何-视觉对象关联**：采用保守的几何关联策略，仅使用点云重叠度和视觉特征相似度来判定观测是否属于同一对象实例。这种方式避免了语义差异（如同义词、错误标签）对实例形成的干扰，保证了对象身份的准确性。
    3.  **证据保留的语义信念构建**：
        - **可靠性加权**：使用分割置信度和3D支持点数的平方根作为观测权重。
        - **同义词感知的概念整合**：在共享文本空间中将语义相似的短语聚合为对象级概念假设，防止同义词导致票数分散。
        - **低证据正则化**：使用狄利克雷先验式的伪计数平滑（`α=0.5`）来计算每个概念的相对支持度，并设置信任状态（`ρ`），对于观测数量过少的节点在检索时降低其语言分支的权重。
    4.  **任务时语义读取器**：
        - **固定词汇投影**：当任务给定一个目标词汇表时，将保留的信念投影到该词汇表上。提出**全信念投影**方法，在投影前对信念进行视觉证据增强，并结合直接视觉预测，得到最终的类别分布。此方法不会丢弃次要假设，因而在语义分割中表现最佳。
        - **自由形式检索**：对于导航任务，提供三种基于语言相似度的读取方式：**共识检索**（使用信念加权平均的文本特征）、**早承诺检索**（只使用支持度最高的概念）、**信念加权检索**（对所有概念按支持度加权计算相似度）。
    5.  **执行时候选纠正**：将导航目标视为假设。机器人到达候选位置后，通过RGB-D观测进行验证，包括可见性、语义和几何检查。若验证失败，则将该候选排除，并将原始查询在剩余候选上重新进行检索和导航，直到确认成功、无候选可试或达到预算（`K_max=2`）。此过程不修改持久图结构，仅纠正当前查询与节点的绑定关系。

- 延迟语义承诺是有效的。在相同的对象图上，**全信念投影**在固定词汇语义分割上达到最优 mIoU（ScanNet200上0.2742，Replica上0.2912），显著优于早承诺读出的0.2393和0.2701，证明了保留次要假设的价值。

### 7. 优点
- **方法新颖且切中要害**：提出“延迟语义承诺”这一核心思想，直接针对了现有场景图构建中信息丢失的痛点，并给出了完整的解决方案。
- **设计上高度解耦与模块化**：将对象记忆与特定任务解码器解耦，使得同一个图可以在不同的下游任务中以不同的方式复用；同时将验证和纠正机制与全局地图更新分离，保证了系统灵活性。

- **从仿真到实体**：在模拟器中进行大规模验证的同时，也在真实人形机器人上进行了初步的物理验证，体现了研究的应用价值和工程落地能力。

### 8. 不足与局限
- **实验覆盖范围有限**：真实世界实验仅为试点研究，规模较小（20次运行），且场景类型可能较为单一。对对象的验证和纠正机制只针对“目标仍然在地图中存在”的情况，未评估目标缺失、物体被移除或地图动态变化等更复杂的场景。
- **关联错误不可逆**：对象关联采用保守策略以避免错误合并，但这种决策在持久地图中是单向的。一旦关联错误，后续的检索和验证仍可能基于错误的实例身份，无法在内存层面进行修复。
- **视觉特征处理不对称**：语言证据按观测保留，但视觉特征仍是聚合的。如果视觉特征由于视角或遮挡发生剧烈变化，单一的聚合特征可能无法最佳地代表该对象。
- **对底层依赖较强**：最终导航的成功率依赖于底层导航栈（局部障碍物规避、规划等）的可靠性。方法假设导航栈能到达目标观测点，但并未将导航失败的情况纳入对目标假设的误判考量。
- **未提供错误分析**：论文未深入分析导致模拟或真实世界中检索失败的具体失败模式和原因，这不利于后续针对性改进。
