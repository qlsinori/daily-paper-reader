## 摘要
零样本目标-物体导航要求机器人在从未进入过的建筑中找到指定类别的物体。主流方法用视觉-语言价值图对前沿进行评分：每一步都是对当前地图的argmax，而一旦执行该决策，其背后的证据便被丢弃。将大型视觉-语言模型置于感知-行动循环中的系统通常仅按固定时间表从当前视角查询它；机器人几分钟前走过的房间永远不会被重新考虑，一次失败的调用也没有定义的回退机制。我们将机器人已经看到的内容转化为深思熟虑的对象。我们的分层快慢智能体让价值图控制器每一步都保持运行，并在移动时写入坐标锚定的记忆：一个由房间类型和确认物体实例组成的语义网格，以及一个有界的、带有姿态标签的关键帧存储。视觉语言模型（VLM）在候选检测被写入之前对其逐一筛选。一个深思层在有界的推理-检索-行动循环中读取该记忆。它由反应层计算出的结构事件唤醒，首先在文本上进行推理，并且仅当仅靠文本无法区分候选时才回忆第一人称视角。每次调用和每次运行的限额限制了其调用次数，一个无调用的第一层解决了最常见的停滞，任何失败都会将控制权返回给反应控制器。我们的系统在HM3D v1验证集上达到68.75%的成功率，在MP3D验证集上达到47.29%，是此处比较的零样本方法中最高的成功率。在全部2000个HM3D episodes的配对比较中，通过argmax而非深思来选择远处前沿的成本为3.40个成功率百分点（95%置信区间[1.70, 5.05]）；对每个前沿都进行深思并不能挽回这些损失。

## Abstract
Zero-shot object-goal navigation (ZSON) requires a robot to find a named object category in a building it has never entered. The prevailing approach scores frontiers with a vision-language value map: every decision is another argmax over the map as it currently stands, and the evidence behind that score is discarded the moment it is taken. Systems that place a large vision-language model inside the perception-action loop typically query it on a fixed schedule from the current view alone; a room the robot walked through minutes earlier is never reconsidered, and a failed call has no defined fallback. We turn what the robot has already seen into the object of deliberation. Our hierarchical fast-slow agent leaves the value-map controller running at every step and writes a coordinate-anchored memory as it moves: a semantic grid of room types and confirmed object instances, together with a bounded store of pose-tagged keyframes. A VLM screens each candidate detection before it is written. A deliberative layer reads this memory in a bounded reason-retrieve-act loop. It wakes on structural events the reactive layer computes, reasons first over text, and recalls a first-person view only for candidates that text alone cannot separate. Per-invocation and per-run caps bound its calls, a call-free first tier resolves the most frequent stall, and any failure returns control to the reactive controller. Our system reaches 68.75% SR on HM3D v1 val and 47.29% on MP3D val, the highest success rate among the zero-shot methods compared here. Choosing among far frontiers by argmax instead of deliberating costs 3.40 SR points in a paired comparison over all 2000 HM3D episodes (95% CI [1.70, 5.05]); deliberating over every frontier does not recover them.

## 1. 论文的核心问题与整体含义

- **研究背景**：零样本目标-物体导航（ZSON）要求机器人在从未进入过的未知室内环境中找到指定类别的物体（如床、马桶、植物），且不经过任何类别特定的训练。
- **现有方法的缺陷**：
  - 主流方法（如VLFM、ASCENT）使用视觉-语言价值图对前沿（frontier）进行评分，每一步都是对当前地图的argmax决策，一旦决策被执行，其背后的证据就被丢弃。
  - 引入LLM/VLM的导航系统通常按固定时间表从当前视角查询模型，机器人几分钟前走过的房间永远不会被重新审视，失败调用也没有定义回退机制。
  - 4类结构性僵局（contact stalls、远处前沿、前沿耗尽、换楼层）无法通过当前值图的另一次argmax解决，其中3类依赖早已被丢弃的早期观察。
- **核心思路**：将被机器人"已经看到过"的内容（历史观察）转化为深思熟虑的对象——构建一个坐标锚定的记忆，并让一个慢速的推理层在有界的情况下对记忆进行检索和推理，而非仅仅依赖当前感知。

## 2. 方法论：核心思想、关键技术细节

### 2.1 总体架构：分层快慢智能体
- **快速层（反应式控制器）**：基于 ASCENT（VLFM 家族）的价值图控制器，每一步持续运行，负责感知、建图、短视运动。每层楼维护4张2D地图：占据图、价值图、语义网格、目标物体图。
- **慢速层（深思式控制器）**：仅在结构事件触发时醒来，执行有界的 reason–retrieve–act 循环（ReAct），返回类型化指令由反应层执行。推理层从不直接驱动运动。

### 2.2 坐标锚定记忆（Coordinate-Anchored Memory）
- **语义网格**：粗粒度网格（0.4m单元），聚合8×8占据像素块。每单元格存储：
  - 房间类型投票直方图（累积而非覆盖）；
  - 有界的关键帧索引环（视野覆盖该单元格）；
  - 稀疏物体实例表（类别、世界坐标、观测次数、支撑关键帧）。
  - 实例被观测≥2次才标记为"确认"并可被检索，抑制单次误检。
- **关键帧存储**：有界的低分辨率关键帧缩略图，按平移/旋转阈值采样，携带姿态、楼层、步数索引，并回填房间标签和可见物体；逐楼层容量限制保证新楼层不会挤掉早期楼层的记忆。
- **检索接口**：给定查询世界坐标，返回房间估计、附近已确认实例、覆盖率统计、排序后的候选关键帧。图像召回遵循严格退步阶梯：精确覆盖命中 → 放宽搜索 → 前沿发现帧 → 空结果（继续纯文本）。

### 2.3 事件触发的深思（4类触发）
| 触发模式 | 触发条件 | 处理方式 |
|---|---|---|
| 接触停滞（Contact stalls） | 滑动窗口内碰撞计数超过阈值 | 分层恢复：第一层无模型调用，直接抑制目标并重规划；必要时VLM生成逃生方向，逐轮排除已试方向 |
| 远处前沿（Distant frontiers） | 最近前沿距离超过 d_far | 第一轮纯文本比较候选，文本不足以区分时检索关键帧，第二轮带图提交（每次最多2张图） |
| 前沿耗尽（Frontier exhaustion） | 前沿集合为空但目标未找到 | 将已存关键帧做索引拼贴，单次带图调用寻找被忽略的通道（楼梯/门/开口） |
| 换楼层（Floor changes） | 当前楼层探索停滞且已知其他楼层 | 纯文本逐楼层摘要，决定是否换层，失败仍继续反应控制 |

### 2.4 预算控制与仲裁
- **逐次调用预算**：最多 M=3 轮推理，单次调用最多2张图，有墙钟上限。
- **逐次运行预算**：每次运行最多20次模型调用，其中最多10次带图调用，所有深思循环共享。
- **仲裁优先级**：恢复宏动作 > 楼梯状态机 > 目标/深思目标。深思目标持久化，抑制廉价反应抢占，直到到达或有效期结束。
- **失败回退**：每条失败路径（内存为空、服务中断、解析失败、预算耗尽）都回到反应式控制器，深思失效永远不会让智能体失去控制器。看门狗（单步决策超180秒）和断路器（连续失败后禁用模型调用）保证确定性降级。

## 6. 主要结论与发现

1. **主结果**：HM3D v1 val 上 SR 68.75%、SPL 33.97%；MP3D val 上 SR 47.29%、SPL 18.01%，全面领先所有对比的零样本方法。
2. **深思的价值**：远处前沿用argmax代替深思损失3.40 SR点（95% CI [1.70, 5.05]，p<0.001）；SR的提升不是来自更长的路径（SPL也领先）。
3. **触发时机比模型访问更重要**：Always-Deliberate（每步触发）得分64.80%，低于Greedy Frontier（65.35%）——给模型更多调用反而更差，证明"何时深思"的策略性价值。
4. **按需获取证据优于一次性全量**:One-Shot（一次性提交全部图像）损失3.70 SR点，说明自适应证据获取的不可替代性。
5. **语义网格的独立贡献**：拿掉语义网格（保留关键帧）损失3.35 SR点，且调用次数几乎不变，证明文本级抽象记忆本身的价值。
6. **失败归因呈互补性**：深思层将增益分散在false positives、no-frontier stops、false negatives三个类别；语义网格2.55/3.35的增益集中在防止过早停止。
7. **其他量化发现**：验证门在融合前否决16.7%的候选检测；重扫描在6.1%的episodes触发，其中41.4%从记忆视图产生新目标。

## 7. 优点

- **架构设计巧妙**：将深思层放在反应层之下而非取代反应层——"深思重定向机器人，但从不驱动它"，保持了反应式导航的高效性和鲁棒性。
- **记忆设计富有洞察**：坐标锚定的双层记忆（抽象语义网格 + 字面关键帧）配合严格回退阶梯，让模型先文本后图像，兼顾了推理效率与视觉验证的需求。
- **预算设计严谨**：逐调用+逐运行双层预算、无调用第一层、确定性降级路径、看门狗+断路器——深思的"可部署性"被作为方法本身的一部分而非实现细节。
- **实验设计高度制衡**：Always-Deliberate 消融直接反驳"更多模型访问=更好"的替代解释；失败类别分解（Figure 4）提供了机制级的可解释性；配对bootstrap和McNemar检验提供了统计严谨性。
- **成本透明**：报告了平均5.00次深思调用、3.04次带图调用、205步/ episode，以及17.2秒深思时间。

## 8. 不足与局限

- **硬件条件限制**：单张RTX 3090 GPU运行，无多卡扩展实验；未见推理延迟的详细分布，仅报告平均深思时间。
- **消融范围有限**：消融只在HM3D上进行，未在MP3D（更难的21类、多楼层场景）上验证各组件贡献；未做多次随机种子重复实验。
- **依赖外部VLM服务**：深思层和验证门调用外部VLM API，增加了系统对网络和服务可用性的依赖；文中虽设计了失败回退，但未报告服务故障下的实际表现。
- **对比范围仍有局限**：只对比了零样本方法，未与有监督或端到端学习的方法比较；未包含更多的近年方法（如2025-2026年新发表的工作）。
- **验证门的语义深度有限**：VLM验证仅基于当前帧裁剪图和提议类别做accept/reject，未利用多视角或多帧信息，可能放行"看起来像但实际不是"的误检。
- **历史观察的复用仍是受限的**：重扫描只能在语义网格和关键帧中进行，无法做物理上的重新访问（文中明确说"不是物理重遍历"），对于需要不同视角才能发现的物体的场景仍有局限。
- **未见对长尾场景的分析**：多楼层MP3D场景下性能仍相对较低（47.29% SR），且未单独分析目标类别间的成功率差异（如cushion vs sofa）。
